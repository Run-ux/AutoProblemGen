# 家庭收纳清单调整

> 生成任务：`taco_leetcode_inverse_edit_equal_home` / theme `home_organization`

## 题目描述

小明有两个柜子，每个柜子里存放的物品都有一个唯一的编码。这些编码遵循特定的格式：一个整数部分，可选的小数点，可选的 non-repeating 部分，以及可能由一对圆括号括起来的 repeating 部分。具体来说，一个合法的编码字符串必须符合以下三种形式之一：
- <整数部分> (例如 0, 12, 123)
- <整数部分>.< non-repeating 部分> (例如 0.5, 1., 2.12, 2.0001)
- <整数部分>.< non-repeating 部分>(<repeating 部分>) (例如 0.1(6), 0.9(9), 0.00(1212))

其中，整数部分的长度在 1 到 4 之间，non-repeating 部分的长度在 0 到 4 之间，repeating 部分的长度在 1 到 4 之间。整数部分不能以两个或更多的零开头（例如 "00" 开头是不允许的）。每个部分只包含数字字符 '0'-'9'。括号仅用于标记 repeating 部分，且必须成对出现，括号内至少有一个数字。

现在，小明发现两个柜子的物品编码清单不一致，他希望通过一系列调整操作，使两个清单的编码变得相同，并且总调整代价最小。每次调整操作称为一步，每一步的代价为 1。允许的调整操作包括：

1. 替换：将清单中的某一个数字字符改为另一个数字字符（例如将 '3' 改为 '5'）。
2. 插入括号：在符合格式的位置插入一对括号，将原本不循环的部分变为新的 repeating 部分。插入后必须满足格式约束（non-repeating 部分长度不能超过 4，且括号不能出现在整数部分等）。
3. 删除括号：删除一对已有的括号，将原来的 repeating 部分变为 non-repeating 部分。删除后不能违反格式约束（例如 non-repeating 部分长度不能超过 4）。
4. 移动括号：将一个左括号向左或向右移动一个字符位置，从而改变 repeating 部分的长度。移动后必须仍然是一个合法的编码字符串。

任何操作过程中及结束后的字符串都必须严格遵守编码格式约束。如果原始两个清单的编码已经相同，则不需要任何调整，总代价为 0。

请你帮助小明计算使两个清单编码相同所需的最小总代价，并输出一组达到该最小代价的修改后的清单编码（任意一组即可）。

## 输入格式

输入包含两行，每行一个字符串，分别表示第一个柜子和第二个柜子的原始物品编码。

## 输出格式

第一行输出一个整数，表示最小总代价。
第二行输出第一个柜子调整后的物品编码。
第三行输出第二个柜子调整后的物品编码。
如果存在多组最小代价方案，输出任意一组即可。

## 数据范围与限制

- 1 ≤ 每个字符串长度 ≤ 13（包括数字、小数点、括号）
- 时间限制：2 秒
- 空间限制：256 MB

## 样例

### 样例 1

**输入**

```text
0.0
0.1
```

**输出**

```text
1
0.1
0.1
```

**说明**

将第一个编码的最后一个 '0' 替换为 '1'，总代价为 1。

### 样例 2

**输入**

```text
0.(123)
0.(124)
```

**输出**

```text
1
0.(124)
0.(124)
```

**说明**

将第一个编码 repeating 部分中的 '3' 替换为 '4'，得到与第二个编码相同的字符串。总代价为 1。

### 样例 3

**输入**

```text
0.1(6)
0.1666(6)
```

**输出**

```text
0
0.1(6)
0.1666(6)
```

**说明**

两个编码本质上表示相同的物品序列，无需修改。输出原字符串即可。
