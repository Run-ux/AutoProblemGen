# 家庭收纳清单调整

> 生成任务：`taco_leetcode_inverse_edit_equal_home` / theme `home_organization`

## 题目描述

小明家里有两个大柜子，每个柜子里分成了许多小格子，每个格子里存放了一件物品。为了管理方便，小明给每个柜子里的物品都编制了一个“物品编码清单”，清单上的每个编码都是一个由数字、小数点和括号组成的特殊字符串。

一个合法的物品编码字符串必须符合以下三种格式之一：
- <整数部分> （例如 0, 12, 123）
- <整数部分>.<非重复部分> （例如 0.5, 1., 2.12, 2.0001）
- <整数部分>.<非重复部分>(<重复部分>) （例如 0.1(6), 0.9(9), 0.00(1212)）

各部分的含义和限制：
- 整数部分：长度在 1 到 4 之间，不能以两个或更多的零开头（如 "00" 不允许）。
- 非重复部分：长度在 0 到 4 之间。
- 重复部分：用圆括号括起来，括号内至少有一个数字，长度为 1 到 4。
- 所有数字均为 '0'~'9'。
- 括号只能用于标记重复部分，且必须成对出现。

两个物品编码表示同一个物品序列当且仅当它们代表的数值相等。具体来说，将每个编码字符串按重复部分无限拼接展开成无限小数，如果从某一位开始两个无限小数的数字序列完全相同，则它们相等。在实际判断时，由于总长度有限，只需将两个字符串分别展开到小数点后至少 17 位（循环节重复至足够长度），比较前 17 位小数即可得出正确结论。

现在小明发现两个柜子的物品清单可能代表不同的物品序列，他希望通过调整清单上的编码，使两个清单最终对应完全相同的物品序列。由于格子中的物品不能随意更改，他只能通过修改编码字符串本身来达到目的。每次对字符串的修改称为一步操作，每一步操作需要付出 1 点代价。每次操作只能执行下面列出的一种修改类型，不能在一次操作中同时进行多个修改。允许的操作类型如下：

1. 替换：将某个数字字符改为另一个数字字符（例如将 '3' 改成 '5'）。
2. 插入括号：在符合格式要求的位置插入一对圆括号，将一段原本属于非重复部分或重复部分的数字标记为新的重复部分。插入后必须满足格式约束（非重复部分长度不超过 4，且括号不能出现在整数部分等）。
3. 删除括号：删除一对已有的圆括号，将原重复部分变为非重复部分。删除后不能违反格式约束（例如非重复部分长度不能超过 4）。
4. 移动括号：将左括号向左或向右移动一个字符位置，从而改变重复部分的起始位置。移动后必须仍然是合法的编码字符串。

任何操作过程中以及最终得到的字符串都必须严格遵守上述编码格式约束。如果原始两个清单的编码已经对应相同的物品序列，则不需要任何调整，总代价为 0。

请你帮助小明计算使两个清单编码相同（即表示同一个数值）所需的最小总代价，并输出一组达到该最小代价的修改后的清单编码。如果存在多组最优方案，输出任意一组即可。

## 输入格式

输入共两行，每行一个字符串，分别表示第一个柜子和第二个柜子的原始物品编码。

## 输出格式

第一行输出一个整数，表示最小总代价。
第二行输出第一个柜子调整后的物品编码。
第三行输出第二个柜子调整后的物品编码。
如果存在多组最小代价方案，输出任意一组即可。

## 数据范围与限制

- 每个输入字符串总长度不超过 15 个字符（包括数字、小数点和括号）。
- 字符串严格遵循描述中给出的三种格式之一。
- 时间限制：2 秒
- 空间限制：256 MB

## 样例

### 样例 1

**输入**

```text
0.0
0.1
```

**输出**

```text
1
0.1
0.1
```

**说明**

将第一个字符串末尾的数字 '0' 替换为 '1'，即可使两个字符串相同，总代价为 1。

### 样例 2

**输入**

```text
0.(123)
0.(124)
```

**输出**

```text
1
0.(124)
0.(124)
```

**说明**

将第一个字符串重复部分中的 '3' 替换为 '4'，得到与第二个字符串完全相同的编码，总代价为 1。

### 样例 3

**输入**

```text
0.1(6)
0.1666(6)
```

**输出**

```text
0
0.1(6)
0.1666(6)
```

**说明**

两个编码原本就表示相同的物品序列（无限小数均为 0.1666...），无需任何调整，代价为 0。输出原字符串即可。

### 样例 4

**输入**

```text
0.1
0.(1)
```

**输出**

```text
1
0.(1)
0.(1)
```

**说明**

将第一个字符串插入一对括号，使 '1' 变成重复部分，得到 '0.(1)' 后与第二个字符串相等。也可以删除第二个字符串的括号得到 '0.1'，代价相同。输出其中一种方案。

### 样例 5

**输入**

```text
0.1(23)
0.12(3)
```

**输出**

```text
1
0.12(3)
0.12(3)
```

**说明**

将第一个字符串的左括号向右移动一位，重复部分由 '23' 变为 '3'，得到 '0.12(3)'，与第二个字符串相等。总代价为 1。

## 说明

两个编码相等性的判断依据是它们展开成无限小数后数值相同。实际实现时，将字符串展开到小数点后 17 位进行比较即可。如果有多组最小代价方案，输出任意一组均算正确。
