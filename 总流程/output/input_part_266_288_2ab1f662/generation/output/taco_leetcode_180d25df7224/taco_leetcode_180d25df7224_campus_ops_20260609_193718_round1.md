# 教室调度模式比较

> 生成任务：`construct_or_obstruction_campus_001` / theme `campus_ops`

## 题目描述

阳光大学的社团活动非常丰富，每个社团都需要提前向教务处申请教室使用时间。教务处使用一种特殊的格式来记录教室的占用模式，能够简洁地表示重复的周期安排。这种格式类似于小数的循环表示：可以用圆括号标明无限重复的部分。例如，“0.1(6)”表示从0.1开始，然后无限重复'6'，即占用模式在时间轴上的分布类似于0.1666...（与实际时间无关，仅用作模式表示）。

现在，两个社团提交了他们的教室占用模式记录，但可能用了不同的表达方式。你的任务是编写程序，比较这两种模式记录是否实质相同（即它们代表同一个教室占用模式）。如果相同，你需要输出该模式的一种“规范格式”（最简表示）；如果不同，你需要精确指出从哪一时刻开始，两个模式首次出现不一致，并提供该时刻的两个数字，以便教务老师能够快速、独立地验证你的判断，而无需重新进行全周期的复杂计算。

输入字符串的格式必须符合以下规则：
- 模式记录由三部分组成：整数部分、非重复小数部分（可选）、循环部分（可选）。
- 具体格式：只有整数部分；或整数部分后跟一个小数点和一个非重复部分；或整数部分后跟一个小数点、一个非重复部分，再跟一对圆括号括起来的循环部分。
- 整数部分不能有多余的前导零（除非整数部分就是0本身），且长度在1到4之间。
- 非重复部分长度在0到4之间，循环部分长度在1到4之间（如果存在）。
- 所有部分仅包含数字字符。

输出必须是严格的JSON对象，包含以下两种可能结构之一：
• 如果两个模式相同，输出：{"type":"equal","representation":"<规范表示>"}，其中<规范表示>是一个符合上述输入格式的字符串，且是该模式的最简规范表示（定义见后）。
• 如果两个模式不同，输出：{"type":"conflict","position":<整数>,"digit1":"<字符>","digit2":"<字符>"}。这里的position表示在将两个模式都完全展开为纯数字序列后（将循环部分重复足够多次以暴露差异），从0开始计数的第一个不同数字的位置。digit1为第一个模式在该位置的数字，digit2为第二个模式在该位置的数字。该证据是自我完整的：任何检查者只需查看该位置上的两个字符即可验证两个模式不等，无需进行全展开或复杂的数值比较。

规范表示的定义（保证唯一且最简）：
- 整数部分没有多余前导零（0本身除外）。
- 如果有小数部分，不会以循环的'9'结尾（意味着不会出现形如0.9(9)的表示，这种表示会转化为有限小数）。
- 优先选择非重复部分最短的表示；在等长的循环长度中，尽量使得循环部分不会以0开始（除非整个循环就是0，此时表示为有限小数）。
- 如果某种模式可以用有限小数准确表示（即没有循环或循环部分等效为0），则不允许出现循环括号。
- 值0的规范表示为"0"。

## 输入格式

两行，每行一个字符串，分别代表两个社团的教室占用模式记录。

## 输出格式

一行，一个JSON对象，结构如上所述。

## 数据范围与限制

- 时间限制：1秒
- 空间限制：256 MB

## 样例

### 样例 1

**输入**

```text
0.(52)
0.5(25)
```

**输出**

```text
{"type":"equal","representation":"0.(52)"}
```

**说明**

两个模式都表示循环小数0.525252...，规范表示中非重复部分应为空，因此输出"0.(52)"。

### 样例 2

**输入**

```text
0.(3)
0.1(2)
```

**输出**

```text
{"type":"conflict","position":1,"digit1":"3","digit2":"2"}
```

**说明**

将两个模式转换为纯数字序列：第一个为'0' + '3'重复 → "03333..."，第二个为'0' + '1222...' → "01222..."。在索引0（整数部分的0）处相同，索引1处出现第一次不同：第一个模式的数字是'3'，第二个模式的数字是'2'。因此冲突证据为position=1，digit1='3'，digit2='2'。验证者只需检查这两个字符即可确认它们不等，无需完整展开。

## 说明

冲突证据中的position索引基于以下规则：将每个模式记录转换为纯数字序列，转换方法为保留整数部分原样，若有小数部分则去掉括号并将循环节重复至长度L（本题保证L=20足够），然后将得到的小数数字串接在整数部分后面。索引0始终对应原整数部分的最左边数字。例如，输入“0.(52)”展开为“052525252...”，输入“123.0(1)”展开为“123010101...”。若两个序列长度不同（比如一个没有小数部分），则较短序列的小数部分视为后续全0。证据的自包含性意味着仅凭position和两个digit字符，即可判定两个模式不等，无需获取其他任何信息。
规范表示的算法需要保证相同数值的模式一定映射到完全相同的字符串。例如，0的规范表示为“0”；0.0和0.00等非法（因为不符合输入格式），0.9(9)的规范表示为“1.”。
