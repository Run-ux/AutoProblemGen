# 便民服务点布局

> 生成任务：`proj_inv_design_temples_move` / theme `community_services`

## 题目描述

在一个线形社区，有 N 户居民，他们的地址用整数坐标表示。社区计划部署 K 个移动便民服务点，每个服务点有固定的服务半径 R（即它可以覆盖距离它半径 R 范围内的所有住户）。由于服务点数量有限，无法直接覆盖所有住户。社区工作者可以事先与部分住户协调，让他们临时在指定日期搬家到其他地点（搬家是指将该住户的地址改为任意整数坐标），每次搬家计入一次调整。服务点可以放置在数轴上的任意实数坐标。

你的任务是计算最少需要多少次搬家，并给出一个能实现最少搬家的最终住户地址列表（按居民编号顺序输出），使得所有居民最终都能被 K 个服务点覆盖。

## 输入格式

第一行包含三个整数 N, K, R，分别表示住户数量、服务点数量和固定的服务半径。
第二行包含 N 个整数，表示每个住户的初始地址，整数之间用空格分隔。

## 输出格式

第一行输出一个整数 M，表示最少搬家次数。
接下来 N 行，每行输出一个整数，表示最终每个住户的地址。输出顺序必须与输入中住户的顺序一致。如果存在多种最优方案，输出任意一种即可。

## 数据范围与限制

- 1 ≤ N ≤ 10^5
- 1 ≤ K ≤ 10^5
- K < N
- 1 ≤ R ≤ 10^7
- 1 ≤ 初始地址 ≤ 10^7
- 时间限制：1 秒
- 空间限制：256 MB

## 样例

### 样例 1

**输入**

```text
3 2 3
1 5 20
```

**输出**

```text
1
1
5
5
```

**说明**

将第三户的地址从 20 移动到 5，移动次数为 1。服务点可以放置在坐标 3（覆盖用户 1 和 2）和坐标 5（覆盖用户 3）。所有住户均被覆盖，且无法用 0 次移动满足要求，故最小移动次数为 1。

### 样例 2

**输入**

```text
4 2 1
1 2 4 5
```

**输出**

```text
0
1
2
4
5
```

**说明**

初始位置已可直接部署服务点覆盖：设置服务点在 1.5 和 4.5，覆盖半径 1 恰好覆盖所有住户。无需搬家，最少移动次数 0。

### 样例 3

**输入**

```text
5 2 3
1 2 10 11 20
```

**输出**

```text
1
1
2
10
11
11
```

**说明**

将第五户的地址从 20 移动到 11，移动次数为 1。然后可将服务点放置在中心 1.5（覆盖用户 1 和 2）和中心 10.5（覆盖用户 3、4、5）。所有住户均被覆盖，且无法通过少于 1 次移动满足要求。

## 说明

保证存在至少一种方案使得通过若干次搬家后所有住户均可被覆盖。输出方案不唯一，任意最优解均可接受。
