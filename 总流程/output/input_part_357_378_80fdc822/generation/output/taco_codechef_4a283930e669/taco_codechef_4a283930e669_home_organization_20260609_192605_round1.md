# 整理收纳方案计数

> 生成任务：`home_organization_counting_v1` / theme `home_organization`

## 题目描述

小明正在整理他的物品收纳间。他有一张物品清单，上面包含了 N 个物品标签（每个标签是一个仅由小写英文字母组成的字符串）。他打算将清单中的部分物品两两配对，放入收纳格中。每个收纳格恰好放置两个物品，一个物品至多使用一次，也可以选择不放入任何收纳格（即闲置）。

对于一个收纳格中两个物品标签，定义它们的匹配度为：设 p 为两个标签的最长公共前缀长度，s 为最长公共后缀长度，则匹配度为 min(p, s)^2。整个收纳方案的整齐度为所有收纳格的匹配度之和。

小明想知道：在所有能够达到的最大整齐度的不同收纳方案中，一共有多少种方案？由于答案可能很大，只需要输出方案数模 1,000,000,007 的结果。

两个收纳方案视为不同，当且仅当它们对应的配对集合（基于物品在清单中的原始索引形成无序对）作为多重集不同。配对内部的顺序以及方案内配对的顺序均无关。

## 输入格式

第一行包含一个整数 T（1 ≤ T ≤ 100,000），表示测试用例的数量。接下来是 T 个测试用例。
每个测试用例的第一行包含一个整数 N（1 ≤ N ≤ 100,000），表示物品数量。
接下来的 N 行，每行包含一个仅由小写字母组成的非空字符串，表示一个物品标签。

## 输出格式

对于每个测试用例，输出一行一个整数，表示达到最大整齐度的不同方案数模 1,000,000,007 的结果。

## 数据范围与限制

- 1 ≤ T ≤ 100,000
- 所有测试用例的 N 之和不超过 100,000
- 所有测试用例的物品标签总长度之和不超过 100,000
- 每个物品标签仅由小写英文字母组成，且长度至少为 1
- 时间限制：2 秒
- 空间限制：256 MB

## 样例

### 样例 1

**输入**

```text
2
3
abc
abd
xyz
4
a
a
a
a
```

**输出**

```text
4
3
```

**说明**

第一个测试用例中，三个物品标签分别为 "abc"、"abd"、"xyz"。任何配对的匹配度均为 0，因此最大整齐度为 0，所有合法方案（包括空方案）都是最优方案。空方案有 1 种；恰好包含一个配对的方案有 C(3,2)=3 种，总方案数为 4。
第二个测试用例中，四个物品标签均为 "a"（但索引不同）。配对 "a" 和 "a" 的匹配度为 min(1,1)^2 = 1。最大总整齐度为 2（形成两个配对）。达到该最大值的方案即为将四个物品分成两个配对的方式，共有 (4-1)!! = 3 种（分别对应三种不同的配对划分），因此方案数为 3。

### 样例 2

**输入**

```text
1
2
ab
ab
```

**输出**

```text
1
```

**说明**

两个物品标签均为 "ab"。它们可以配成一个收纳格，匹配度为 min(2,2)^2 = 4，达到最大整齐度 4。由于只有一种配对方式，最优方案唯一，故输出 1。

## 说明

方案的不同性严格基于物品在原始清单中的索引，而非标签内容。即使两个物品标签相同，只要它们来自清单中的不同位置，在计数时视为不同的元素；但配对集合是无序的，因此交换同一对内的两个物品或改变配对在方案中的顺序不产生新方案。所有运算均在模 1,000,000,007 下进行。
