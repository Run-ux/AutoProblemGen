# 整理柜子 · 最优清单

> 生成任务：`home_org_canonical_witness_001` / theme `home_organization`

## 题目描述

小明正在整理家里的柜子。柜子有一排共 n 个格子，编号为 1 到 n。他有 n 件物品，每件物品有一个重要性分数 s_i（保证都是 100 的倍数）。

柜子参与了两项整理标签计划：
- 标签 A：在编号为 a, 2a, 3a, … 的格子上，该格子中物品的 x% 分数会计入整理评分；
- 标签 B：在编号为 b, 2b, 3b, … 的格子上，该格子中物品的 y% 分数会计入整理评分。
若某个格子同时被两个标签覆盖，则计入 (x + y)% 的分数。

保证 x + y ≤ 100，且所有分数都是 100 的倍数，因此计算不会产生小数。

小明计划只使用前 m 个格子（即格子 1 到 m）。他需要从 n 件物品中挑选恰好 m 件，每件物品只能使用一次，并将它们放入这 m 个格子里（每个格子放一件）。放入的顺序（即哪个物品放在哪个格子）可以任意决定。

整理评分的计算方式为：对前 m 个格子，根据上述标签规则计算每个格子的贡献百分比，再乘上该格子中物品的分数，求和后得到总整理评分。

小明有两个目标：
1. 使用的格子数 m 尽可能小，即用最少的物品让总整理评分达到或超过 k；
2. 在满足 m 最小的前提下，他希望在格子 1 到 m 中看到的物品分数序列（按格子从左到右的顺序）的字典序尽可能大。

字典序比较规则：将两个长度均为 m 的分数序列从左到右逐项比较。在第一个不同的位置上，分数较大的序列视为更大；如果分数相同，则比较该物品在原输入中出现的索引（从 1 开始），索引较大的视为更大。你只需输出分数序列，不需要输出索引。

请你帮助小明求出每个询问下的最优方案。

## 输入格式

第一行一个整数 q (1 ≤ q ≤ 100)，表示询问的组数。
接下来按组依次给出 q 组询问。每组询问的格式如下：

第一行一个整数 n (1 ≤ n ≤ 2×10^5)，代表物品的总数。
第二行 n 个整数 s_1, s_2, ..., s_n (100 ≤ s_i ≤ 10^9, s_i 是 100 的倍数)，表示每件物品的重要性分数。
第三行两个整数 x 和 a (1 ≤ x ≤ 100, 1 ≤ a ≤ n)，表示标签 A 的百分比和周期。
第四行两个整数 y 和 b (1 ≤ y ≤ 100, 1 ≤ b ≤ n, 保证 x + y ≤ 100)，表示标签 B 的百分比和周期。
第五行一个整数 k (1 ≤ k ≤ 10^14)，为目标整理评分。

保证所有询问的 n 之和不超过 2×10^5。

## 输出格式

对于每组询问，输出一行：
- 如果存在方案能达到 k 分，输出一个整数 m（最小格子数），然后是 m 个整数，表示字典序最大的分数序列（按放置位置从左到右的顺序）。
- 否则输出 -1。

## 数据范围与限制

- 时间限制：2.0 秒
- 空间限制：256.0 MB
- 1 ≤ n ≤ 200000，所有询问 n 的总和 ≤ 200000
- 100 ≤ s_i ≤ 10^9，s_i 是 100 的倍数
- 1 ≤ x, y ≤ 100，x + y ≤ 100
- 1 ≤ a, b ≤ n
- 1 ≤ k ≤ 10^14

## 样例

### 样例 1

**输入**

```text
2
3
200 100 300
50 2
30 3
150
4
400 100 200 100
20 2
10 4
80
```

**输出**

```text
2 200 300
2 200 400
```

**说明**

第一组询问：n=3，分数 [200, 100, 300]，标签 A: x=50%, a=2；标签 B: y=30%, b=3；目标 k=150。
- 若只用 1 个格子（m=1），只能用格子 1，它不带任何标签，贡献为 0，不可能达到 150。
- 使用 2 个格子（m=2）：格子 1（无标签），格子 2（标签 A，50%）。需要总贡献 ≥150。把最大的分数 300 放到格子 2，贡献 = 300 × 50% = 150；格子 1 放任意剩余物品，贡献 0。因此 m=2 可行，且 2 是最小的 m。
- 在所有 m=2 且总贡献 ≥150 的序列中，要选字典序最大的。可能的分数序列有 [200, 300] 或 [100, 300]（格子 2 必须放 300 才能达标，格子 1 放剩下的）。比较 [200, 300] 和 [100, 300]，第一项 200 > 100，因此 [200, 300] 更大。输出 2 200 300。

第二组询问：n=4，分数 [400, 100, 200, 100]，标签 A: x=20%, a=2；标签 B: y=10%, b=4；目标 k=80。
- m=1：格子 1 无标签，不可行。
- m=2：格子 1（无），格子 2（标签 A，20%）。需要贡献 ≥80，则格子 2 必须放至少 400 的物品（400×20%=80）。因此必须把 400 放在格子 2，格子 1 放剩余任意物品。
- 剩余物品中可选 200 或 100（两个 100 中的一个）。为了字典序最大，格子 1 的分数应尽量大，所以选 200。序列 [200, 400] 是可行的且字典序最大。注意 [400, 100] 虽然第一个数更大，但 400 放在格子 1 贡献为 0，格子 2 只能放剩余最大 200（贡献 40），总贡献 40 < 80，不可行。因此输出 2 200 400。

### 样例 2

**输入**

```text
1
1
100
10 2
10 2
50
```

**输出**

```text
-1
```

**说明**

只有一件物品，分数为 100。格子 1 不在任何标签周期内（a=2, b=2，第 1 个格子不是 2 的倍数），贡献百分比为 0%，总贡献为 0，无法达到目标 k=50，因此输出 -1。

## 说明

字典序比较规则：先比较分数，分数大的序列更大；分数相同时，比较该物品在原输入中的索引（从 1 开始），索引大的更大。所有物品的分数均为 100 的倍数，计算贡献时不会产生小数。每组询问独立，物品不可跨询问复用。
