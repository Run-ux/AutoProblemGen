# 校园闸机配对计数

> 生成任务：`taco_campus_turnstile_pairing_count` / theme `campus_ops`

## 题目描述

某大学校园里有 n 间教室，教室之间由 n−1 条走廊连接，形成一棵树，任意两间教室可以互相到达。学校在 2k 间不同教室里安装了闸机，现在计划将这些闸机恰好配成 k 对，每一对的两台闸机之间通过走廊建立一条直达通道。每种配对方案的总距离定义为这 k 条路径所经过的走廊总长度（每条走廊的长度均为 1）。

根据分析，要使总距离达到最大，必须满足：对于任意一条走廊，它被路径经过的次数恰好等于该走廊两侧闸机数中较少的那一侧的闸机数量（即流量达到上限）。

请你计算共有多少种不同的闸机配对方案能够使总距离达到这个最大值。由于方案数可能很大，请对 1000000007 (10^9+7) 取模后输出。

配对方案的不同仅由哪些闸机被分到同一对决定，不考虑对内的顺序，也不考虑 k 个对之间的排列顺序。

## 输入格式

第一行包含两个整数 n 和 k，分别表示教室数量和需要配对的闸机对数。
第二行包含 2k 个互不相同的整数，表示安装了闸机的教室编号，编号从 1 到 n。
接下来的 n−1 行，每行包含两个整数 u 和 v，表示编号为 u 的教室和编号为 v 的教室之间有一条走廊。

## 输出格式

输出一个整数，表示使总距离达到最大值的闸机配对方案数量对 1000000007 取模的结果。

## 数据范围与限制

- 2 ≤ n ≤ 2000
- 1 ≤ k ≤ n/2
- 1 ≤ 闸机编号 ≤ n，且所有闸机编号互不相同
- 保证输入的走廊构成一棵树
- 时间限制：2 秒
- 空间限制：256 MB

## 样例

### 样例 1

**输入**

```text
4 1
1 4
1 2
2 3
3 4
```

**输出**

```text
1
```

**说明**

只有一种配对方案：将教室 1 和教室 4 的闸机配对，路径为 1–2–3–4，总距离为 3，达到最大值，因此方案数为 1。

### 样例 2

**输入**

```text
7 2
1 2 5 6
1 3
3 2
4 5
3 7
4 3
4 6
```

**输出**

```text
2
```

**说明**

闸机位于教室 1, 2, 5, 6，可以算出最大总距离为 6。满足这一最大值的配对方案共有两种：(1,5) 和 (2,6) 配对，或者 (1,6) 和 (2,5) 配对。其余配对方式总距离都小于 6，不计入答案。

## 说明

输入保证 2k ≤ n。如果某条走廊某一侧没有闸机，则该走廊不会被任何路径经过。方案计数时，对内的两个闸机无顺序之分，对之间的顺序也不影响方案是否相同。
