# 家庭收纳：物品配对方案计数

> 生成任务：`home_org_counting_pairs` / theme `home_organization`

## 题目描述

小明的家里有 n 个房间，房间之间由 n-1 条走廊连接，任意两个房间都可以通过若干条走廊相互到达，且所有走廊的长度都是 1。

小明有 2k 件物品，它们分别放在不同的房间里（每个房间最多放一件物品）。他打算将这些物品两两配对，共分成 k 对。对于一条连接房间 u 和 v 的走廊，如果移除这条走廊，整个家会分成两个区域。设其中一个区域中包含 x 件物品，则另一个区域中包含 2k - x 件物品。

小明希望配完所有物品后，每条走廊恰好被 min(x, 2k - x) 对物品的配对路径经过。可以证明，满足这一条件的配对方案恰好使所有配对路径的总长度达到最大，且不会出现某条走廊被“过度使用”。

请你帮小明计算：一共有多少种不同的物品配对方案满足上述条件？由于答案可能很大，请输出方案数对 998244353 取模的结果。

注意：物品配对是无序的，即 (a, b) 和 (b, a) 视为同一对；作为结果的 k 对也是无序的，即配对集合中配对之间的顺序不影响方案计数。

## 输入格式

第一行包含两个整数 n, k (2 ≤ n ≤ 200,000, 1 ≤ k ≤ n/2)，分别表示房间的数量和需要配成的对数。

第二行包含 2k 个互不相同的整数，表示每一件物品所在的房间编号，编号范围为 1 到 n。

接下来 n-1 行，每行包含两个整数 u, v (1 ≤ u, v ≤ n, u ≠ v)，表示一条直接连接房间 u 和房间 v 的走廊。输入保证所有走廊构成一棵树。

## 输出格式

输出一个整数，表示满足条件的配对方案数对 998244353 取模的结果。

## 数据范围与限制

- 2 ≤ n ≤ 200,000
- 1 ≤ k ≤ n/2
- 时间限制：2.5 秒
- 空间限制：256 MB

## 样例

### 样例 1

**输入**

```text
3 1
1 2
1 2
2 3
```

**输出**

```text
1
```

**说明**

只有房间 1 和房间 2 放有物品，唯一的走廊是 (1,2) 和 (2,3)。移除走廊 (1,2)，一侧有 1 件物品，另一侧有 1 件物品，min=1，因此这条走廊必须被一对经过。唯一可行的配对就是将这两件物品配成一对，所以方案数为 1。

### 样例 2

**输入**

```text
4 2
1 2 3 4
1 2
2 3
3 4
```

**输出**

```text
2
```

**说明**

四个房间形成一条链，每个房间都有一件物品。各条走廊两侧的物品数量较小值分别为 (1,2):1，(2,3):2，(3,4):1。要求每条走廊的经过对数恰好等于该值。枚举所有配对方式，只有 (1,4) 和 (2,3) 以及 (1,3) 和 (2,4) 满足条件，共 2 种方案。

## 说明

题目中的取模数 998244353 是一个质数，用于避免大整数溢出。配对方案中，物品对的内部顺序以及对之间的顺序均不计入方案差异，只关心哪两件物品被配成一对。输入数据保证 2k ≤ n，即物品数量不超过房间总数。
