# 和谐社区的构建

> 生成任务：`inv_design_squareful_min_edit` / theme `community_services`

## 题目描述

在一个小社区里，有 n 个居民。每个居民拥有一个非负整数编号。社区希望以某种顺序排列居民，使得任意相邻两位居民的编号之和都是一个完全平方数。满足这个条件的排列称为“和谐排列”。

初始时，居民的编号不一定能得到恰好 K 种不同的和谐排列（如果两个排列的编号序列完全相同，即使居民不同，也视为同一种排列）。社区管理员可以修改某些居民的编号——将指定居民的原编号替换为 [0, 10^9] 内的任意整数，每个居民最多修改一次，即同一个居民不能多次修改。

你的任务是计算：最少需要修改多少个居民的编号，才能使得最终的居民编号序列存在恰好 K 种不同的和谐排列。如果无论怎么修改都无法达到 K 种和谐排列，则输出 -1。

## 输入格式

第一行两个整数 n 和 K，分别表示居民数量和目标和谐排列数。
第二行 n 个整数，依次表示初始时每个居民的编号。

## 输出格式

一个整数，表示最少需要修改的居民数量。如果无法达到目标，输出 -1。

## 数据范围与限制

- 1 ≤ n ≤ 12
- 0 ≤ K ≤ 10^9
- 0 ≤ 初始编号 ≤ 10^9
- 修改后的编号可以是 [0, 10^9] 内的任意整数
- 时间限制：2 秒
- 空间限制：256 MB

## 样例

### 样例 1

**输入**

```text
2 1
1 8
```

**输出**

```text
1
```

**说明**

初始编号 [1,8] 会产生两种和谐排列：[1,8] 和 [8,1]。目标为 1，可以将第二个居民编号改为 8，得到 [8,8]，此时和谐排列只有一种（因为 [8,8] 的编号序列唯一）。因此最少修改 1 个居民。

### 样例 2

**输入**

```text
2 2
1 1
```

**输出**

```text
1
```

**说明**

初始编号 [1,1] 只有一种和谐排列，目标为 2。将第二个居民编号改为 3，得到 [1,3]，共有两种和谐排列：[1,3] 和 [3,1]。最少修改 1 个居民。

### 样例 3

**输入**

```text
1 0
0
```

**输出**

```text
-1
```

**说明**

当 n=1 时，唯一排列就是它自己，和谐排列数总是 1，无法达到 0。

## 说明

统计不同和谐排列时，编号序列相同的排列被视作同一种排列。
你需要保证输出的修改方案是修改居民数最少的；如果存在多种最小方案，只需输出最少修改数量，不必给出具体修改内容。
数据保证答案不会超过 n，无需考虑整数溢出。
