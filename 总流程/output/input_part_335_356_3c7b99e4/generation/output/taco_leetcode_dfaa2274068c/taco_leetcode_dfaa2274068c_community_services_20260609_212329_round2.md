# 和谐整理的最小修改次数

> 生成任务：`taco_leetcode_dfaa2274068_inverse_mod` / theme `home_organization`

## 题目描述

乐乐正在整理收纳柜，柜子里有 n 个物品，每个物品上写着一个非负整数作为标签。他要把这些物品排成一排，要求任意相邻两个物品的标签之和是一个完全平方数（即可以写成某个非负整数的平方）。满足该条件的排列称为“和谐排列”。特别地，如果 n = 1，唯一的排列自动视为和谐排列。

乐乐可以修改物品的标签：每次操作可以选择任意一个物品，将其标签改为任意非负整数。他希望通过若干次修改，使得修改后的物品标签数组的和谐排列总数恰好等于给定的目标值 K。由于修改操作比较麻烦，乐乐希望操作次数尽可能少。

请你帮助乐乐计算：最少需要进行多少次修改操作才能让和谐排列总数恰好为 K；如果无法做到，请输出 -1。

## 输入格式

第一行包含两个整数 n 和 K，以空格分隔，分别表示物品数量和目标和谐排列数。
第二行包含 n 个非负整数，以空格分隔，表示初始时每个物品的标签。

## 输出格式

一个整数，表示最少修改次数；若无法达成目标，则输出 -1。

## 数据范围与限制

- 1 ≤ n ≤ 12
- 0 ≤ K ≤ 10^9
- 0 ≤ A[i] ≤ 10^9
- 时间限制：2秒
- 空间限制：256 MB

## 样例

### 样例 1

**输入**

```text
2 1
2 2
```

**输出**

```text
0
```

**说明**

初始标签为 [2,2]，2+2=4 是完全平方数，唯一的排列 [2,2] 是和谐排列，和谐排列数为 1，恰好等于目标 K=1，无需修改。

### 样例 2

**输入**

```text
2 0
1 8
```

**输出**

```text
1
```

**说明**

初始标签为 [1,8]，唯一的排列 [1,8] 满足 1+8=9（完全平方数），因此和谐排列数为 1。将第一个物品的标签修改为 2，得到 [2,8]，此时相邻和为 2+8=10，不是完全平方数，没有任何和谐排列，排列数为 0，等于目标 K=0。修改 1 次即可达到目标。

## 说明

如果 n = 1，唯一的排列被视为和谐排列，和谐排列数始终为 1。因此当 K 不等于 1 时（例如 K=0 或 K>1），答案必为 -1。

当数组中有重复元素时，交换完全相同的数值不视为不同的排列；两个排列被视为不同当且仅当存在某个位置上的标签值不同。

修改操作可以直接选择某个物品的初始标签值，也可以选择任意非负整数。算法需要保证输出的操作次数在所有可行方案中是最小的。
