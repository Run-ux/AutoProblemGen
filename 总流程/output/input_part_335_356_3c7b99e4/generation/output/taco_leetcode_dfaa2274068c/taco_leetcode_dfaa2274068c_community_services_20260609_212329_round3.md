# 社区和谐设计

> 生成任务：`community_harmony_design` / theme `community_services`

## 题目描述

社区中有 n 位居民，每位居民有一个非负整数欢乐值。社区管理员希望重新安排居民的欢乐值序列，使得一个排列被称为“和谐”的当且仅当排列中每相邻两位的欢乐值之和为完全平方数。注意，如果居民数量为 1，则该排列自动视为和谐。

你不需要计算总共有多少种和谐排列，而是有一个目标数量 K。管理员可以执行修改操作：每次选择一个位置，将该位置上的欢乐值改为任意非负整数（范围 0 到 10^9）。目标是使修改后的欢乐值数组恰好有 K 种不同的和谐排列（按值序列判定是否相同，即两个排列若数值序列完全一致，则视为同一种）。

请你求出最少需要多少次修改操作，如果无法通过任何修改达到目标 K，则输出 -1。

## 输入格式

第一行一个整数 n (1 ≤ n ≤ 12)，表示居民数量。
第二行 n 个整数 a_1, a_2, ..., a_n (0 ≤ a_i ≤ 10^9)，表示初始欢乐值。
第三行一个整数 K (0 ≤ K ≤ 479001600)，表示目标和谐排列数量。

## 输出格式

输出一个整数，表示最少修改操作次数，如果无法达成目标则输出 -1。

## 数据范围与限制

- 1 ≤ n ≤ 12
- 0 ≤ a_i ≤ 10^9
- 0 ≤ K ≤ 479001600
- 时间限制：2 秒
- 空间限制：256 MB

## 样例

### 样例 1

**输入**

```text
1
0
1
```

**输出**

```text
0
```

**说明**

只有一位居民，任何排列均视为和谐，因此初始和谐排列数为 1，等于目标 K，无需修改。

### 样例 2

**输入**

```text
2
1 1
1
```

**输出**

```text
1
```

**说明**

初始数组 [1,1] 只有一种排列，但相邻和 1+1=2 不是完全平方数，和谐排列数为 0。将第二个数改为 0，得到 [1,0]，此时仅一种排列，且 1+0=1 为完全平方数，和谐排列数为 1，达到目标。最少修改次数为 1。

### 样例 3

**输入**

```text
2
1 3
2
```

**输出**

```text
0
```

**说明**

初始数组 [1,3] 有两种不同的排列：[1,3] 和 [3,1]，相邻和均为 1+3=4 为完全平方数，故和谐排列数即为 2，已等于目标 K，无需修改。

## 说明

当 n=1 时，由于不存在相邻对，该排列自动视为和谐，且和谐排列数为 1（仅有一种排列）。
排列按值序列区分：若两个排列在每一个位置上的数值都相同，则认为它们是同一种排列，不计为多次。
完全平方数指可以表示为某个整数的平方的数，例如 0, 1, 4, 9, 16 等。
如果无论如何修改都无法得到恰好 K 种和谐排列，则输出 -1。
修改操作可以任意选择位置和值，但值必须保持在 [0, 10^9] 范围内。
