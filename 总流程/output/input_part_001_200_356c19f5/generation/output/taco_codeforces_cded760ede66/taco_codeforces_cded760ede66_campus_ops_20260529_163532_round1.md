# 社团物资分配

> 生成任务：`campus_ops_scheme_or_conflict` / theme `campus_ops`

## 题目描述

学校仓库里存放着一些特殊的物资包，每个物资包的价值正好是某个幂次 k^e（其中 k 是大于 1 的整数，e 是非负整数），并且每种价值的物资包只有一个。

现在有 n 个社团提出了物资申请，第 i 个社团希望得到总价值恰好为 a_i 的物资。你需要从仓库中挑选一些物资包分配给社团，每个物资包只能分配给一个社团。

如果能够满足所有社团的需求，请输出一种分配方案；如果无论如何分配都无法同时满足所有社团，请指出具体是哪两个社团因为同一个价值的物资包而发生了冲突。

## 输入格式

第一行包含一个整数 T (1 ≤ T ≤ 1000)，表示测试用例的个数。接下来每两行描述一个测试用例。

对于每个测试用例：
第一行包含两个整数 n 和 k (1 ≤ n ≤ 30, 2 ≤ k ≤ 100)，分别表示社团的数量和物资包价值的底数。
第二行包含 n 个整数 a_1, a_2, …, a_n (0 ≤ a_i ≤ 10^16)，依次表示每个社团的需求总额。

## 输出格式

对于每个测试用例，输出两或三部分内容，具体取决于是否可分配：

如果存在分配方案，第一行输出 "plan"（不含引号）。
接下来的第一行输出一个整数 M (0 ≤ M ≤ 总幂次个数)，表示实际发放的物资包数量。
然后输出 M 行，每行包含两个整数 c 和 e，表示将价值为 k^e 的物资包分配给第 c 个社团（社团编号从 1 开始）。

如果不存在分配方案，第一行输出 "conflict"（不含引号）。
紧接着在一行内输出三个整数 e, c1, c2，表示价值为 k^e 的物资包同时被社团 c1 和社团 c2 需要（c1 ≠ c2）。

## 数据范围与限制

- 时间限制：2 秒
- 空间限制：256 MB
- 1 ≤ T ≤ 1000
- 1 ≤ n ≤ 30
- 2 ≤ k ≤ 100
- 0 ≤ a_i ≤ 10^16

## 样例

### 样例 1

**输入**

```text
2
2 2
1 2
3 3
1 1 1
```

**输出**

```text
plan
2
1 0
2 1
conflict
0 1 2
```

**说明**

第一组数据：仓库中有价值为 2^0=1 和 2^1=2 的物资包。将价值 1 的物资包分配给社团 1，价值 2 的物资包分配给社团 2，两者恰好满足需求。
第二组数据：三个社团都需要价值 3^0=1 的物资包，而该价值的物资包只有一个，因此无法同时满足，任意两个社团就会冲突。这里输出社团 1 和 2 都需要指数 0。

### 样例 2

**输入**

```text
1
3 4
0 4 1
```

**输出**

```text
plan
2
2 1
3 0
```

**说明**

仓库中有价值 4^0=1 和 4^1=4 的物资包。社团 1 需求为 0，无需分配；社团 2 需求 4，获得价值 4 的物资包；社团 3 需求 1，获得价值 1 的物资包。分配成功。

## 说明

分配方案可能不唯一，输出任意一个合法方案即可。
对于冲突情况，只需要给出一对冲突的社团即可，即使有更多社团也同时需要同一价值的物资包。
指数不会太大，因为 a_i ≤ 10^16，保证所有涉及的指数不超过约 60（实际取决于 k）。
一个社团可以接收多个不同价值的物资包，但同一个价值的物资包不能分给多个社团。
