# 最优巴士路线调整

> 生成任务：`inv_design_community_route_1` / theme `community_services`

## 题目描述

社区为方便住户出行，开通了一条巴士接驳线路，该线路用一个二维向量 $C$ 表示，每次乘坐巴士会使住户的当前位置增加 $C$。同时，住户可以在任何时刻原地顺时针旋转 90 度（即 $(x,y)$ 变为 $(y,-x)$）。

现在，社区计划对巴士路线进行微调，以更好地服务住户。调整方式为选择一个整数向量 $D=(dx,dy)$，将原路线 $C$ 改为 $C' = C + D$。调整所需的成本定义为曼哈顿距离 $|dx| + |dy|$。

已知住户的初始位置 $A$ 和目标位置 $B$（社区服务中心），目标是通过多次旋转和乘坐调整后的巴士，从 $A$ 到达 $B$。可以证明，总存在一种调整方案使得住户能够到达目标。

请计算满足要求的最小调整成本（非负整数）。

## 输入格式

输入包含三行，每行两个整数，用空格分隔：
第一行是住户初始位置的坐标 $x_A, y_A$。
第二行是服务中心位置的坐标 $x_B, y_B$。
第三行是原巴士路线向量的坐标 $x_C, y_C$。

## 输出格式

输出一个非负整数，表示使得住户能够到达服务中心所需的最小调整成本。

## 数据范围与限制

- 所有坐标均为整数，绝对值不超过 $10^8$。
- 时间限制：1.0 秒
- 空间限制：256.0 MB

## 样例

### 样例 1

**输入**

```text
2 2
3 3
1 0
```

**输出**

```text
1
```

**说明**

将原路线从 $(1,0)$ 调整为 $(1,1)$，成本为 $|1-1|+|1-0|=1$。住户从 $(2,2)$ 出发，直接乘坐一次巴士（无需旋转）即可到达 $(3,3)$。

### 样例 2

**输入**

```text
0 0
1 1
0 1
```

**输出**

```text
1
```

**说明**

将原路线从 $(0,1)$ 调整为 $(1,1)$，成本为 $|1-0|+|1-1|=1$。住户从 $(0,0)$ 出发，乘坐一次巴士即可到达 $(1,1)$。

### 样例 3

**输入**

```text
0 0
0 0
5 5
```

**输出**

```text
0
```

**说明**

起点与终点重合，无需调整路线即可到达（只需不移动），成本为 $0$。

## 说明

曼哈顿距离定义为 $|dx|+|dy|$。若某个旋转状态下住户位置已等于服务中心，则无需调整即可到达，此时答案为 $0$。
