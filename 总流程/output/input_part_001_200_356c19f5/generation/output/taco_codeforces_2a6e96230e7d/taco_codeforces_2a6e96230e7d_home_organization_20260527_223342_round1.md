# 收纳调整最优化

> 生成任务：`taco_codeforces_2a6e96230e7d_inv` / theme `home_organization`

## 题目描述

小明有一个智能收纳柜，柜子的每个格子可以用二维坐标 (x, y) 表示。他需要将一个物品从初始格子 (x1, y1) 移动到目标格子 (x2, y2)。他可以执行以下两种操作任意多次、任意顺序：
1. 顺时针旋转90度：将物品的坐标 (x, y) 变成 (y, -x)。
2. 沿固定方向移动：将物品的坐标加上一个固定的向量 (dx, dy)，即 (x+dx, y+dy)。

有时给定的初始位置、目标位置和固定移动向量无法通过上述操作实现移动。不过，小明可以事先花费一些时间微调坐标：对于初始位置、目标位置和固定移动向量的每一个坐标，他都可以每次调整1个单位（增加1或减少1），花费1分钟。总花费是所有坐标调整量的绝对值之和。

请你帮助小明计算最少需要花费多少分钟，使得调整后可以通过操作将物品从调整后的初始位置移动到调整后的目标位置。

## 输入格式

输入包含三行，每行两个整数。第一行为初始位置坐标 x1 y1，第二行为目标位置坐标 x2 y2，第三行为固定移动向量 dx dy。所有坐标值的绝对值不超过 10^8。

## 输出格式

输出一个非负整数，表示最少需要的总调整时间（分钟）。

## 数据范围与限制

- 时间限制：2.0 秒
- 空间限制：256.0 MB

## 样例

### 样例 1

**输入**

```text
0 0
1 1
0 1
```

**输出**

```text
0
```

**说明**

初始位置 (0,0)，目标位置 (1,1)，固定移动向量 (0,1)。此时无需调整即可通过操作到达，例如：先不旋转，直接加一次 (0,1) 得到 (0,1)，再顺时针旋转90度变为 (1,0)，再加一次 (0,1) 得到 (1,1)。（亦可采用其他操作序列）总花费为0。

### 样例 2

**输入**

```text
0 0
1 1
2 2
```

**输出**

```text
2
```

**说明**

将固定移动向量从 (2,2) 调整为 (1,1)，x坐标调整1，y坐标调整1，花费2；初始和目标不变。调整后从 (0,0) 出发，可通过旋转和移动到达 (1,1)。可以证明没有总花费更小的调整方案。

### 样例 3

**输入**

```text
1 0
2 0
0 0
```

**输出**

```text
1
```

**说明**

固定移动向量为 (0,0) 时只能依赖旋转。初始 (1,0) 旋转后只能到达 (1,0)、(0,-1)、(-1,0)、(0,1)，均不等于 (2,0)。一种最优调整是将初始位置的 x 坐标由 1 调整为 2（花费1），目标及其他坐标不变，调整后初始位置等于目标，无需操作即完成移动。
