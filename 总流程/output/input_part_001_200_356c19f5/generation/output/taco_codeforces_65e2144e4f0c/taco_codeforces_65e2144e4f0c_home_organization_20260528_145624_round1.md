# 收纳柜的改造

> 生成任务：`home_org_inverse_1` / theme `home_organization`

## 题目描述

小明的家里有一个巨大的收纳柜，柜子由 n 个格子组成，格子之间通过 n−1 条通道连接，任意两个格子都可以互相到达，因此整个通道结构形成一棵树。小明很喜欢玩捉迷藏，他每次都从 1 号格子出发，目标是到达一个只连有一条通道的尽头格子（1 号格子本身不算）。

为了阻止小明，家长们在某些格子上放置了标签。所有标签的位置互不相同，并且不会放在 1 号格子。游戏开始时，小明和所有标签同时行动。每单位时间，每位参与者可以选择沿着一条通道移动到相邻格子，也可以留在原地。如果某个标签和小明在某一时刻出现在同一格子或者同一条通道上（包括迎面相遇或擦肩而过），则标签成功抓住了小明。

家长们希望用最少的标签来保证一定能抓住小明。也就是说，对于给定的标签集合，他们想知道：最少需要保留其中的几个标签，才能无论小明怎么走，都必然在到达尽头格子之前被抓住？如果即使保留全部标签，小明仍然有办法获胜，则记这个最少数量为 −1。

现在，你已经知道所有标签的初始位置，还知道一个目标值 K（K 可以是 −1，或者一个正整数）。你可以对柜子的通道进行一次“整理”：每次整理时，选择一条当前存在的通道并将其封住，同时在另一对目前没有直接相连的格子之间开辟一条新的通道。整理完毕后，整个柜子的通道结构必须仍然是一棵树（即没有环且所有格子连通）。

你的任务是：通过若干次这样的整理，使得整理后，所需的最少标签数量恰好等于 K。你需要求出达到这一目标所需的最小整理次数。如果无论怎样整理都无法满足要求，则输出 −1。

## 输入格式

第一行一个整数 t (1≤t≤10^4)，表示测试数据组数。
接下来是 t 组测试数据，每组数据的格式如下：
第一行两个整数 n,m (2≤n≤2⋅10^5, 1≤m<n)，分别表示格子数和标签数。
第二行 m 个互不相同的整数 x1,x2,…,xm (2≤xi≤n)，表示标签所在的格子编号。
第三行一个整数 K (−1≤K≤m)，表示目标最少标签数。若 K=−1，表示希望小明总能获胜；否则 K 是一个非负整数，且保证 0≤K≤m，但注意 K=0 在实际中不可能达到，因为至少需要一个标签才能保证抓住小明。
接下来 n−1 行，每行两个整数 u,v (1≤u,v≤n)，表示一条通道连接格 u 和格 v。保证给出的图是一棵树。

保证所有测试数据的 n 之和不超过 2⋅10^5。

## 输出格式

对每组测试数据，输出一行一个整数，表示所需的最少整理次数。如果无法达到目标，输出 −1。

## 数据范围与限制

- 时间限制：2 秒
- 空间限制：256 MB
- 1 ≤ t ≤ 10^4
- 2 ≤ n ≤ 2⋅10^5，1 ≤ m < n
- 1 ≤ xi ≤ n 且所有的 xi 互不相同
- −1 ≤ K ≤ m
- 输入保证图是一棵树
- 所有测试数据的 n 之和不超过 2⋅10^5

## 样例

### 样例 1

**输入**

```text
1
4 2
2 3
2
1 2
2 3
3 4
```

**输出**

```text
1
```

**说明**

初始树中，小明从 1 出发，第一步只能走到 2。标签在 2 和 3。若只保留标签 2，小明走到 2 时会被抓住；若只保留标签 3，标签 3 也可以从 3 移动到 2 抓住小明（根据同时移动规则）。因此只需要 1 个标签即可保证抓住小明。目标 K=2 要求最少标签数为 2。
进行一次整理：封住通道 (2,3)，同时开辟通道 (1,3)。新树为 1−2, 1−3, 3−4。此时小明从 1 出发可以选择走向 2 或 3。若只有标签 2，小明可以走 3→4 到达尽头格子 4 而获胜；若只有标签 3，小明可以走 2 到达尽头格子 2 而获胜。因此必须同时保留标签 2 和标签 3 才能保证抓住小明，最少标签数为 2，恰好满足目标。故最少整理次数为 1。

### 样例 2

**输入**

```text
1
4 1
2
-1
1 2
1 3
3 4
```

**输出**

```text
0
```

**说明**

初始树中，小明从 1 出发，可以走 1→3→4 到达尽头格子 4，而唯一的标签在 2。标签从 2 移动到 3 或 4 的速度无法快于小明，小明总是能获胜。因此即使保留所有标签也无法抓住小明，最少标签数为 −1，恰好等于目标 K=−1，无需整理。

### 样例 3

**输入**

```text
1
3 1
2
2
1 2
2 3
```

**输出**

```text
-1
```

**说明**

只有一个标签，而目标 K=2 要求最少需要 2 个标签。由于整理不能增加标签数量，不可能达到目标，故输出 −1。

## 说明

每次整理操作定义为：选择一条当前存在的通道并删除，同时选择一对当前没有直接通道的格子并建立新通道，操作后整个图必须仍是一棵树。如果目标 K 大于标签数 m，显然不可能实现，此时应输出 −1。当 K=−1 时，表示希望小明总能获胜，即任何标签子集都不能保证必定抓住小明。对于 K 的其他取值，保证 K 不超过 m。
