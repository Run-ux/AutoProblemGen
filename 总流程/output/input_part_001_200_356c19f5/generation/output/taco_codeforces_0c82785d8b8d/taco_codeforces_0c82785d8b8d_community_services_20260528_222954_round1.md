# 社区服务小组的优选

> 生成任务：`taco_codeforces_0c82785d8b8d_canonical_witness` / theme `community_services`

## 题目描述

在一个规划整齐的社区中，有 n 户居民，每户都位于平面上一个坐标为偶数的点 (x, y) 上。社区管理员希望挑选一个由三户居民组成的服务小组，负责向社区内的整点驿站分发通知。
一个三人小组是“有效的”，当且仅当他们位置所构成的三角形内部包含奇数个整点驿站（整点指的是横纵坐标均为整数的位置）。由于所有住户的坐标均为偶数，三角形的面积自动为整数，因此有效条件等价于三角形内部整点个数为奇数。
在所有有效小组中，管理员希望选取“最优先”的一个。优先顺序定义如下：对于任意一个小组，首先将三位成员的坐标按照字典序升序排列（先按 x 坐标升序，若 x 相同则按 y 坐标升序），得到一个有序三元组；然后比较不同小组的有序三元组，字典序最小的小组具有最高优先级。数据保证至少存在一个有效小组，且所求的最小字典序小组是唯一的。
你的任务是找出这个最优小组，并输出三位成员的编号（编号从 1 开始，按输入顺序）。

## 输入格式

第一行包含一个整数 n (3 ≤ n ≤ 6000)，表示住户的数量。
接下来的 n 行，每行包含两个偶数 x 和 y (0 ≤ x, y ≤ 10^7)，表示一位住户的坐标。所有住户的坐标互不相同，且任意三点不共线。

## 输出格式

输出一行，包含三个整数，用空格分隔，表示所选住户的编号。编号可以以任意顺序输出。

## 数据范围与限制

- 3 ≤ n ≤ 6000
- 0 ≤ x, y ≤ 10^7，且 x 和 y 均为偶数
- 所有住户坐标互不相同
- 不存在三点共线
- 保证至少存在一个有效服务小组
- 时间限制：2 秒
- 空间限制：256 MB

## 样例

### 样例 1

**输入**

```text
3
0 0
2 0
0 4
```

**输出**

```text
1 2 3
```

**说明**

只有一个三角形，由住户 1、2、3 构成。该三角形内部整点个数为奇数（因为住户 1 (0,0) 和住户 3 (0,4) 在模 4 意义下同类），因此有效。其按坐标排序后的有序三元组为 ((0,0),(0,4),(2,0))，显然字典序最小。

### 样例 2

**输入**

```text
5
0 0
2 16
30 14
4 6
2 10
```

**输出**

```text
1 5 3
```

**说明**

共有三个有效小组：
1) 住户 1 (0,0)、5 (2,10)、3 (30,14)，排序后为 ((0,0),(2,10),(30,14))
2) 住户 2 (2,16)、5 (2,10)、3 (30,14)，排序后为 ((2,10),(2,16),(30,14))
3) 住户 4 (4,6)、5 (2,10)、3 (30,14)，排序后为 ((2,10),(4,6),(30,14))
比较有序三元组，第一个小组以 (0,0) 开头，字典序最小。因此选择住户 1、5、3。

## 说明

字典序比较的对象是小组内三个住户坐标按 (x, y) 升序排列得到的有序三元组。对于两个有序三元组 A 和 B，A 的字典序更小当且仅当存在一个位置 k (1 ≤ k ≤ 3)，使得 A 和 B 在前 k-1 个分量上相等，而 A 的第 k 个分量的 x 坐标更小，或者 x 相同时 y 坐标更小。
