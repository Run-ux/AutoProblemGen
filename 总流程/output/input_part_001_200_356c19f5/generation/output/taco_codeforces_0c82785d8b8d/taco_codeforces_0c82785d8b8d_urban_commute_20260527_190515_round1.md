# 最少站点迁移

> 生成任务：`inverse_interesting_commute_zone` / theme `urban_commute`

## 题目描述

城市公交系统中有 $n$ 个站点，每个站点落在平面上，坐标均为偶数。所有站点位置互不相同，且不存在任意三个站点共线。
城市里有无穷多乘客，每个整数坐标点恰好有一名乘客。
任意三个不同的站点可以构成一个通勤区域（三角形区域）。如果一个通勤区域满足：
- 内部（严格包围）的乘客数量为奇数；
- 区域面积为整数；
则称该通勤区域为“有趣的通勤区域”。

现在，公交公司希望调整部分站点的位置，使得调整后有趣的通勤区域总数恰好等于给定的目标值 $T$。每次调整可以选定一个站点，将其坐标修改为一个新的偶数坐标。调整过程中必须始终保持：
- 所有站点坐标互不相同；
- 任意三个站点不共线。

你需要计算最少需要调整多少个站点（即最少移动次数）才能达成目标。如果无论怎样调整都无法恰好得到 $T$ 个有趣的通勤区域，则输出 $-1$。

## 输入格式

第一行包含两个整数 $n$ 和 $T$（$3 \le n \le 6000$，$0 \le T \le \binom{n}{3}$）。
接下来 $n$ 行，每行包含两个偶数整数 $x_i$ 和 $y_i$（$0 \le x_i, y_i \le 10^7$，均为偶数），表示初始时一个站点的坐标。所有站点坐标互不相同，且保证初始时无三点共线。

## 输出格式

输出一行一个整数 $M$：最少需要的站点调整次数。如果不可能达到目标，输出 $-1$。

## 数据范围与限制

- $3 \le n \le 6000$
- $0 \le T \le \binom{n}{3}$
- $0 \le x_i, y_i \le 10^7$ 且为偶数
- 初始时所有站点坐标互不相同，且无三点共线
- 每次调整后仍需保持坐标互异且无三点共线
- 时间限制：6 秒
- 空间限制：256 MB

## 样例

### 样例 1

**输入**

```text
3 1
0 0
2 0
0 4
```

**输出**

```text
0
```

**说明**

三个站点坐标分别为 (0,0)、(2,0)、(0,4)。此时有趣的通勤区域数正好为 1，已经等于目标 $T=1$，因此不需要移动任何站点。

### 样例 2

**输入**

```text
4 1
0 0
0 2
2 0
2 2
```

**输出**

```text
-1
```

**说明**

四个站点各属于一个不同的模 4 类别：(0,0)、(0,2)、(2,0)、(2,2)。当前有趣的通勤区域数为 0。可以验证，当 $n=4$ 时可能的有趣区域数只能是 0、2 或 4，无法变为 1，因此输出 -1。

### 样例 3

**输入**

```text
3 1
0 0
0 2
2 0
```

**输出**

```text
1
```

**说明**

三个站点初始类别为 (0,0)、(0,2)、(2,0)，有趣区域数为 0。通过一次调整，将站点 (2,0) 移动到 (4,0)（类别变为 (0,0)），调整后站点为 (0,0)、(0,2)、(4,0)，类别计数变为两个 (0,0) 和一个 (0,2)，有趣区域数变为 1，达到目标。

## 说明

站点的模 4 余数类别（即坐标对 4 取余）决定了通勤区域的有趣性。若要改变有趣区域的总数，必须改变各类别站点的个数。可以证明，只要目标类别分布能产生 $T$，且总站点数不变，就一定存在一个合法的坐标修改序列（每次修改保持互异且无三点共线）达到该分布。
