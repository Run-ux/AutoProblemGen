# 通勤三角区

> 生成任务：`urban_commute_certificate_odd_inside` / theme `urban_commute`

## 题目描述

城市公交系统中规划了 n 个站点，每个站点位于平面上的一个坐标 (x, y)。出于调度效率的考虑，所有站点的 x 坐标和 y 坐标均为偶数。任意两个站点位置不同，且不存在三个站点位于同一条直线上。

现在需要选择一个“通勤三角区”：选取三个不同的站点，将它们连成一个三角形。如果一个三角形满足以下两个条件，则称其为“合格的”：
1. 该三角形的面积为整数；
2. 严格位于三角形内部的整数坐标点（可以视为潜在乘客的落脚点）的数量为奇数。

你的任务是：如果存在至少一个合格的三角形，则输出 YES 并指出一个具体的合格三角形（给出三个站点的编号）；如果不存在任何合格的三角形，则输出 NO 并提供一个“不存在性证明”——将站点按 (x mod 4, y mod 4) 分类后的四个类别计数，用于直接说明不可能构成合格三角形。

## 输入格式

第一行包含一个整数 n (3 ≤ n ≤ 6000)，表示站点数量。
接下来 n 行，每行包含两个整数 x, y (0 ≤ x, y ≤ 10^7，且 x 和 y 均为偶数)，描述一个站点的坐标。
输入保证：所有站点坐标互不相同；不存在任意三点共线的情况。

## 输出格式

如果存在至少一个合格的三角形，则输出两行：
第一行输出字符串 "YES"（不含引号）；
第二行输出三个用空格分隔的整数 i1 i2 i3，表示所选站点的编号（站点按照输入顺序从 1 开始编号）。任意一个满足条件的三角形均可被接受。

如果不存在任何合格的三角形，则输出两行：
第一行输出字符串 "NO"（不含引号）；
第二行输出四个用空格分隔的非负整数 c00 c02 c20 c22，分别表示满足 (x mod 4, y mod 4) 等于 (0,0), (0,2), (2,0), (2,2) 的站点数量。这四个整数必须与输入的实际分类一致，并且为了作为不存在性的有效证明，必须满足：c00, c02, c20, c22 中的每个数值都不超过 1（即 max(c00, c02, c20, c22) ≤ 1）且 c00 + c02 + c20 + c22 = n。

## 数据范围与限制

- 时间限制：2秒
- 空间限制：256MB
- 3 ≤ n ≤ 6000
- 0 ≤ x, y ≤ 10^7，且 x 和 y 均为偶数
- 所有站点坐标互不相同
- 不存在三点共线的情况

## 样例

### 样例 1

**输入**

```text
3
0 0
2 0
0 4
```

**输出**

```text
YES
1 2 3
```

**说明**

三个站点 (0,0), (2,0), (0,4) 构成的三角形面积为 4（整数），且其内部恰好有 1 个整数坐标点（奇数），因此是一个合格的三角形。站点编号 1、2、3 对应输入顺序。

### 样例 2

**输入**

```text
4
0 0
0 2
2 0
2 2
```

**输出**

```text
NO
1 1 1 1
```

**说明**

四个站点的模 4 分类分别为 (0,0), (0,2), (2,0), (2,2)，因此 c00=1, c02=1, c20=1, c22=1。每个类别计数都不超过 1，且总和为 4，满足证书条件，说明无法构成任何合格的三角形。

## 说明

当存在解时，任意一个合法的三角形均可接受，不要求输出所有解。
对于 NO 输出的证书，判题程序会检查 c00, c02, c20, c22 是否与实际分类一致，以及是否满足 max(c) ≤ 1 且和等于 n；若不满足，则判定为错误。
注意：由于所有坐标均为偶数，三角形内部整数点数量的奇偶性完全由所选三个顶点的模 4 分类决定，上述证书条件因此成为不存在性的可靠判据。
