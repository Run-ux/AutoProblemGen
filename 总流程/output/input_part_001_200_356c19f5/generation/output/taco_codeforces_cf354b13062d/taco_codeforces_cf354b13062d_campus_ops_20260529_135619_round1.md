# 实验室的标准化调整

> 生成任务：`taco_cf_354b13062d_count` / theme `campus_ops`

## 题目描述

小明所在的大学有一条长长的走廊，走廊上依次排列着 n 间实验室，编号为 1,2,…,n，它们的顺序固定不变。第 i 间实验室里原本存放了一些标准件，数量为 a_i。

为了统一管理，学校希望有一天每间实验室恰好都只保留 1 件标准件。每天可以进行一次调整：挑选两间相邻的实验室（即编号相差 1 的两间）i 和 i+1，然后选择其中一间，将其标准件数量修改为这两间实验室标准件数量的最大公约数。注意这里“相邻”严格由实验室的编号顺序决定，不能跨编号选择。

如果无论如何都无法让所有实验室都变为 1，则认为无法达成目标。

现在，教务部想知道：在达成目标的前提下，要使得调整的总天数最少，那么有多少种不同的调整方案？这里的“调整方案”指的是恰好达到最少天数的一系列操作序列。两个方案不同当且仅当在某一天，所选的相邻实验室对 (i, i+1) 不同，或者虽然选了对相同，但被替换标准件数量的实验室不同（即替换了 i 或 i+1）。

由于可能的方案数很大，你只需要输出方案数对 1,000,000,007 取模后的结果。

可以观察到，整个调整过程可以划分为两个阶段：
- 阶段一：如果初始时没有任何实验室的数量为 1，则需要先通过若干次操作产生第一个 1；
- 阶段二：一旦数组中出现至少一个 1，之后每一次操作都可以将一个非 1 的相邻位置变为 1，直到所有位置都是 1。
这两个阶段的操作序列互不重叠，且所有达到最少天数的方案都可以唯一地按照「第一个 1 是在哪一步被创造出来的」进行划分，因此总的方案数等于所有可能的第一阶段方案数乘上对应状态下的第二阶段方案数之和。

## 输入格式

第一行包含一个整数 n (1 ≤ n ≤ 2000)，表示实验室的数量。
第二行包含 n 个由空格分隔的整数 a_1, a_2, …, a_n (1 ≤ a_i ≤ 10^9)，依次表示各间实验室的标准件初始数量。

## 输出格式

如果无法达到目标，输出一行 −1；否则，输出一个整数，表示恰好使用最少天数的不同调整方案数对 1,000,000,007 取模的结果。

## 数据范围与限制

- 1 ≤ n ≤ 2000
- 1 ≤ a_i ≤ 10^9
- 时间限制：2 秒
- 空间限制：256 MB

## 样例

### 样例 1

**输入**

```text
3
2 2 2
```

**输出**

```text
-1
```

**说明**

所有数的最大公约数是 2，无论如何操作都不可能产生 1，因此无法达成目标。

### 样例 2

**输入**

```text
2
2 3
```

**输出**

```text
2
```

**说明**

最少需要 2 天。第 1 天必须在相邻的 2 和 3 之间产生一个 1，有两种方式：将第 1 间实验室的 2 替换为 1，或者将第 2 间实验室的 3 替换为 1；第 2 天再用剩下的一次操作将另一间实验室变为 1。所以共有 2 种方案。

### 样例 3

**输入**

```text
4
1 2 1 3
```

**输出**

```text
2
```

**说明**

最少需要 2 天。因为已有两个 1，只需将第 2 间实验室的 2 和第 4 间实验室的 3 变为 1。这两步的先后顺序有两种（先变第 2 间或先变第 4 间），每种顺序都是合法的，因此共 2 种方案。

### 样例 4

**输入**

```text
3
2 2 3
```

**输出**

```text
3
```

**说明**

最少需要 3 天。初始没有 1，必须先通过操作产生一个 1。唯一的产生方式是选择相邻对 (2,3)（即第 2 间和第 3 间实验室），将其中的一个替换为 1。这一步有两种可能：替换第 2 间得到 [2,1,3]，或替换第 3 间得到 [2,2,1]。
- 若得到 [2,1,3]，接下来需要用两步将剩余的两个非 1 位置变为 1。这里后续的第二步有 2 种选择（将第 1 间的 2 变 1 或将第 3 间的 3 变 1），每种选择对应的第三步唯一，因此有 2 种后续方案。
- 若得到 [2,2,1]，后续只有一种方式：先将第 2 间的 2 变为 1，再将第 1 间的 2 变为 1。
总的方案数为 1×2 + 1×1 = 3。

## 说明

方案数需要对 1,000,000,007 取模。若初始整个数组的最大公约数大于 1，则必然无解，请输出 −1。两个方案不同当且仅当存在某一天，选择的相邻实验室对 (i,i+1) 不同，或者被替换标准件数量的实验室不同（即替换了 i 还是 i+1）。在阶段划分中，第一阶段产生第一个 1 的子数组必须连续且长度尽可能短；第二阶段的操作顺序自由度由组合数计算，并不唯一由原始最小长度决定。
