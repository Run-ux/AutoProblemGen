# 技能达标最优方案数

> 生成任务：`campus_gcd_counting_v1` / theme `campus_ops`

## 题目描述

校园编程社最近发起了一项全员达标活动：让每位成员的技能等级都变为 1，即入门水平。社长林小树想出了一种结对互助的方法，并制定了操作规则。

社团有 n 名成员排成一排，第 i 名成员的初始技能等级为 s_i。每次操作，你可以选择相邻的两名成员，计算他们当前技能等级的最大公约数（gcd），然后指定其中一人的技能等级直接变成这个公约数。注意，替换哪一名由你决定，每一次操作都会改变队列的状态。

目标是使所有成员的技能等级都变为 1。若初始无法达成（即所有 s_i 的 gcd 不为 1），输出 -1。否则，你需要求出在**使用最少操作次数**达成目标的前提下，一共有多少种不同的操作序列？

两条操作序列不同，当且仅当在某个步骤，你选择的相邻位置不同，或者虽然位置相同但你替换的成员不同。

可以证明，所有最优操作序列都可以唯一地分解为两个阶段：
- 生成阶段：选定一个长度最小的连续子数组，其元素的 gcd 为 1，通过恰好 len−1 次操作在该子数组内产生至少一个 1；
- 传播阶段：通过恰好 n−1 次操作，将已产生的 1 依次传播到其余所有位置。

不同最小子数组可能对应不同的生成方案，传播阶段的方案数由第一个 1 产生的位置决定。在统计总数时，需将每个可能的最小生成子数组对应的方案数相加，但要注意避免因子数组重叠而重复计数。（上述分解为自然结论，可直接使用。）

最终答案对 1,000,000,007 取模。

## 输入格式

第一行包含一个整数 n (1 ≤ n ≤ 2000)，表示成员的数量。
第二行包含 n 个空格分隔的整数 s_1, s_2, ..., s_n (1 ≤ s_i ≤ 10^9)，依次表示成员的初始技能等级。

## 输出格式

输出一个整数。如果无法使所有技能等级变为 1，输出 -1；否则输出方案数对 1,000,000,007 取模的结果。

## 数据范围与限制

- 时间限制：2 秒
- 空间限制：256 MB

## 样例

### 样例 1

**输入**

```text
5
2 2 3 4 6
```

**输出**

```text
20
```

**说明**

数组共有两个最短子数组 [2,3] 和 [3,4] 可使 gcd 为 1，最少操作次数为 (2-1)+(5-1)=5。对于每个子数组，生成阶段有 2 种方案产生第一个 1，传播阶段方案数分别为 C(4,1)=4 和 C(4,2)=6（依第一个 1 的位置而定）。两个子数组无重叠方案，总计 2×(4+6)=20。

### 样例 2

**输入**

```text
4
2 4 6 8
```

**输出**

```text
-1
```

**说明**

所有技能等级的 gcd 为 2，不可能产生 1。

### 样例 3

**输入**

```text
3
2 6 9
```

**输出**

```text
3
```

**说明**

整个数组 gcd 为 1，最短子数组长度为 3，最少操作数为 (3-1)+(3-1)=4。生成阶段有 3 种方案，传播阶段的方案组合后总数为 3。

### 样例 4

**输入**

```text
1
1
```

**输出**

```text
1
```

**说明**

已经达标，空操作序列是唯一的最优序列。

## 说明

本题中方案数可能很大，请务必对 1,000,000,007 取模后输出。统计时需确保每条最优操作序列被计数恰好一次，尤其当存在多个最短子数组时要注意它们的重叠关系，避免重复计数。
