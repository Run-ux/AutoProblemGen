# 教室检查方案计数

> 生成任务：`taco_cf_count_purification_sets` / theme `campus_ops`

## 题目描述

今年学校将进行一次全面的教室使用情况检查。共有 n 个班级和 n 个可用时间段（编号为 1 到 n）。
每个班级在每个时间段可能空闲（用 '.' 表示）或被其他活动占用（用 'E' 表示）。
为了尽量减少对正常教学的影响，学校希望通过恰好 n 次检查来完成全部覆盖（这是能够覆盖所有情况的必要最小次数）。
一次检查的方式是：选择一个空闲的格子 (班级 i, 时间段 j)，在那里设置一个检查点。该检查点会检查班级 i 在所有时间段的情况，同时也会检查所有班级在时间段 j 的情况。换句话说，对于任意班级 i' 和时间段 j'，只要 i' = i 或 j' = j，那么这个格子就会被这次检查覆盖到。
你需要挑出恰好 n 个空闲格子作为检查点，使得每一个 (班级, 时间段) 组合都被至少一个检查点覆盖。
注意，由于检查次数严格等于 n，任意一个合法的检查点集合中，要么每个班级都恰好作为一个检查点所在的班级（即每行恰好选一个格子）；要么每个时间段都恰好作为一个检查点所在的时间段（即每列恰好选一个格子）。如果你发现某行或某列完全没有空闲格子，则对应的覆盖方式将无法实现。
两个检查点集合如果包含完全相同的格子（与顺序无关），则视为相同的方案。
现在请你计算：是否存在这样的检查方案？如果存在，请输出最小检查次数（它必定是 n），并输出不同的最少检查点集合的个数。由于答案可能很大，你需要将个数对 998244353 取模后输出。
如果不存在任何可行的检查方案（即同时存在某行全为 'E' 且某列全为 'E'），请输出 -1。

## 输入格式

第一行包含一个整数 n (1 ≤ n ≤ 100)，表示班级/时间段的数量。
接下来 n 行，每行包含一个长度为 n 的字符串，由字符 '.' 和 'E' 组成，其中 '.' 表示空闲，'E' 表示被占用。第 i 行的第 j 个字符表示班级 i 在时间段 j 的占用情况。

## 输出格式

如果不存在可行的检查方案，输出一行一个整数 -1。
否则，输出一行两个整数：第一个整数为最小检查次数，即 n；第二个整数为满足要求的不同检查点集合数目对 998244353 取模的结果。

## 数据范围与限制

- 1 ≤ n ≤ 100
- 时间限制：2 秒
- 空间限制：256 MB

## 样例

### 样例 1

**输入**

```text
3
.E.
E.E
.E.
```

**输出**

```text
3 6
```

**说明**

矩阵大小为 3×3。最小检查次数为 3。
总方案数为 6：按班级选择的方式共有 2×1×2=4 种；按时间段选择的方式同样有 4 种；其中两种方案同时满足按班级和按时间段选择（即每行每列恰选一个点的完美匹配），被重复计算了一次，因此最终结果为 4+4-2=6。

### 样例 2

**输入**

```text
2
EE
..
```

**输出**

```text
2 1
```

**说明**

矩阵大小为 2×2。第 1 行全为 'E'，无法在该行选取检查点，因此只能按时间段选择：每列选一个点。第 1 列和第 2 列在第 2 行都是 '.'，只有一种选择：{(2,1), (2,2)}。按班级选择的方案数为 0，按时间段选择的方案数为 1×1=1，完美匹配数为 0，总方案数为 1。输出最小检查次数 2 和方案数 1。

## 说明

请注意方案集合是无序的，即只关心选择了哪些格子，不关心选择的顺序。
当某一行全为 'E' 且某一列全为 'E' 时，不存在可行的检查方案，此时输出 -1。
模数 998244353 是一个质数。
