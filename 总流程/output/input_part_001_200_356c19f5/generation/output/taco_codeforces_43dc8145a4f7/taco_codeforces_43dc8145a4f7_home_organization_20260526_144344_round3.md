# 家庭收纳方案计数

> 生成任务：`home_org_counting_01` / theme `home_organization`

## 题目描述

小丽是一位收纳师，她正在为一位客户规划一个大型衣柜。衣柜有 n 个柜子（行），每个柜子包含 8 个格子，从左到右编号 1 至 8。这些格子被划分为三个相邻组件：{1,2}、{3,4,5,6}、{7,8}。客户有 m 种不同的物品，第 i 种物品有 a_i 个，相同种类的物品视为一样。小丽需要将所有物品放入柜子的格子中，每个格子最多只能放一个物品。摆放时，必须遵守以下规则：在同一个相邻组件内的所有非空格子，必须放置相同种类的物品（不同组件之间可以放置不同种类）。

由于各个柜子之间没有额外的限制，我们可以分柜子来考虑。对于一个柜子，我们用一个分配向量 d = (d_1,...,d_m) 表示它需要放置各种物品的个数。称 d 是合法的，如果存在一种在该柜子 8 个格子中放置物品的具体方式，恰好使用 d_i 个第 i 种物品，并且满足组件内同种的规则。记 g(d) 为满足合法分配 d 的柜内放置方式数。

那么，一个完整的衣柜放置方案可以由以下方式得到：为每一个柜子选择一个合法的分配向量，要求所有柜子的分配向量之和等于 (a_1,...,a_m)，然后把各个柜子的方式数相乘，得到该分配向量组合对应的方案数。最后，把所有可能的合法分配向量组合的方案数相加，即为总的放置方案数。

现在小丽想知道总共有多少种不同的放置方案。由于答案可能很大，请输出模 10^9+7 后的结果。

## 输入格式

第一行包含两个整数 n 和 m（1 ≤ n ≤ 10000，1 ≤ m ≤ 100），分别表示柜子的数量和物品种类数。
第二行包含 m 个整数 a_1, a_2, ..., a_m（1 ≤ a_i ≤ 10000），表示每种物品的数量。保证所有物品总数不超过 8n。

## 输出格式

输出一个整数，表示方案数模 10^9+7 的值。

## 数据范围与限制

- 1 ≤ n ≤ 10^4
- 1 ≤ m ≤ 100
- 1 ≤ a_i ≤ 10^4
- ∑ a_i ≤ 8·n
- 时间限制：2 秒
- 空间限制：256 MB

## 样例

### 样例 1

**输入**

```text
1 2
4 4
```

**输出**

```text
2
```

**说明**

只有一个柜子，物品 A 和 B 各有 4 个，共需占用 8 个格子。柜子的三个相邻组件分别为 {1,2}、{3,4,5,6}、{7,8}。由于每个组件内必须放同一种物品，组件 {3,4,5,6} 有 4 个格子，恰好可以容纳一种物品的 4 个，而另外两个组件各自有 2 个格子。若将大组件分配给 A，则两个小组件必须分配给 B，这样就得到一种合法的分配向量 (4,4)，对应的柜内放置方式唯一（因为物品同种且组件内同种，交换组件内物品没有新方案）。同样，将大组件分配给 B。因此 g(4,4)=2，总方案数即为 2。

### 样例 2

**输入**

```text
1 1
5
```

**输出**

```text
56
```

**说明**

只有一种物品，共 5 个，柜子有 8 个格子，需要选择 5 个格子放置物品。因为只有一种物品，组件内同种规则自动满足。所以任何选出 5 个格子的方案都是合法的，不同的选择对应不同的最终格子占用状态。方案数为 C(8,5)=56。

### 样例 3

**输入**

```text
2 2
3 5
```

**输出**

```text
79872
```

**说明**

有两个柜子和两种物品，A 有 3 个，B 有 5 个。需要枚举第一个柜子的分配向量 (d1_A, d1_B)，第二个柜子对应 (3-d1_A, 5-d1_B)。对于每个可能的分配向量 d，g(d) 表示该柜子中满足规则的放置方式数。例如 g(0,5)=56，表示一个柜子中全放 B 且使用 5 个格子有 56 种方式；而 g(3,5)=0，因为无法在一个柜子中同时放下 3 个 A 和 5 个 B 且不违反组件内同种规则。通过计算所有合法分配向量组合的 g(d1) * g(d2) 并求和，得到总方案为 79872。

### 样例 4

**输入**

```text
1 1
1
```

**输出**

```text
8
```

**说明**

单个柜子中放置 1 个物品，共有 8 个格子，任意选择一个格子即可，方案数为 C(8,1)=8。

## 说明

模数为 10^9+7。同种物品不可区分，方案的区别仅由每个格子上放置的物品类型（或为空）决定。由于各个柜子独立，计数时采用分配向量分解，确保不重不漏。
