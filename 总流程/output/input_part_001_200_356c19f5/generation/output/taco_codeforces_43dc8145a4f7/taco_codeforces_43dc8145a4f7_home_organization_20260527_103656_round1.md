# 整理柜子

> 生成任务：`taco_codeforces_43dc8145a4f7_counting` / theme `home_organization`

## 题目描述

小明有一个巨大的柜子，柜子共有 $n$ 行，每行有 $8$ 个格子，从左到右编号为 $1$ 到 $8$。小明希望将 $k$ 种不同的物品放入柜子中，第 $i$ 种物品有 $a_i$ 个。为了便于查找，他希望在相邻的格子上放置的物品属于同一种类，这样他就可以贴上大标签。这里相邻的定义为：如果两个格子在同行且编号对属于 $\{\{1,2\},\{3,4\},\{4,5\},\{5,6\},\{7,8\}\}$，则它们是相邻的。每个格子最多可以放一个物品。所有物品都必须被放入柜子。

小明发现，每一行中有三个被相邻关系隔开的独立区域：格子 $\{1,2\}$（容量为 $2$）、格子 $\{3,4,5,6\}$（容量为 $4$）和格子 $\{7,8\}$（容量为 $2$）。由于区域内部的所有格子都彼此相邻（或通过相邻关系连通），所以每个区域内只能放置同一种类的物品。两个不同物品种类不能同时出现在同一个区域内。

为了统计不同的整理方案，小明规定了一种“块级表示”：对每一行的每一个区域，只需要记录放了哪种物品（如果没放则记为“空”）以及放了多少个。两个方案被认为是不同的，当且仅当存在至少一个区域，它所放置的物品种类或放入的数量不相同。区域内部具体占用了哪些格子不影响方案的区分——换句话说，对于给定种类和给定数量，我们总是假设物品占据了该区域内编号最小的那些格子，而不关心实际格子的选择。

现在小明想知道，一共有多少种满足条件的放置方案。由于答案可能很大，请输出方案数对 $998244353$ 取模的结果。

## 输入格式

第一行包含两个整数 $n$ 和 $k$ $(1 \le n \le 10000, 1 \le k \le 100)$，分别表示柜子的行数和物品的种类数。
第二行包含 $k$ 个整数 $a_1, a_2, \dots, a_k$ $(1 \le a_i \le 10000)$，其中 $a_i$ 表示第 $i$ 种物品的数量。保证 $a_1 + a_2 + \dots + a_k \le 8n$。

## 输出格式

输出一个整数，表示不同的整理方案数量对 $998244353$ 取模后的结果。如果不存在任何满足条件的方案，则输出 $0$。

## 数据范围与限制

- 时间限制：2 秒
- 空间限制：256 MB
- $1 \le n \le 10000$
- $1 \le k \le 100$
- $1 \le a_i \le 10000$
- $\sum a_i \le 8n$

## 样例

### 样例 1

**输入**

```text
1 1
1
```

**输出**

```text
3
```

**说明**

柜子有 1 行，只有 1 种物品，数量为 1。三个区域的容量分别为 2, 4, 2。因为物品数量为 1，可以放在任意一个区域，并占据该区域内的一个格子。由于区域内部格子对称，我们只按区域种类和数量区分方案，因此有三种不同的方案：在第一个区域放 1 个、在第二个区域放 1 个、或在第三个区域放 1 个。没有其他可能。

### 样例 2

**输入**

```text
1 2
1 1
```

**输出**

```text
6
```

**说明**

有两种物品，各 1 个。仍然只有一行。由于每个区域只能放同种物品，所以两种物品需要放在不同的区域（不能放在同一个区域，因为一个区域只能容纳一种物品）。从三个区域中选择两个区域分别放入两种物品，共有 $3 \times 2 = 6$ 种分配方式。每种方式中，两块区域各放置对应种类的 1 个物品。因此总方案数为 6。

### 样例 3

**输入**

```text
1 1
2
```

**输出**

```text
6
```

**说明**

一种物品，数量 2，放入一行。三个区域的容量为 2, 4, 2。我们只需要决定每个区域放多少个该物品（总和为 2），且不超过区域容量。可能的分法有：(2,0,0), (0,2,0), (0,0,2), (1,1,0), (1,0,1), (0,1,1)，共 6 种。所以输出 6。

## 说明

请使用 64 位整数类型进行运算，并在每一步取模。模数 $998244353$ 是一个质数，可以用于组合计数的取模。去重规则是基于区域级的物品种类和数量，而不是具体格子的占用情况。这保证了每种物理上可能的放置方式被唯一地表示为一个区域分配方案。如果没有满足条件的方案，输出 $0$。
