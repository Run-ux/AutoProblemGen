# 公交延误指标最小调整

> 生成任务：`urban_commute_klxor_inverse` / theme `urban_commute`

## 题目描述

城市中有 N 个公交站点，每个站点在一天结束时会被标记为两种状态之一：0（准点）或 1（延误）。这些状态按照固定的顺序排列，形成一个长度为 N 的二进制串 S。

交通管理中心定义了一种“延误指标”来评估整体运营情况：首先，取出所有长度为 K 的连续站点区段（即所有连续 K 个站点构成的子串），共 N-K+1 个；然后对这 N-K+1 个长度为 K 的串，按位独立进行异或运算，得到一个长度为 K 的二进制串 T。T 中 1 的个数就是该线路的延误指标。

现在，你被允许对某些站点的状态进行翻转（0 变 1 或 1 变 0）。每次翻转计为一次修改。你的任务是：通过最少的翻转次数，使得最终得到的延误指标恰好等于给定的目标值 P。如果无论怎么翻转都无法达到目标，输出 -1。

## 输入格式

第一行一个整数 T，表示测试用例的数量。接下来每个测试用例的描述如下：
每个测试用例占两行。
第一行包含三个整数 N, K, P，分别表示站点总数、区段长度、目标延误指标。
第二行包含一个长度为 N 的、仅由字符 '0' 和 '1' 构成的字符串 S，表示各个站点的初始状态。

## 输出格式

对于每个测试用例，输出一行一个整数，表示最少需要的翻转次数；若无法达到目标，则输出 -1。

## 数据范围与限制

- 1 ≤ T ≤ 10
- 1 ≤ K ≤ N ≤ 2 × 10^5
- 0 ≤ P ≤ K
- S 仅包含字符 '0' 和 '1'，且 |S| = N
- 时间限制：2 秒
- 空间限制：256 MB

## 样例

### 样例 1

**输入**

```text
1
4 2 2
1001
```

**输出**

```text
0
```

**说明**

N=4，K=2，P=2，初始 S=1001。计算所有长度为 2 的子串："10", "00", "01"，按位异或得 T="11"，延误指标为 2，正好等于目标 P，无需任何翻转，所以输出 0。

### 样例 2

**输入**

```text
1
4 2 0
1001
```

**输出**

```text
1
```

**说明**

N=4，K=2，P=0，初始 S=1001。初始延误指标为 2（同上例）。最少只需要翻转第 2 个站点（S[2] 从 0 变为 1），得到新序列 S=1101；此时子串变为 "11", "10", "01"，按位异或得 T="00"，延误指标变为 0。翻转次数为 1，无法更少，故输出 1。

### 样例 3

**输入**

```text
1
5 3 1
00000
```

**输出**

```text
1
```

**说明**

N=5，K=3，P=1，初始 S="00000"。所有长度为 3 的子串均为 "000"，异或得 T="000"，延误指标为 0。目标 P=1，最少只需翻转一个站点，例如将第 1 个站点翻转（0 变 1），则 S 变成 "10000"。此时子串为 "100", "000", "000"，按位异或得 T="100"，延误指标恰好为 1。翻转次数为 1，且无法更少，故输出 1。

## 说明

可以证明，在给定约束下，总是存在至少一种翻转方案使得延误指标达到目标 P，因此答案不会是 -1。但题目表述仍然保留 -1 的可能性以保持完整性。
请注意计算延误指标时，子串是按位独立异或，即 T 的第 j 位等于所有子串第 j 位的异或值。
