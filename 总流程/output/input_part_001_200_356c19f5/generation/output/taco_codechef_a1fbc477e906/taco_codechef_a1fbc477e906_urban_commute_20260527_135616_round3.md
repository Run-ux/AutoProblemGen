# 公交延误指标最小调整

> 生成任务：`urban_commute_klxor_inverse` / theme `urban_commute`

## 题目描述

在城市交通网络中，有 N 个公交站点依序排列。每天结束时，每个站点被标记为准点（0）或延误（1），形成长度为 N 的状态序列 S。

交通管理中心定义“延误指标”来评估整体线路：首先取所有长度为 K 的连续站点区段（即连续 K 个站点），共 N-K+1 个区段；对这些区段的状态序列按位进行异或运算，得到一个长度为 K 的二进制串 T，T 中 1 的个数就是该线路的延误指标。

现在你可以对任意站点的状态进行翻转（0 变 1，1 变 0），每次翻转计为一次操作。你的任务是：通过最少的翻转次数，使得最终延误指标恰好等于给定的目标值 P。如果无论如何翻转都无法达到 P，输出 -1。

## 输入格式

第一行一个整数 T，表示测试用例的数量。接下来每个测试用例的描述如下：
每个测试用例占两行。
第一行包含三个整数 N, K, P，分别表示站点总数、区段长度、目标延误指标。
第二行包含一个长度为 N 的、仅由字符 '0' 和 '1' 构成的字符串 S，表示各个站点的初始状态。

## 输出格式

对于每个测试用例，输出一行一个整数，表示最少需要的翻转次数；若无法达到目标，则输出 -1。

## 数据范围与限制

- 1 ≤ T ≤ 10
- 1 ≤ K ≤ N ≤ 2 × 10^5
- 0 ≤ P ≤ N - K + 1
- S 仅包含字符 '0' 和 '1'，且 |S| = N
- 时间限制：2 秒
- 空间限制：256 MB

## 样例

### 样例 1

**输入**

```text
1
4 2 2
1001
```

**输出**

```text
0
```

**说明**

初始 S=1001，长度为 2 的子串有 "10"、"00"、"01"，按位异或得 T="11"，延误指标为 2，等于目标，无需翻转。

### 样例 2

**输入**

```text
1
4 2 0
1001
```

**输出**

```text
1
```

**说明**

初始指标为 2，目标为 0。最少翻转第 2 位（0→1），S 变为 1101，子串为 "11"、"10"、"01"，异或得 T="00"，指标为 0。翻转次数为 1。

### 样例 3

**输入**

```text
1
3 2 3
111
```

**输出**

```text
-1
```

**说明**

K=2，延误指标的长度为 2，因此最多只能有 2 个 1，目标 P=3 永远无法达到，输出 -1。

## 说明

对于每个测试用例，延误指标定义为所有长度为 K 的连续子串按位异或后得到的长度为 K 的串 T 中 1 的个数。异或运算是按位独立进行的，即 T 的第 j 位等于所有子串第 j 位的异或值。如果无法通过翻转达到目标 P，输出 -1。
