# 活动计划的最小调整

> 生成任务：`inverse_klxor_minflips` / theme `campus_ops`

## 题目描述

校园文化节要到了，学校要在连续 N 天里安排社团活动。每天的状态用一个二进制位表示：0 表示当天没有社团占用教室，1 表示有占用。

为了评估活动的分布情况，学校将每连续 K 天作为一个观察窗口，共得到 N-K+1 个窗口。对于每个窗口，统计窗口内被占用天数的奇偶性（窗口内所有天的状态之和除以 2 的余数），从而得到一个长度为 N-K+1 的二进制序列，称为窗口特征序列。

现在，你已经知道各个社团提交的初步占用计划 S（一个长度为 N 的二进制串），以及学校期望的目标窗口特征序列 T（长度为 N-K+1 的二进制串）。

作为活动管理员，你拥有修改计划的权力：在任意一天，你可以将该天的状态翻转（把 0 改成 1，或把 1 改成 0）。注意：翻转第 i 天（1-indexed）会改变所有包含该天的窗口的特征值。具体来说，对于每一个窗口 j，如果 j ≤ i ≤ j+K-1，则该窗口的特征位会发生翻转（0 变 1，1 变 0）。换言之，一次翻转会影响所有从 max(1, i-K+1) 到 min(i, N-K+1) 的连续窗口。翻转操作的先后顺序不会影响最终的窗口特征序列，你只需要决定哪些天被翻转。

你的任务是：给定初始计划 S 和目标窗口特征序列 T，计算最少需要翻转多少天，使得修改后的计划计算出的窗口特征序列恰好等于 T。

## 输入格式

第一行一个整数 CaseNum，表示测试用例的数量。接下来每个测试用例按顺序包含三行：
- 第一行两个整数 N 和 K，分别表示总天数和观察窗口的长度。
- 第二行一个长度为 N 的字符串 S，仅包含字符 '0' 和 '1'，表示初始占用计划。
- 第三行一个长度为 N-K+1 的字符串 T，仅包含字符 '0' 和 '1'，表示目标窗口特征序列。

## 输出格式

对于每个测试用例，按输入顺序输出一行一个整数，表示达到目标所需的最少翻转天数。

## 数据范围与限制

- 1 ≤ CaseNum ≤ 10
- 1 ≤ K ≤ N ≤ 200000
- |S| = N，且 S 仅包含字符 '0' 和 '1'
- |T| = N-K+1，且 T 仅包含字符 '0' 和 '1'
- 输入保证至少存在一种翻转方案使窗口特征序列等于 T
- 时间限制：1 秒（C/C++）
- 空间限制：256 MB

## 样例

### 样例 1

**输入**

```text
1
4 2
1001
101
```

**输出**

```text
0
```

**说明**

初始计划 "1001"，K=2，计算出的窗口特征序列为：窗口1（第1-2天）1⊕0=1，窗口2（第2-3天）0⊕0=0，窗口3（第3-4天）0⊕1=1，得到 "101"，恰好等于目标 "101"，无需翻转，答案为 0。

### 样例 2

**输入**

```text
1
4 2
1001
000
```

**输出**

```text
2
```

**说明**

初始计划 "1001" 的窗口特征序列为 "101"，不等于目标 "000"。一种最优方案：翻转第2天和第3天，得到 "1111"，此时窗口1：1⊕1=0，窗口2：1⊕1=0，窗口3：1⊕1=0，序列为 "000"。可以证明仅需翻转2天，故答案为 2。

### 样例 3

**输入**

```text
1
5 5
10101
0
```

**输出**

```text
1
```

**说明**

N=5, K=5，只有一个窗口覆盖全部5天。初始计划 "10101" 的窗口特征为 1⊕0⊕1⊕0⊕1 = 1，即 "1"，不等于目标 "0"。只需翻转任意一天（例如第2天），原串变为 "11101"，则异或结果为 1⊕1⊕1⊕0⊕1 = 0，目标达成。最少翻转次数为 1。

### 样例 4

**输入**

```text
1
4 1
1100
0000
```

**输出**

```text
2
```

**说明**

K=1，每个窗口就是一天本身，窗口特征序列即为原串。目标 "0000" 要求所有天都不占用。当前 "1100" 有2个1，需翻转第1天和第2天，答案为 2。

## 说明

翻转操作具有连续性：翻转第 i 天会影响 max(1, i-K+1) 到 min(i, N-K+1) 之间的所有窗口特征位。可以证明，对于任意合法输入，最少翻转天数由初始计划与目标特征序列唯一确定，并且能够通过分析前缀差异严格求出下界。测试数据保证至少存在一种方案，且答案唯一。
