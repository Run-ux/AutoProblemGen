# 公交延误指标最小调整

> 生成任务：`urban_commute_klxor_inverse` / theme `urban_commute`

## 题目描述

城市公交线路上有 N 个站点依序排列，每天运营结束后每个站点会被标注为准点（0）或延误（1），形成一个长度为 N 的状态串 S。为了评估整体线路的延误状况，交通管理中心定义了“延误指标”：取出 S 中所有长度为 K 的连续区段（共 N−K+1 段），将这些区段的状态串按位进行异或运算，得到一个新的长度为 K 的二进制串 T，T 中 1 的个数即为延误指标。

现在，你可以任意选择某些站点，将其状态翻转（准点变延误，延误变准点）。每次翻转计为一次操作。你的目标是：进行若干次翻转后，使得延误指标恰好等于给定的目标值 P。请计算最少需要多少次翻转。

如果无论如何翻转都无法使延误指标等于 P，请输出 -1。

## 输入格式

第一行一个整数 T，表示测试用例的数量。接下来每个测试用例占两行。
第一行包含三个整数 N, K, P，分别表示站点总数、区段长度、目标延误指标。
第二行包含一个长度为 N 的、仅由字符 '0' 和 '1' 构成的字符串 S，表示各个站点的初始状态。

## 输出格式

对于每个测试用例，输出一行一个整数，表示最少需要的翻转次数；若无法达到目标，则输出 -1。

## 数据范围与限制

- 1 ≤ T ≤ 10
- 1 ≤ K ≤ N ≤ 200,000
- 0 ≤ P ≤ K
- S 仅包含字符 '0' 和 '1'，且 |S| = N
- 时间限制：2 秒
- 空间限制：256 MB

## 样例

### 样例 1

**输入**

```text
1
4 2 2
1001
```

**输出**

```text
0
```

**说明**

初始 S=1001，长度为 2 的连续区段有 “10”、“00”、“01”，按位异或得 T=“11”，延误指标为 2，等于目标 P=2，无需任何翻转。

### 样例 2

**输入**

```text
1
4 2 0
1001
```

**输出**

```text
1
```

**说明**

初始延误指标为 2，目标为 0。最少翻转方案是将第 2 位 0 翻转为 1，S 变为 1101。此时区段为 “11”、“10”、“01”，异或得 T=“00”，延误指标为 0。翻转次数为 1。

### 样例 3

**输入**

```text
1
3 2 1
000
```

**输出**

```text
1
```

**说明**

初始延误指标为 0，目标为 1。翻转第 1 位（0→1），S 变为 100。区段为 “10”、“00”，异或得 T=“10”，延误指标为 1。翻转次数为 1。

### 样例 4

**输入**

```text
1
3 3 3
000
```

**输出**

```text
3
```

**说明**

初始 S=000，K=3，只有一个区段即 S 本身，因此 T=“000”，延误指标为 0。目标 P=3。必须将所有 3 位翻转成 1，得到 S=111，T=“111”，延误指标为 3。至少需要 3 次翻转。

## 说明

延误指标定义为：所有长度为 K 的连续区段按位异或后得到的长度为 K 的串 T 中 1 的个数。按位异或即对应位分别进行异或运算（0⊕0=0, 0⊕1=1, 1⊕1=0）。
注意：目标延误指标 P 的有效上界为 K，因为 T 的长度为 K。数据保证对于所有合法输入，总是存在至少一种翻转方案使得延误指标等于目标 P，因此实际答案不会是 -1；但为保持输出格式的完整性，若程序出现意外判断，仍可输出 -1 作为占位符。
