# 活动计划的最小调整

> 生成任务：`inverse_klxor_minflips` / theme `campus_ops`

## 题目描述

校园文化节要到了，学校要在连续 N 天里安排社团活动。每天的状态用一个二进制位表示：0 表示当天没有社团占用教室，1 表示有占用。

为了评估活动的分布情况，学校将每连续 K 天作为一个观察窗口，共得到 N-K+1 个窗口。对于每个窗口，统计窗口内被占用天数的奇偶性（窗口内所有天的状态之和除以 2 的余数），从而得到一个长度为 N-K+1 的二进制序列，称为窗口特征序列。

现在，你已经知道各个社团提交的初步占用计划 S（一个长度为 N 的二进制串），以及学校期望的目标窗口特征序列 T（长度为 N-K+1 的二进制串）。

作为活动管理员，你拥有修改计划的权力：在任意一天，你可以将该天的状态翻转（把 0 改成 1，或把 1 改成 0）。每次翻转都会给该天的社团带来不便，因此你希望总的翻转天数尽可能少。

你的任务是：给定初始计划 S 和目标窗口特征序列 T，计算最少需要翻转多少天，使得修改后的计划计算出的窗口特征序列恰好等于 T。

## 输入格式

第一行一个整数 CaseNum，表示测试用例的数量。接下来每个测试用例包含三行：
- 第一行两个整数 N 和 K，分别表示总天数和观察窗口的长度。
- 第二行一个长度为 N 的字符串 S，仅包含字符 '0' 和 '1'，表示初始占用计划。
- 第三行一个长度为 N-K+1 的字符串 T，仅包含字符 '0' 和 '1'，表示目标窗口特征序列。

## 输出格式

对于每个测试用例，输出一行一个整数，表示达到目标所需的最少翻转天数。

## 数据范围与限制

- 1 ≤ CaseNum ≤ 10
- 1 ≤ K ≤ N ≤ 200000
- |S| = N，且 S 仅包含字符 '0' 和 '1'
- |T| = N-K+1，且 T 仅包含字符 '0' 和 '1'
- 输入保证至少存在一种翻转方案使窗口特征序列等于 T
- 时间限制：1 秒（C/C++）
- 空间限制：256 MB

## 样例

### 样例 1

**输入**

```text
1
4 2
1001
101
```

**输出**

```text
0
```

**说明**

初始占用计划为 "1001"，K=2，计算出的窗口特征序列为 "101"（窗口1：1⊕0=1，窗口2：0⊕0=0，窗口3：0⊕1=1），已经等于目标 "101"，因此不需要翻转，答案为 0。

### 样例 2

**输入**

```text
1
4 2
1001
000
```

**输出**

```text
2
```

**说明**

初始占用计划为 "1001"，计算出的窗口特征序列为 "101"，不等于目标 "000"。可以翻转第2天和第4天（将 "1001" 变为 "1100"），修改后的计划得到的窗口特征序列为 "000"。可以证明没有更少的翻转方案，故答案为 2。

## 说明

每个测试用例的答案唯一。翻转操作可以按任意顺序进行，只需计算最少翻转天数。
