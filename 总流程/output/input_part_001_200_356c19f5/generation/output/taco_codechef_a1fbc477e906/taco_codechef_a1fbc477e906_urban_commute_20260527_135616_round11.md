# 公交延误指标最小调整

> 生成任务：`urban_commute_klxor_inverse` / theme `urban_commute`

## 题目描述

城市公交线路上有 N 个站点依次编号 1 到 N。每天运营结束后，每个站点会被标记为准点（0）或延误（1），形成一个长度为 N 的状态串 S。

为了评估线路整体延误状况，交通管理中心定义了“延误指标”：取出所有长度为 K 的连续区段（一共 N−K+1 段），将这些区段的状态串按位异或，得到一个长度为 K 的二进制串 T。T 中 1 的个数即为延误指标。

现在你可以进行若干次调整：每次可以选择任意一个站点，将其状态翻转（0 变 1，1 变 0）。每次翻转计为一次操作。你的目标是：经过若干次翻转后，使得延误指标恰好等于给定的目标值 P。请计算最少需要的翻转次数。

如果无论如何翻转都无法使延误指标等于 P，请输出 −1。

## 输入格式

第一行一个整数 T (1 ≤ T ≤ 10)，表示测试用例的个数。
接下来每个测试用例占两行：
第一行包含三个整数 N、K、P。
第二行包含一个长度为 N 的、仅由字符 '0' 和 '1' 构成的字符串 S。

## 输出格式

对于每个测试用例，输出一行一个整数：最少翻转次数，或者若无法达到目标则输出 −1。

## 数据范围与限制

- 1 ≤ T ≤ 10
- 1 ≤ K ≤ N ≤ 200,000
- 0 ≤ P ≤ N − K + 1
- 所有测试用例的 N 之和不超过 200,000
- S 仅包含字符 '0' 和 '1'，且 |S| = N
- 时间限制：2 秒
- 空间限制：256 MB

## 样例

### 样例 1

**输入**

```text
1
4 2 2
1001
```

**输出**

```text
0
```

**说明**

初始 S = 1001，K = 2。所有长度为 2 的区段为 “10”、“00”、“01”，按位异或得到 T = “11”，延误指标为 2，等于目标 P = 2。不需要任何翻转。

### 样例 2

**输入**

```text
1
4 2 0
1001
```

**输出**

```text
1
```

**说明**

初始延误指标为 2，目标为 0。最少翻转方案：将第 2 位翻转为 1，S 变为 1101。此时区段为 “11”、“10”、“01”，异或得 T = “00”，延误指标为 0。翻转次数为 1。

### 样例 3

**输入**

```text
1
2 1 2
00
```

**输出**

```text
-1
```

**说明**

K = 1 时延误指标 T 的长度为 1，因此延误指标最大为 1，不可能达到 P = 2。本例输入在约束范围内，仍无法达成目标，故输出 −1。

### 样例 4

**输入**

```text
1
3 2 1
000
```

**输出**

```text
1
```

**说明**

初始延误指标为 0。翻转第 1 位，S 变为 100。区段 “10”、“00” 异或得 T = “10”，延误指标为 1。翻转次数为 1。

## 说明

延误指标的定义：所有长度为 K 的连续区段按位异或后得到的长度为 K 的串 T 中 1 的个数。按位异或即对应位分别进行异或运算（0⊕0=0, 0⊕1=1, 1⊕1=0）。
注意：目标 P 的合法输入范围已在约束中给出为 0 ≤ P ≤ N−K+1。延误指标 T 的长度为 K，因此其 popcount 天然不超过 K，当 P > K 时必然无解（如样例 3），但仍可能在约束范围内。若无法达到目标，必须输出 −1。
