# 社团教室分配难题

> 生成任务：`campus_tree_target_design` / theme `campus_ops`

## 题目描述

校园里的 n 个社团按照树形管理结构组织在一起，社团 1 是根社团，每个社团 i 有一个直接上级社团 p_i（p_i = 0 表示 i 是根社团）。每个社团 i 有一个初始的“顺位要求” c_i，它表示在最终分配教室编号时，社团 i 希望在自己管辖的子树（包括它自己）中，恰好有 c_i 个社团的教室编号比它更小。

现在学校需要为每个社团分配一个互不相同的正整数作为教室编号（所有编号均在 1 到 10^9 之间），以满足所有社团的顺位要求。但是，由于一些特殊原因，你希望指定的社团 u 最终分配到的教室编号恰好等于 v。

为了达成这个目标，你可以适当调整某些社团的顺位要求：把社团 i 的要求 c_i 修改为一个新的整数 c'_i，修改后仍需满足 0 ≤ c'_i ≤ size(subtree(i)) - 1（这里 size(subtree(i)) 表示以 i 为根的子树中的社团总数）。每修改一个单位，会产生 |c_i - c'_i| 的沟通成本。你的任务是找到最小的总沟通成本，并给出一组最终教室编号的分配方案，使得：
 • 对于每个社团 i，其子树中编号严格小于 a_i 的社团个数恰好等于修改后的 c'_i；
 • 社团 u 的教室编号恰好等于 v。

如果无论如何修改顺位要求，都无法满足上述两条（即使在允许范围内任意调整每个 c_i），则只需要输出一行 “NO”。

## 输入格式

第一行包含一个整数 n (1 ≤ n ≤ 2000)，表示社团的个数。

接下来的 n 行，第 i 行包含两个整数 p_i 和 c_i (0 ≤ p_i ≤ n，0 ≤ c_i ≤ n - 1)，分别表示社团 i 的上级社团编号（0 表示该社团为根社团）和它的初始顺位要求。输入保证描述了一棵包含 n 个社团的树，并且对每个社团 i 有 0 ≤ c_i ≤ size(subtree(i)) - 1。

最后一行包含两个整数 u 和 v (1 ≤ u ≤ n，1 ≤ v ≤ 10^9)，表示希望社团 u 最终分配到的教室编号等于 v。

## 输出格式

如果存在满足条件的方案，则在第一行输出一个整数，表示最小的总沟通成本（即 Σ|c_i - c'_i|）。然后在第二行输出 n 个整数 a_1, a_2, …, a_n，表示最终分配给每个社团的教室编号。这些编号必须互不相同，均在 [1, 10^9] 内，且满足所有修改后的顺位要求以及 a_u = v。

如果有多组最优方案，输出任意一组即可。

如果不存在任何合法的修改方案，则仅输出一行 “NO”（不含引号，大写）。

## 数据范围与限制

- 时间限制：1.0 秒
- 空间限制：256 MB
- 1 ≤ n ≤ 2000
- 0 ≤ p_i ≤ n，且输入保证构成一棵以某个 p_i = 0 的节点为根的树
- 0 ≤ c_i ≤ size(subtree(i)) - 1
- 1 ≤ u ≤ n
- 1 ≤ v ≤ 10^9
- 所有输入的 c_i 均为整数

## 样例

### 样例 1

**输入**

```text
3
0 0
1 0
1 0
3 1
```

**输出**

```text
2
2 3 1
```

**说明**

初始要求全部为 0。希望社团 3 获得编号 1。如果完全不修改，为了满足所有要求，教室编号必须满足 a_3 是子树 3 中最小的（c_3=0），同时 a_1 是整棵树中最小的（c_1=0），这会导致 a_1 < a_3，矛盾。因此必须修改要求。

最优方案是：将 c_1 从 0 改为 1（成本 1），将 c_2 从 0 改为 1（成本 1），c_3 保持 0。此时总成本为 2。对应的教室编号分配为 a = [2, 3, 1]：对社团 1，子树中比它小的只有社团 3，恰有 1 个；对社团 2，子树中比它小的只有社团 3，恰有 1 个；对社团 3，子树中无更小编号，恰有 0 个。且 a_3 = 1 满足要求。可以验证不存在总成本小于 2 的方案。

### 样例 2

**输入**

```text
4
0 0
1 0
1 0
3 0
4 1
```

**输出**

```text
2
2 4 3 1
```

**说明**

树结构：社团 1 是根，社团 2 和 3 直接受其管理，社团 4 受社团 3 管理。所有初始要求为 0。希望社团 4 获得编号 1。

最优调整：将 c_1 从 0 改为 1（成本 1），将 c_3 从 0 改为 1（成本 1），其余保持 0。此时教室编号可分配为 [2, 4, 3, 1]：对于社团 1，子树中比 2 小的只有社团 4（编号 1），c'_1 = 1；对于社团 3，子树中比 3 小的也只有社团 4，c'_3 = 1；社团 2 和 4 的子树中均无更小编号，满足 c'_2 = 0, c'_4 = 0。总成本为 2，且 a_4 = 1。

## 说明

数据保证至少存在一种合法的修改方案，因此一定可以输出最小成本和分配方案；实际测试数据中不会出现必须输出 “NO” 的情况。总成本在 n ≤ 2000 时不会超过 10^7，可直接使用 32 位有符号整数计算和输出，无需取模。教室编号必须互不相同，且均在 [1, 10^9] 范围内。如果存在多组最优方案，输出任意一组即可。
