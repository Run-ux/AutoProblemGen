# 最少的站点统计修正

> 生成任务：`taco_inverse_design_0100` / theme `urban_commute`

## 题目描述

小 Y 负责维护一个城市公交系统的线路规划。线路呈树形结构，共有 n 个站点，编号为 1 到 n。每个站点 i 有一个父站点 p_i（若 p_i=0 则为整条线路的起点），并且有一个尚未确定的整数编号 a_i，表示该站点的期望乘客吞吐量级别。
由于记录系统出现故障，目前只知道每个站点 i 的“子树内小于自身编号的站点个数”的初步统计值 c_i（即：在 i 及其所有后代站点中，编号严格小于 a_i 的站点数量）。同时，对于部分关键站点，系统还额外保留了一份非常可靠的记录，指明这些站点的 a_i 必须等于指定的 target_i（如果 target_i = 0，则表示没有强制要求）。
运营团队怀疑部分 c_i 可能统计有误，因此允许对任意站点的 c_i 进行调整，但调整后的新值 c_i' 必须满足 0 ≤ c_i' ≤ size_i−1，其中 size_i 是 i 的子树大小（包含 i 自身）。调整的次数越少，说明原先的记录越接近真实情况。
请你写一个程序，求出最小的调整次数 K，使得存在一组 1 到 10^9 之间的整数编号 a_i，同时满足：
· 对于每个站点 i，i 的子树中编号严格小于 a_i 的站点数量恰好等于 c_i'；
· 对于每个 target_i > 0 的站点 i，a_i 必须等于 target_i。
如果无论如何都无法满足，则输出 −1；否则输出 K，再输出 n 个整数表示调整后的 c_i'，最后输出 n 个整数表示一组满足条件的 a_i。可以证明，若有解，必有一组解将 a_i 限制在 1 到 n 之间。

## 输入格式

第一行一个整数 n (1≤n≤2000)，表示站点的个数。
接下来 n 行，每行三个整数 p_i, c_i, target_i (0≤p_i≤n, 0≤c_i≤n−1, 0≤target_i≤n)。p_i 是站点 i 的父站点，0 表示根站点；c_i 是初步记录的计数值；target_i 是指定的目标编号，若为 0 则表示无强制要求，否则保证所有出现的正整数 target_i 互不相同且不超过 n。

## 输出格式

如果不存在合法方案，输出一行 −1。
否则，第一行输出一个整数 K，表示最少需要调整的 c_i 的个数。
第二行输出 n 个整数，第 i 个数为调整后的 c_i'。
第三行输出 n 个整数，第 i 个数为最终分配的 a_i（1≤a_i≤10^9，可以证明若有解必有一组解在 1 到 n 之间，输出此范围内的值即可）。
若有多组最优方案，输出任意一组。

## 数据范围与限制

- 1 ≤ n ≤ 2000
- 0 ≤ p_i ≤ n
- 输入保证 p_i 描述一棵合法的树。
- 0 ≤ c_i ≤ n−1
- 0 ≤ target_i ≤ n，且所有 target_i>0 的值互不相同。
- 时间限制：1.0 秒
- 空间限制：256.0 MB

## 样例

### 样例 1

**输入**

```text
3
0 1 0
1 1 0
1 0 3
```

**输出**

```text
1
1 0 0
2 1 3
```

**说明**

站点 1 是根，站点 2 和 3 是它的子节点。原始 c 值为 [1,1,0]，目标要求 a_3=3。站点 2 的子树大小为 1，其 c_2=1 不合法（必须为 0），必须修改；其他 c 值可以保留。故最少调整次数 K=1。修改后 c'=[1,0,0]。分配 a=[2,1,3] 满足：站点 1 子树中小于 2 的有 1 个 (站点 2)；站点 2 子树没有小于 1 的；站点 3 子树没有小于 3 的；且 a_3=3。

### 样例 2

**输入**

```text
2
0 0 2
1 0 2
```

**输出**

```text
-1
```

**说明**

站点 1 是根，站点 2 是其子节点。要求 a_1=2, a_2=2，这是不可能的，因为 a_i 必须两两不同。因此无解。

### 样例 3

**输入**

```text
1
0 0 1
```

**输出**

```text
0
0
1
```

**说明**

只有一个站点，c_1=0 无需修改，目标 a_1=1 已满足，最小调整次数为 0。

## 说明

• 对于 target_i=0 的站点，a_i 没有额外限制，只需满足子树计数约束。
• 若有多种最优修改方案或多种合法 a_i，输出任意一组即可。
• 保证若有解，a_i 可以取遍 1 到 n 的排列（或子集），因此输出在 1 到 n 之间即确保正确。
• 调整 c_i 的次数定义为发生改变的 c_i 的个数，与具体修改的数值无关；一个站点即使 c_i 改了多次也只计一次。
• 请留意输出顺序：c_i' 和 a_i 均按站点编号 1..n 顺序输出。
