# 公交流量修复

> 生成任务：`urban_commute_station_flow` / theme `urban_commute`

## 题目描述

城市公交系统将总站视为根，运营线路呈树状向下延伸。系统记录了每个站点 i 的上级站点编号 p_i（p_i=0 表示该站点为总站），并统计了每个站点的乘客流量值 a_i（正整数）。然而在一次系统升级中，所有精确流量 a_i 全部丢失，只保留了一个统计值 c_i：在站点 i 负责的子线路（包含 i 及其所有下游站点）中，流量严格小于 a_i 的站点的个数。
你的任务是尝试根据这些残留信息恢复所有站点的流量值。如果给定的 c_i 数据本身存在矛盾，则无法恢复，你需要找出一个“冲突站点”作为证据——该站点自身的数据已经与线路结构产生了不可调和的冲突，并且在其管辖范围内，所有其他站点的数据都单独自洽。

## 输入格式

第一行包含一个整数 n (1 ≤ n ≤ 2000)，表示站点数量。
接下来 n 行，每行包含两个整数 p_i 和 c_i (0 ≤ p_i ≤ n, 0 ≤ c_i ≤ n-1)，分别表示站点 i 的上级站点编号（p_i=0 表示该站点为总站）和统计值 c_i。
输入保证所给数据构成一棵以总站为根的有根树，且总站唯一。

## 输出格式

如果存在一组合法的流量值，第一行输出 YES，第二行输出 n 个整数 a_1 a_2 ... a_n，表示各站点的流量，每个值须满足 1 ≤ a_i ≤ 10^9。若存在多组合法解，输出任意一组即可。
如果不存在合法的流量值，第一行输出 NO，第二行输出一个整数 v (1 ≤ v ≤ n)，表示一个冲突站点。该站点必须满足：c_v > (v 的子线路中的站点总数 - 1)，并且对于 v 的子线路中的任意其他站点 w（w ≠ v），均有 c_w ≤ (w 的子线路中的站点总数 - 1)。如果有多个这样的冲突站点，输出其中任意一个即可。

## 数据范围与限制

- 1 ≤ n ≤ 2000
- 0 ≤ p_i ≤ n
- 0 ≤ c_i ≤ n-1
- 输入保证构成以总站为根的有根树
- 时间限制：1.0 秒
- 空间限制：256 MB

## 样例

### 样例 1

**输入**

```text
3
0 1
1 0
1 0
```

**输出**

```text
YES
2 1 3
```

**说明**

总站为 1，其子站点为 2 和 3。可以设定流量分别为 a1=2, a2=1, a3=3。站点 1 的子线路包含 {1,2,3}，其中小于 a1=2 的只有站点 2（流量1），恰好 1 个，符合 c1=1；站点 2 和 3 的子线路均只有自身，c2=c3=0 成立。

### 样例 2

**输入**

```text
2
0 2
1 0
```

**输出**

```text
NO
1
```

**说明**

站点 1 为总站，其子线路包含自身和站点 2，共 2 个站点。c1=2 要求有 2 个流量更小的站点，这需要除站点 1 外有 2 个站点，但实际只有 1 个（站点 2），矛盾。站点 2 的子线路只有自身，c2=0 合理，符合冲突站点条件，因此输出站点 1。

## 说明

输出的流量值必须在 [1, 10^9] 范围内。如果有多个合法的流量方案，任意输出一种即可。冲突站点只需满足题面描述的条件，若有多个符合条件的冲突站点，输出其中任意一个即可。
