# 社团能力分配方案数

> 生成任务：`campus_med_count` / theme `campus_ops`

## 题目描述

某大学有 n 个社团，每个社团计划招募恰好 n 名新生，共有 n × n 名报名者。每个报名者有一个能力值，能力值为正整数。现在要将所有报名者分配给这 n 个社团，每个社团恰好得到 n 人。社团之间没有区别（即交换两个社团的所有成员不会产生新的分配方案）。

每个社团得到 n 名成员后，会按能力值从小到大排序，然后取第 ⌈(n+1)/2⌉ 小的能力值作为该社团的代表水平（即中位数）。例如，若 n=3，第 2 小的能力值为代表水平；若 n=4，也是第 2 小的能力值为代表水平。

你的任务是：计算有多少种不同的分配方案，同时满足以下两个条件：
1. 每个社团的代表水平至少为 L。
2. 所有社团的代表水平之和不大于 K。

两个分配方案被认为是不同的当且仅当存在某个社团其包含的报名者集合不同（报名者来自矩阵中的不同位置，即使能力值相同也被视为不同的人）。

由于答案可能很大，请输出方案数对 1,000,000,007 取模的结果。

## 输入格式

第一行包含一个整数 t，表示测试用例的数量。
接下来是 t 个测试用例，每个测试用例的格式如下：
第一行包含三个整数 n, L, K，分别表示社团个数（即每行人数）、中位数下限以及总和中位数上限。
接下来的 n 行，每行包含 n 个整数，表示所有报名者的能力值。能力值之间用空格分隔。

## 输出格式

对于每个测试用例，输出一行一个整数，表示满足条件的分配方案数对 1,000,000,007 取模的结果。如果不存在任何方案，则输出 0。

## 数据范围与限制

- 时间限制：2 秒
- 空间限制：256 MB
- 1 ≤ t ≤ 100
- 1 ≤ n ≤ 1000
- 所有测试用例的 n 之和不超过 1000
- 1 ≤ L ≤ 1,000,000,000
- 1 ≤ K ≤ 100,000,000,000,000
- 1 ≤ 每个能力值 ≤ 1,000,000,000
- 输入中的所有能力值均为整数

## 样例

### 样例 1

**输入**

```text
1
2 3 10
1 2
3 4
```

**输出**

```text
2
```

**说明**

n=2，L=3，K=10，报名者能力值为 {1,2,3,4}。中位数定义为第 2 小的数。满足条件的分配方案有两种：
- 社团1：{1,3} → 中位数 3；社团2：{2,4} → 中位数 4。中位和 7 ≤ K=10，且每个中位数 ≥ 3。
- 社团1：{1,4} → 中位数 4；社团2：{2,3} → 中位数 3。同样满足条件。
注意，{1,3}和{2,4}交换社团标签视为同一种方案，不重复计数。

### 样例 2

**输入**

```text
1
2 4 10
1 2
3 4
```

**输出**

```text
0
```

**说明**

仅将 L 提高到 4。此时两种合格方案中都有一个社团的中位数是 3（<4），因此没有方案满足条件，输出 0。

## 说明

- 模数为 1,000,000,007。
- 报名者被视为不同的个体：即使能力值相同，来自矩阵中的不同位置也视为不同的人。
- 中位数定义：将社团内成员按能力值从小到大排序后，第 ⌈(n+1)/2⌉ 个即为该社团代表水平。
- 社团之间没有顺序（即视为相同），交换两个社团的所有成员不算新方案。
- 输入数据较大，请使用 64 位整数类型（如 C++ 中的 long long）来存储能力值和总和。
- 若不存在任何方案，请输出 0。
