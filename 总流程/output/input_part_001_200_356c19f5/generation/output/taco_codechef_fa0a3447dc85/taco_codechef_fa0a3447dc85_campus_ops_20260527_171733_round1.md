# 社团展演编排

> 生成任务：`taco_codechef_fa0a3447dc85_canonical_witness` / theme `campus_ops`

## 题目描述

校园文化节中，有 n 个社团参与展演。每个社团需要表演 n 个节目，组织者提供了一个初始的 n×n 节目评分表 A，其中 A_{i,j} 表示第 i 个社团的第 j 个节目的精彩度评分。

你可以完全重新安排所有节目：将全部 n×n 个评分打乱，再任意分配到各个社团的各个位置，形成一个新的节目表。节目表必须包含和初始表完全相同的评分多重集（即每个评分出现的次数不变）。

对于最终的节目表，第 i 个社团的节目评分按非降序排列，将其中第 ⌈(n+1)/2⌉ 小的评分称为该社团的“代表分”，记作 m_i。例如，n=4 时，代表分是排序后的第 3 小评分。

整个节目表的“精彩度”定义为所有社团代表分的最小值：goodness = min_i m_i。
“编排代价”定义为所有社团代表分的总和：cost = Σ m_i。

你拥有一个预算上限 k，要求最终的编排代价不超过 k。

现在，你需要找到一个完整的节目编排，并且该编排必须严格满足以下由高到低优先级的多个目标：
1. 精彩度最大：在代价 ≤ k 的所有可行编排中，精彩度达到最大可能值 G*；
2. 代价最小：在精彩度等于 G* 的所有编排中，编排代价尽可能小；
3. 字典序最小：在满足前两个条件的所有编排中，将最终节目表按社团顺序（第一行到第 n 行）逐行拼接得到的评分序列，在字典序上最小。

如果不存在任何代价 ≤ k 的编排，直接输出 -1。

## 输入格式

第一行一个整数 T，表示测试用例个数。
对于每个测试用例：
第一行两个整数 n 和 k，表示社团数目（也是每个社团的节目数）和预算上限。
接下来 n 行，每行 n 个整数，描述初始节目评分表 A。

## 输出格式

对于每个测试用例，若存在合法编排，输出 n 行，每行 n 个整数，表示满足所有要求的最终节目表；若不存在，输出一行一个整数 -1。
多个测试用例的输出之间不应有空行。

## 数据范围与限制

- 时间限制：2 秒
- 空间限制：256 MB
- 1 ≤ T ≤ 100
- 1 ≤ n ≤ 1000
- 所有测试用例的 n 之和 ≤ 1000
- 1 ≤ k ≤ 10^14
- 1 ≤ A_{i,j} ≤ 10^9

## 样例

### 样例 1

**输入**

```text
1
2 100
5 1
2 8
```

**输出**

```text
1 5
2 8
```

**说明**

初始评分：1,2,5,8。最大可能精彩度为 5（需每行代表分 ≥5，可分配为 [1,5] 与 [2,8]，代表分分别为 5 和 8，精彩度=5）。此时最小代价为 5+8=13 ≤ 100，且该编排为字典序最小的方案。

### 样例 2

**输入**

```text
1
2 6
1 2
3 4
```

**输出**

```text
1 2
3 4
```

**说明**

初始评分：1,2,3,4。在代价 ≤6 的限制下，最大精彩度为 2。最小代价为 6，且只有本输出满足字典序最小。

### 样例 3

**输入**

```text
1
2 5
1 2
3 4
```

**输出**

```text
-1
```

**说明**

同上初始评分，但预算仅为 5。任何编排的代价至少为 6，故无解。

## 说明

- 中位数定义：对于包含 n 个元素的序列，将其按非降序排列后，第 ⌈(n+1)/2⌉ 个元素即为中位数。本题中的代表分即对应行节目的中位数。
- 字典序比较：将输出矩阵按行序依次拼接成一个长度为 n² 的序列，按从左到右的顺序比较，首次出现不同元素时，较小元素所属的序列字典序更小。
- 当选择输出 -1 时，仅输出一行一个 -1，不要额外输出空行或其它内容。
- 评分均为正整数。评测时会严格校验你的输出是否满足所有优先级约束，不满足则判错。
