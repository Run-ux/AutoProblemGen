# 社区需求均衡调整

> 生成任务：`taco_community_count` / theme `community_services`

## 题目描述

某街道共有 K 个社区，每个社区内有 N 户家庭。社区服务中心每天会记录每户家庭的服务需求指数，这些指数都是介于 L 到 R 之间的整数。由于近期各社区的需求总和差异较大，管理员决定对部分家庭的指数进行调整，以使得资源分配更加均衡。

每次调整时，管理员可以从所有社区的全部家庭中选择至多一户，将其需求指数修改为 [L, R] 内的任意整数值。管理员总共最多只能进行 B 次调整。

我们只关心最终每户家庭被调整成什么需求值，而不关心中间的调整顺序。如果至少有一户家庭的最终需求值不同，就视为不同的最终分配方案。

请你帮忙计算，在总共调整次数不超过 B 的前提下，有多少种可能的最终分配方案，能够使得所有社区的需求总和恰好相等。由于答案可能很大，请输出对 1,000,000,007 取模后的结果。

## 输入格式

第一行包含一个整数 T，表示测试数据的组数。

接下来依次给出每组测试数据。每组数据的格式如下：

第一行包含五个用空格隔开的整数 K, N, L, R, B，分别表示社区数量、每个社区的居民户数、需求值的下界、需求值的上界以及允许的最大调整次数。

接下来 K 行，每行包含 N 个用空格隔开的整数，按照社区编号顺序给出每户家庭的当前需求指数。

## 输出格式

对于每组测试数据，输出一行一个整数，表示符合要求的最终分配方案数对 1,000,000,007 取模的结果。

## 数据范围与限制

- 1 ≤ T ≤ 5
- 1 ≤ K ≤ 100,000
- 1 ≤ N ≤ 100,000
- 1 ≤ N × K ≤ 100,000
- 1 ≤ L ≤ R ≤ 1,000,000,000
- 1 ≤ B ≤ min(N × K, 1000)
- 所有测试数据的 N × K 总和不超过 100,000
- 时间限制：1 秒
- 空间限制：256 MB

## 样例

### 样例 1

**输入**

```text
1
2 1 1 10 1
5
3
```

**输出**

```text
2
```

**说明**

该测试数据包含 K=2 个社区，每个社区有 N=1 户家庭。需求值下界 L=1，上界 R=10。允许的最多调整次数 B=1。初始需求值分别为 5 和 3。

由于每个社区只有一户家庭，总和即等于该户的需求值。要让两个社区总和相等，最终两个值必须相同。

在最多 1 次调整的限制下，有两种可行的最终方案：
- 将第一个社区的值从 5 改为 3，得到最终值 3 和 3；
- 将第二个社区的值从 3 改为 5，得到最终值 5 和 5。
注意不能同时修改两户，因为 B=1。此外，修改为其他值（例如 4）会使两个值不同，不满足要求。
因此方案总数为 2。

### 样例 2

**输入**

```text
1
1 2 1 3 1
1 2
```

**输出**

```text
5
```

**说明**

该测试数据包含 K=1 个社区，社区内有 N=2 户家庭，需求值范围为 [1,3]，当前需求值为 1 和 2。允许最多调整 1 次。

因为只有一个社区，任何最终需求分配都能使“所有社区总和相等”自动成立。问题变为：在不超过 1 次调整的前提下，可以有多少种不同的最终需求值分配？

初始方案 (1,2) 可以不调整获得。
若调整第一户，可以将其改为 1, 2 或 3，得到方案 (1,2), (2,2), (3,2)。
若调整第二户，可以将其改为 1, 2 或 3，得到方案 (1,1), (1,2), (1,3)。
将这些方案去重后，最终不同的方案为 (1,1), (1,2), (1,3), (2,2), (3,2)，共 5 种。

## 说明

最终分配方案由所有家庭的最终需求值完全决定，只要存在一户的值不同即视为不同方案。答案需要对 1,000,000,007 取模。操作次数预算 B 可以在不同社区间自由分配，即总共修改的元素个数不超过 B 即可。
