# 格子整理

> 生成任务：`home_org_construct_or_conflict` / theme `home_organization`

## 题目描述

小华正在整理一个收纳柜。

柜子中有 n 个格子，编号从 1 到 n，形成一棵树形结构：1 号格子是根，每个非根格子都有唯一的父格子。

每个格子 v 里放有 a_v 个物品（a_v 为非负整数）。小华记录了一张清单，上面写着每个格子 v 对应的 s_v —— 从根格子到该格子的路径上所有物品的总数（包含 v 本身）。显然 s_1 = a_1。此外每个格子还有一个隐藏的深度 h_v，定义为从根格子到 v 的路径上的格子个数，根格子深度为 1。

不幸的是，在整理过程中，清单上所有深度为偶数的格子的 s_v 值被墨水污染，变得无法辨认，用 -1 表示。深度为奇数的格子的 s_v 值仍然清晰，保证不为 -1。

小华现在想知道：能不能根据这些剩余的信息，把每个格子最初的物品数量 a_v 恢复出来？

如果可以，他希望你给出一种方案，使得所有格子物品数量总和尽可能小；

如果不可以（即无论如何都找不到合法的恢复方案），他希望你明确指出矛盾在哪里：找出两个格子 u 和 v，满足 u 是 v 的祖先，两者的深度均为奇数，并且已知的 s_u 大于 s_v。这样一来，因为路径上的物品数量不可能减少，就形成了一个无法解决的矛盾。

## 输入格式

第一行一个整数 n (2 ≤ n ≤ 10^5)，表示格子数量。

第二行 n-1 个整数 p_2, p_3, …, p_n，其中 p_i 表示格子 i 的父格子编号，保证 1 ≤ p_i < i。

第三行 n 个整数 s_1, s_2, …, s_n (-1 ≤ s_i ≤ 10^9)。若 v 的深度为奇数，则 s_v 不为 -1，表示从根到 v 路径上的物品总数；若 v 的深度为偶数，则 s_v = -1，表示该值已被隐藏。

## 输出格式

如果存在合法的恢复方案，输出一行 n 个非负整数 a_1, a_2, …, a_n，表示每个格子原有的物品数量。如果有多种使总和最小的方案，任意输出一种即可。

如果不存在任何合法方案，输出一行两个整数 u 和 v，用空格隔开，满足：
- u 是 v 的祖先；
- u 和 v 的深度均为奇数；
- 输入中给出的 s_u > s_v。
如果有多组这样的证据，输出任意一组即可。

## 数据范围与限制

- 2 ≤ n ≤ 100,000
- 1 ≤ p_i < i
- -1 ≤ s_i ≤ 1,000,000,000
- 确保所有深度为奇数的格子满足 s_i ≠ -1
- 时间限制：2 秒
- 空间限制：256 MB

## 样例

### 样例 1

**输入**

```text
3
1 1
1 -1 -1
```

**输出**

```text
1 0 0
```

**说明**

格子 1（深度 1）已知 s_1=1。格子 2、3（深度 2，偶数）的 s 值被隐藏。偶数深度的 s 值可以设为 0（因为它们没有子节点），这样总和最小。得到 a_1 = s_1 = 1，a_2 = s_2 - s_1 = 0，a_3 = s_3 - s_1 = 0，总和为 1。

### 样例 2

**输入**

```text
4
1 2 1
2 -1 1 -1
```

**输出**

```text
1 3
```

**说明**

格子 1（深度 1）s_1=2，格子 3（深度 3）s_3=1。格子 1 是格子 3 的祖先，两个格子的深度均为奇数，但 s_1 > s_3，违反了路径和单调不减的性质，因此不可能存在合法方案。输出这一对矛盾格子。

## 说明

对于隐藏的 s 值（偶数深度），恢复时令其等于所有子节点中已知 s 值的最小值（若无子节点则设为 0），该策略可保证得到的 a 数组总和最小。

如果同时存在多对满足条件的矛盾格子，输出任意一对均可。
