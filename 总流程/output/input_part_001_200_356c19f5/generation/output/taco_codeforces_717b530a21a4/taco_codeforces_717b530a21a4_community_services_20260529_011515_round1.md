# 社区服务点选址

> 生成任务：`taco_codeforces_717b530a21a4` / theme `community_services`

## 题目描述

在一个新兴社区中，有 n 个住户，住户之间由 n 条道路直接相连。道路可以双向通行，且任意两个住户之间最多只有一条直接道路。整个社区的道路网络是连通的，并且恰好包含一个环路（也就是说，如果看成图，是有 n 个顶点、n 条边的连通图，存在唯一的简单环）。

为了提升居民的生活便利性，社区管委会计划在部分住户处设立服务点（例如快递柜、小型维修站等）。一个服务点可以为距离不超过 K 的住户提供服务。这里，两个住户之间的“距离”定义为沿着道路行走需要经过的最少边数。如果服务点就设在某个住户处，那么该住户的距离为 0。

你需要求出：最少需要设立多少个服务点，才能让社区中的每一个住户到某个服务点的距离都不超过 K。

## 输入格式

第一行包含两个整数 n 和 K (3 ≤ n ≤ 3000, 1 ≤ K ≤ 3000)，分别表示住户的数量和服务覆盖的距离阈值。

接下来 n 行，每行包含两个整数 u 和 v (1 ≤ u, v ≤ n, u ≠ v)，表示住户 u 和住户 v 之间有一条直接道路。保证不会出现重复的道路，并且整个道路网络是连通的，恰好包含 n 条边（因此唯一的环路一定存在）。

## 输出格式

输出一个整数，表示最少需要设立的服务点数量。

## 数据范围与限制

- 时间限制：2.0 秒
- 空间限制：256 MB
- 3 ≤ n ≤ 3000
- 1 ≤ K ≤ 3000
- 1 ≤ u, v ≤ n，u ≠ v
- 图连通，有 n 个顶点和 n 条边，没有重边和自环，因此有且仅有一个简单环
- 道路双向通行，距离定义为最短路径上的边数

## 样例

### 样例 1

**输入**

```text
4 1
1 2
2 3
3 4
4 1
```

**输出**

```text
2
```

**说明**

四个住户构成一个环路。当 K=1 时，每个住户只能被其自身或邻居服务。选择住户 1 和 3 作为服务点：住户 1 覆盖自己、2 和 4；住户 3 覆盖自己、2 和 4。所有住户均被覆盖。容易验证 1 个服务点无法覆盖全部，因此最少需要 2 个。

### 样例 2

**输入**

```text
6 2
1 2
2 3
3 1
3 4
4 5
5 6
```

**输出**

```text
2
```

**说明**

图中包含一个三角形 (1,2,3) 以及从 3 到 6 的一条链。K=2 时，只选一个服务点无法覆盖所有住户（例如选 3，则住户 6 的距离为 3，超过 2）。选择住户 3 和 6：住户 3 可覆盖 1(距离1)、2(距离1)、3(0)、4(1)、5(2)；住户 6 可覆盖 6(0) 和 5(1)。所有住户均被覆盖。可以证明最少需要 2 个服务点。
