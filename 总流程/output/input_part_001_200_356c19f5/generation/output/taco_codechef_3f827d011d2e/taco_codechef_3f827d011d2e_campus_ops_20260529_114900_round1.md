# 社团指导权博弈

> 生成任务：`taco_synthetic_game_rooted` / theme `campus_ops`

## 题目描述

某大学有 $N$ 个社团，编号 $1$ 到 $N$。社团之间存在单向的“指导”关系，例如社团 $A$ 指导社团 $B$ 意味着 $A$ 可以向 $B$ 提供支持。这些指导关系构成了一棵有向树：如果把所有指导关系看作无向边，得到的图是一棵无根树。

如果存在一个社团 $r$，使得从 $r$ 出发遵循指导方向可以到达所有其他社团，就说这棵有向树以 $r$ 为根。学生会所在的社团 $1$ 希望未来能够直接或间接指导全校所有社团，也就是达到以社团 $1$ 为根的状态。

现在，两位学生干部 A（先手）和 B（后手）轮流修改指导关系，每次操作规定如下：
- 选择一条当前存在的有向边 $(u, v)$，将其删除；
- 再添加一条新的有向边 $(x, y)$，使得整张图仍是一棵有向树（不允许出现重边或多条边指向同一结点导致非树结构）。

一旦某位玩家操作后，有向树变成了以社团 $1$ 为根的状态，该玩家立即获胜，游戏结束。

初始状态保证不是以社团 $1$ 为根（否则先手无需操作即已获胜）。

假设双方都采取最优策略，并且都以获胜为目标。请判断先手是否有必胜策略。

## 输入格式

第一行包含一个整数 $T$，表示测试数据的组数。每组数据格式如下：
第一行包含一个整数 $N$，表示社团数量。
接下来 $N-1$ 行，每行包含两个整数 $u, v$，表示一条从 $u$ 指向 $v$ 的有向边。

## 输出格式

对于每组测试数据，输出一行一个字符串 "First" 或 "Second"，表示在双方均采取最优策略的条件下，先手是否有必胜策略。

## 数据范围与限制

- $1 \le T \le 10$
- $2 \le N \le 10^4$
- $1 \le u, v \le N$
- 输入保证给定的图构成一棵有向树
- 初始状态下，社团 $1$ 不是能够到达所有社团的根
- 所有测试数据的 $N$ 总和不超过 $10^5$
- 时间限制：$1$ 秒
- 空间限制：$256$ MB

## 样例

### 样例 1

**输入**

```text
1
3
2 1
3 2
```

**输出**

```text
Second
```

**说明**

初始指导关系为 $2 \to 1, 3 \to 2$。先手无论执行何种操作，都无法一步达到以社团 $1$ 为根的状态；在最优策略下，后手总能在后续的对局中迫使先手失败，因此后手必胜。

### 样例 2

**输入**

```text
1
3
1 2
3 1
```

**输出**

```text
First
```

**说明**

初始指导关系为 $1 \to 2, 3 \to 1$。先手可以删除边 $3 \to 1$ 并添加边 $1 \to 3$，得到 $1 \to 2$ 和 $1 \to 3$，此时从社团 $1$ 可到达所有社团，先手在一步之内获胜，故先手必胜。

## 说明

双方均按照最优策略行动，游戏在有限步内必然结束，且不存在和局。输出应为 'First' 或 'Second'（首字母大写，其余小写）。
