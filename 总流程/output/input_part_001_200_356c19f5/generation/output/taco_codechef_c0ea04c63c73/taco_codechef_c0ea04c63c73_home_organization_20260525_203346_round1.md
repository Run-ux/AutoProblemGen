# 整理储物柜标签

> 生成任务：`inverse_minsz_min_modify` / theme `home_organization`

## 题目描述

小明家里有一个很长的储物柜，里面有一排共 n 个格子，每个格子里都贴着一张标签。标签上写着一个“有趣数”——就是形如 2^x − 1 的正整数（比如 1, 3, 7, 15, …，其中 x 是正整数且不超过 60）。

妈妈希望储物柜看起来更整齐，她给小明一个目标数字 C，并要求最后所有格子里的标签数字的按位异或和必须恰好等于 C。小明可以更换其中一些格子里的标签，但每次只能把一张标签改写成另一个有趣数（仍然必须是 2^y − 1 的形式），不能增加或减少格子，也不能把一张标签改成非有趣数。

现在给你一开始每张标签上的数字以及目标 C，请你帮小明算一算：最少需要更换多少张标签？并且输出一种更换之后的方案，使得所有标签都是有趣数且异或和等于 C。

## 输入格式

第一行一个整数 T，表示测试数据的组数。接下来每组数据按以下格式给出：
第一行一个整数 n，表示格子个数。
第二行 n 个整数 a₁, a₂, …, aₙ，表示一开始贴在格子上的标签数字。保证每一个 aᵢ 都是有趣数。
第三行一个整数 C，表示目标异或和。

## 输出格式

对于每组测试数据，输出两行：
第一行一个整数 K，表示最少的更换次数。
第二行 n 个整数 B₁, B₂, …, Bₙ，表示更换后的标签数字序列。这些数必须都是有趣数，并且满足 B₁ ⊕ B₂ ⊕ … ⊕ Bₙ = C。如果有多种最优方案，输出任意一种即可。

## 数据范围与限制

- 1 ≤ T ≤ 100000
- 1 ≤ n ≤ 60
- 1 ≤ aᵢ < 2⁶⁰，且每个 aᵢ 均可表示为 2^x − 1 的形式，其中 1 ≤ x ≤ 60
- 0 ≤ C < 2⁶⁰
- 输入数据保证至少存在一种更换方案能满足要求。
- 所有测试数据的 n 的总和不超过 6 × 10⁵。
- 时间限制：2 秒
- 空间限制：256 MB

## 样例

### 样例 1

**输入**

```text
2
2
1 1
2
4
1 3 7 15
0
```

**输出**

```text
1
3 1
2
1 3 1 3
```

**说明**

第一组数据：初始标签 [1,1] 的异或和为 0，目标是 2。将第一个 1 改为 3（3 也是有趣数），得到 [3,1]，异或和变为 3⊕1 = 2，只更换了 1 次。
第二组数据：初始标签 [1,3,7,15] 的异或和为 1⊕3⊕7⊕15 = 10，目标是 0。可以保留前两个标签 1 和 3 不动，把第三个标签 7 改成 1，第四个标签 15 改成 3，得到 [1,3,1,3]，此时异或和为 0，更换了 2 次。可以证明无法只换 1 个标签就达到目标。

### 样例 2

**输入**

```text
1
3
1 3 7
7
```

**输出**

```text
2
7 1 1
```

**说明**

初始标签 [1,3,7] 的异或和为 1⊕3⊕7 = 5，目标是 7。如果保留最后一个标签 7 不动，只需要把前两个标签都改成 1，得到 [7,1,1]，异或和变成 7⊕1⊕1 = 7，花费 2 次更换。尝试保留更多标签都会导致需要填写的数据不是有趣数，因此 2 次就是最小更换次数。

## 说明

有趣数是指形如 2^x − 1（x 为正整数）的数，例如 1, 3, 7, 15, 31 等。所有输入给出的初始标签以及输出方案中的标签都必须满足这一性质。异或运算（⊕）在 C++/Java/Python 中对应位运算符号 ^。保证输入数据至少存在一种可行的更换方案。
