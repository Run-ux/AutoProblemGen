# 社区服务圈

> 生成任务：`community_service_circle` / theme `community_services`

## 题目描述

城市里有两个相邻的社区 A 和 B，每个社区内有若干住户。为了方便管理，市政部门计划建立一个圆形区域的社区服务中心，希望服务中心能够覆盖社区 A 的所有住户（所有 A 的住户都严格位于圆内），同时完全不覆盖社区 B 的任何住户（所有 B 的住户都严格位于圆外）。注意：服务中心的半径必须大于 0。

你的任务是判断是否存在这样的圆形服务中心。如果存在，你需要给出一个可行的方案（圆心坐标和半径）。如果不存在，你需要指出一个“冲突证据”：从两个社区中各选出一些住户，这些住户所形成的子集已经足以证明不存在任何圆形服务中心能够将它们分离。具体而言，证据必须满足以下条件之一：
- 选出的 A 的子集与 B 的子集的凸包（即包含这些点的最小凸多边形）相交；
- 选出的 A 的子集中存在一个点严格位于 B 子集的凸包内部，或者选出的 B 的子集中存在一个点严格位于 A 子集的凸包内部。

该证据只需要检查其中包含的住户点即可验证，不需要查看社区中的其他住户。

## 输入格式

第一行包含两个整数 n 和 m (1 ≤ n, m ≤ 10000)，分别表示社区 A 和社区 B 的住户数量。
接下来的 n 行，每行两个整数 x y (-10000 ≤ x, y ≤ 10000)，表示社区 A 的一个住户坐标。
接下来的 m 行，每行两个整数 x y (-10000 ≤ x, y ≤ 10000)，表示社区 B 的一个住户坐标。
所有给出的 n+m 个点的坐标互不相同。

## 输出格式

如果存在满足要求的圆形服务中心，则第一行输出 "YES"（不包含引号）。
第二行输出三个实数 x y r，分别表示圆心的 x 坐标、y 坐标和半径。实数可以输出任意小数位数，但你的输出与正确答案的绝对或相对误差不超过 1e-6 即被视为正确。半径必须大于 0，且对于社区 A 的所有点 p，其到圆心的距离必须严格小于 r；对于社区 B 的所有点 q，到圆心的距离必须严格大于 r。

如果不存在这样的服务中心，则第一行输出 "NO"（不包含引号）。
第二行输出两个正整数 k 和 l，分别表示从社区 A 和社区 B 中选出的住户数量，要求 k ≥ 1 且 l ≥ 1。
接下来的 k 行，每行两个整数，表示从社区 A 中选出的住户的坐标。
接下来的 l 行，每行两个整数，表示从社区 B 中选出的住户的坐标。
这些选出的点必须构成一个不可分离的证据，即满足以下条件之一：
1. 选出的 A 点子集的凸包与选出的 B 点子集的凸包相交；
2. 存在选出的 A 子集中的一个点严格位于选出的 B 子集的凸包内部，或者存在选出的 B 子集中的一个点严格位于选出的 A 子集的凸包内部。
如果满足任意一种情况，则足以证明不存在任何圆能够严格分离这两个子集中的所有点，从而原问题也无解。验证者只需依据证书中的点即可做出判定。

## 数据范围与限制

- 1 ≤ n, m ≤ 10000
- -10000 ≤ x, y ≤ 10000，所有点坐标为整数且互不相同
- 时间限制：2000 ms (2 seconds)
- 空间限制：256 MB

## 样例

### 样例 1

**输入**

```text
2 2
0 0
2 0
1 1
1 -1
```

**输出**

```text
NO
2 2
0 0
2 0
1 1
1 -1
```

**说明**

社区 A 的两个住户 (0, 0) 和 (2, 0) 构成的凸包是一条水平线段，社区 B 的两个住户 (1, 1) 和 (1, -1) 构成的凸包是一条垂直线段，这两条线段相交于点 (1, 0)，因此不可能存在一个圆将两个社区严格分开。输出的证书包含了这两个子集本身，它们已经足以证明不可分离。

### 样例 2

**输入**

```text
2 1
0 0
0 1
10 10
```

**输出**

```text
YES
0.0 0.5 0.6
```

**说明**

构造圆心为 (0.0, 0.5)、半径为 0.6 的圆。社区 A 的点 (0, 0) 和 (0, 1) 到圆心的距离均为 0.5，严格小于半径；社区 B 的点 (10, 10) 到圆心的距离约为 13.44，严格大于半径，因此满足要求。

## 说明

1. 当输出 YES 时，任何满足严格分离条件的圆均为正确答案，你可以输出任意一个。
2. 当输出 NO 时，证书不要求包含的点数最小，只要满足上述冲突条件即可。事实上，若整个问题无解，总是存在这样的证书。
