# 社区服务的完美协调

> 生成任务：`cs_inv_001` / theme `community_services`

## 题目描述

在一个社区中，有 N 个服务点按固定顺序排成一排，每个服务点 i 的当前服务时长记为 A_i。为了满足住户的日常需求，社区管理员可以对服务点进行一次性的时长调整：每次操作可以选择一个服务点，将其服务时长增加 1 或减少 1，每次操作的代价为 1。最终得到一个新的服务时长序列 A'。

现在有 Q 位住户提出了自己的服务需求。每个需求由三个参数 (p, k, T) 描述：
- p 是一个质数，住户特别关注服务时长能被 p 整除的服务点。
- k 表示住户希望在排班表的前 k 个服务点中获得服务。
- T 是住户期望前 k 个服务点的时长总和不小于 T。

管理员可以利用一个特殊的重排规则：对于任意一个需求 (p, k, T)，在序列 A' 中，所有时长能被 p 整除的服务点被视为“灵活服务点”，它们可以在 A' 中任意交换位置；而其他服务点的位置固定不变。注意，这个重排操作是虚拟的——每个需求独立进行重排，不会真正改变序列 A'，但所有需求共享同一个最终序列 A'。

你需要帮助管理员决定最小的总修改代价，使得存在一个序列 A'，能够同时满足所有 Q 个住户的需求。如果不可能，请输出 -1。

## 输入格式

第一行包含一个整数 T，表示测试数据的组数。
每组测试数据按以下格式给出：
第一行一个整数 N，表示服务点的数量。
第二行包含 N 个整数 A_1, A_2, ..., A_N，表示初始服务时长。
第三行一个整数 Q，表示需求的数量。
接下来 Q 行，每行三个整数 p, k, T，描述一个需求。p 保证是质数。

## 输出格式

对于每组测试数据，输出一行一个整数，表示最小的总修改代价。如果不存在满足所有需求的序列 A'，输出 -1。

## 数据范围与限制

- 1 ≤ T ≤ 100
- 1 ≤ N ≤ 10^5
- 1 ≤ A_i ≤ 10^5
- 1 ≤ Q ≤ 10^5
- 2 ≤ p ≤ 10^5，且 p 为质数
- 1 ≤ k ≤ N
- 1 ≤ T ≤ 10^12
- 单个测试数据中 N 与 Q 的总和不超过 2×10^5
- 所有测试数据中 N 与 Q 的总和不超过 2×10^5
- 时间限制：2 秒
- 空间限制：512 MB

## 样例

### 样例 1

**输入**

```text
1
5
1 2 3 4 5
1
2 3 8
```

**输出**

```text
0
```

**说明**

初始序列为 [1,2,3,4,5]。唯一的需求是 p=2, k=3, T=8。
在 A' = A 时，能被 2 整除的元素是 2 和 4，分别位于位置 2 和位置 4。在前 3 个位置（索引 1,2,3）中，位置 1 固定为 1，位置 3 固定为 3，位置 2 是灵活位置。我们可以把最大的灵活元素 4 放到位置 2，得到 [1,4,3,2,5]，前 3 项之和为 1+4+3=8，恰好达到目标。因此不需要任何修改，最小代价为 0。

### 样例 2

**输入**

```text
1
4
1 2 3 4
2
2 2 5
3 3 8
```

**输出**

```text
2
```

**说明**

初始序列为 [1,2,3,4]。有两个需求：
需求 1：p=2, k=2, T=5。
需求 2：p=3, k=3, T=8。
首先考虑不修改的情况：
- 对于需求 1，灵活元素为 {2,4}，固定元素为 {1,3}。前 2 个位置中，位置 1 固定为 1，位置 2 是灵活位置。将 4 移到位置 2 可得 [1,4,3,2]，前 2 和为 5，满足 T=5。
- 对于需求 2，灵活元素为 {3}，固定元素为 {1,2,4}。前 3 个位置中，位置 1、2 固定为 1、2，位置 3 灵活为 3，前 3 和为 1+2+3=6，小于 T=8。因此必须修改。
若只增加服务点 3 的时长 1 单位，序列变为 [1,2,4,4]，需求 2 的前 3 和变为 1+2+4=7，仍不足；若增加 2 单位至 5，序列变为 [1,2,5,4]。此时：
- 需求 2：灵活元素为 {5}，固定元素不变，前 3 和 = 1+2+5=8，满足。
- 需求 1：灵活元素为 {2,4}，固定元素为 {1,5}，前 2 和 = 1+4=5，依然满足。
总修改代价为 |5-3|+0 = 2。可以证明不存在代价更小的方案（代价为 1 时，需求 2 的目标无法达到）。故最小代价为 2。

## 说明

如果不存在满足所有需求的序列 A'，输出 -1。
每个需求的 p 保证为质数。
重排操作仅针对单个需求独立进行，不影响最终序列 A'。
服务时长始终为正整数，但 A'_i 可以小于 1 或大于 10^5，只需保证修改代价定义。
