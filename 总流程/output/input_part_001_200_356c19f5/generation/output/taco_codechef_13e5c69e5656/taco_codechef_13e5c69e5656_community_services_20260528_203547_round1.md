# 社区服务优先级排列计数

> 生成任务：`taco_codechef_13e5c69e5656_counting` / theme `community_services`

## 题目描述

在一个社区中，有一排住户，从左到右共 N 户。每位住户有一个优先级值 M_i，表示该住户需要社区服务的紧急程度。

社区服务中心会不定期收到服务请求，每个请求包含两个参数：
- 服务类型 p（保证 p 是一个素数），它表示只有优先级值能被 p 整除的住户才可以被重新排列顺序；
- 整数 k，表示只考虑前 k 位住户（即位置 1 到 k）的服务。

对于每个请求，你可以对原始住户序列进行一次重排：
- 优先级值不能被 p 整除的住户，其位置绝对固定，不能移动；
- 优先级值能被 p 整除的住户则可以进行任意置换（即这些住户的优先级值之间的相对顺序可以改变）。

重排后，计算前 k 位住户的优先级值之和。在所有合法重排方式中，我们希望该和尽可能大，即达到最大值。

现在问题来了：对于每个请求，有多少种不同的重排方式（整个序列视为一个整体，若任意一个位置上的优先级值不同，就视为不同的排列方式），能够使得前 k 位住户的优先级值之和等于这个最大值？

为了达到该最大值，你需要将可移动住户中优先级值最大的若干位（数量恰好等于前 k 位中可移动位置的数量）安排到前缀的可移动位置上；如果存在多个相同值的住户，不同的选择方式会得到不同的前缀多集，进而产生不同的序列。后部可移动住户之间的任意排列也会产生不同的序列。你需要汇总所有可能方式的种数。

由于答案可能很大，请输出答案对 1,000,000,007 取模后的结果。

注意：每个请求都是独立的，每次重排都是从原始序列开始，请求之间互不影响。

## 输入格式

第一行一个整数 T，表示测试用例的数量。每个测试用例的格式如下：
第一行一个整数 N，表示住户的数量。
第二行 N 个空格分隔的整数 M_1, M_2, ..., M_N，表示各住户的初始优先级值。
第三行一个整数 Q，表示服务请求的数量。
接下来 Q 行，每行两个整数 p 和 k，分别表示服务类型（素数）和考虑的前 k 位住户。

## 输出格式

对于每个测试用例中的每个服务请求，输出一行一个整数，表示能达到最大前 k 项和的合法重排方式的数量，对 1,000,000,007 取模。

## 数据范围与限制

- 1 ≤ T ≤ 100
- 1 ≤ N ≤ 100,000
- 1 ≤ Q ≤ 100,000
- 1 ≤ M_i, p ≤ 100,000
- 1 ≤ k ≤ N
- p 是素数
- 所有测试用例的 N 与 Q 之和均不超过 200,000
- 时间限制：2 秒
- 空间限制：256 MB

## 样例

### 样例 1

**输入**

```text
1
4
2 2 4 4
2
2 2
2 3
```

**输出**

```text
1
3
```

**说明**

原始序列为 [2, 2, 4, 4]，所有权重都能被 p=2 整除，故全部可移动。
- 查询 p=2, k=2：最大前两项和为 4+4 = 8，必须将两个 4 放在前两个位置。此时序列只能是 [4, 4, 2, 2]，共 1 种排列。
- 查询 p=2, k=3：最大前三项和为 4+4+2 = 10，必须将两个 4 和一个 2 放在前三个位置。可行的排列有 [4, 4, 2, 2]、[4, 2, 4, 2]、[2, 4, 4, 2]，共 3 种排列。

### 样例 2

**输入**

```text
1
5
1 2 3 4 5
2
2 3
3 4
```

**输出**

```text
1
1
```

**说明**

原始序列为 [1, 2, 3, 4, 5]。
- 查询 p=2, k=3：只有第 2、4 个住户（值为 2 和 4）可移动。前三个位置中有一个可移动位置（第 2 个）。为使和最大，必须将该位置替换为可移动值中最高的 4，剩余可移动值 2 放在后面。唯一序列 [1, 4, 3, 2, 5]，方案数为 1。
- 查询 p=3, k=4：只有第 3 个住户（值为 3）可移动。前四个位置中有一个可移动位置（第 3 个）。可移动值只有 3，故只能保持原序列 [1, 2, 3, 4, 5]，方案数为 1。

## 说明

若某个服务类型 p 不存在任何能被其整除的住户，则无法进行任何移动，此时原序列唯一，排列数为 1。
若所有可移动住户均位于前 k 位之后（即前缀中无可移动位置），那么最大前 k 项和即为原始前缀和，任意将这些可移动住户在后部重新排列的方案都满足条件，方案数等于后部可移动住户的排列数（需考虑重复值的去重）。
计算排列数时，整个住户序列的每一个位置均参与比较，仅当所有位置上的值完全相同时才视为同一种排列。所有答案均需对 1,000,000,007 取模。
