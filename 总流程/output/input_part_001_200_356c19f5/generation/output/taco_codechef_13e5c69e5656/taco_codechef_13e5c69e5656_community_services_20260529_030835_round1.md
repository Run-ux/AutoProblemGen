# 社区服务的排班方案

> 生成任务：`community_service_count_001` / theme `community_services`

## 题目描述

幸福社区有 N 个服务点，编号 1 到 N。每个服务点 i 有一个固定的服务时长 M_i。住户会按顺序依次访问前 k 个服务点。社区管理员可以为每位住户调整部分服务点的顺序，但只能调整那些服务时长能被质数 p 整除的服务点（称为灵活服务点），其余服务点的相对顺序保持不变。每次调整从原始顺序开始，各个查询相互独立。
对于每个查询 (p, k)，你需要计算：在所有能使前 k 个服务点的服务时长之和达到最大的重排方案中，有多少种不同的最终服务点序列？如果两个序列在某个位置上的服务时长不同，则认为它们不同。答案可能很大，请将其对 1,000,000,007 取模后输出。

## 输入格式

第一行一个整数 T，表示测试用例数量。
接下来每个测试用例：
  第一行一个整数 N，表示服务点的数量。
  第二行 N 个由空格分隔的整数 M_1, M_2, ..., M_N，分别表示每个服务点的服务时长。
  第三行一个整数 Q，表示查询的数量。
  接下来 Q 行，每行两个整数 p 和 k，表示一个查询：p 是一个质数，表示住户关注的类型；k 是该住户将访问的前 k 个服务点。

## 输出格式

对于每个测试用例，依次输出每个查询的答案，每个答案占一行，表示达到最大总服务时长的不同最终序列的数目，结果对 1,000,000,007 取模。

## 数据范围与限制

- 1 ≤ T ≤ 100
- 1 ≤ N ≤ 10^5
- 1 ≤ Q ≤ 10^5
- 1 ≤ M_i ≤ 10^5
- 2 ≤ p ≤ 10^5，p 是质数
- 1 ≤ k ≤ N
- 所有测试用例的 N 总和不超过 2×10^5
- 所有测试用例的 Q 总和不超过 2×10^5
- 时间限制：2 秒
- 空间限制：256 MB

## 样例

### 样例 1

**输入**

```text
1
4
2 4 4 6
2
2 3
2 2
```

**输出**

```text
3
4
```

**说明**

原始序列 [2,4,4,6]。
对于第一个查询 p=2, k=3：所有服务点均可被 2 整除，灵活服务点为索引 1,2,3,4。前 3 个位置中有 3 个灵活位置。为使前 3 项之和最大，必须将最大的 3 个灵活时长 6,4,4 放到前三个位置。它们的不同排列数为 3! / 2! = 3，对应的最终序列为 [6,4,4,2]、[4,6,4,2]、[4,4,6,2]。
对于第二个查询 p=2, k=2：灵活服务点同上，前 2 个位置中有 2 个灵活位置。最优前缀必须包含 6 和一个 4。前两个位置可以是 (6,4) 或 (4,6)，后两个位置剩余一个 4 和 2，可以任意排列。但由于存在两个相同的 4，最终不同的完整序列有 4 种：[6,4,4,2]、[6,4,2,4]、[4,6,4,2]、[4,6,2,4]。

### 样例 2

**输入**

```text
1
5
3 3 3 6 9
1
3 5
```

**输出**

```text
20
```

**说明**

原始序列 [3,3,3,6,9]，质数 p=3，k=5。所有服务时长都能被 3 整除，因此所有服务点都是灵活服务点。为使前 5 项之和最大，可以将所有点按任意顺序重排，不同序列数即为 5 个元素的全排列去除重复值：5! / 3! = 20。因此答案为 20。

## 说明

每个查询中的 p 均为质数。答案需要对 1,000,000,007 取模。达到最大总时长的方案总是存在，并且可以通过题目描述的贪心构造得到。计数时需考虑重复值导致的去重，即仅当数组完全一致时才视为同一个序列。
