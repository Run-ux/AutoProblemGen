# 活动均衡计划

> 生成任务：`inverse_flip_to_kbalanced` / theme `campus_ops`

## 题目描述

小码是学校社团管理部的干事，他需要为接下来 n 个时段安排教室使用计划。每个时段可以选择进行社团活动（用 0 表示）或课程教学（用 1 表示）。学校规定，为了保证校园活动丰富多彩也不耽误学习，任意连续的 k 个时段内，社团活动和课程教学的数量必须相等，即各有 k/2 个（k 保证为偶数）。

小码已经拟定了一个初步计划，用一个长度为 n 的、仅包含 0 和 1 的字符串表示。但他发现这个计划可能不满足均衡条件。他可以对任意时段的安排进行调整：如果原来安排的是社团活动，可以改为课程教学；如果原来是课程教学，可以改为社团活动。每次这样的调整算作一次操作。

请你帮小码计算出，最少需要进行多少次调整操作，才能让整个计划变成一个 k-均衡的计划。

## 输入格式

第一行包含一个整数 t (1 ≤ t ≤ 10000)，表示测试数据的组数。
接下来每组测试数据包含两行：
- 第一行包含两个整数 n 和 k (2 ≤ k ≤ n ≤ 3·10^5，k 为偶数)，分别表示时段的个数和均衡窗口的长度。
- 第二行包含一个长度为 n 的字符串 s，仅由字符 '0' 和 '1' 组成，表示小码的初步计划。

保证所有测试数据的 n 之和不超过 3·10^5。

## 输出格式

对于每组测试数据，输出一行一个整数，表示达到 k-均衡计划所需的最少调整次数。

## 数据范围与限制

- 时间限制：2 秒
- 空间限制：256 MB
- 1 ≤ t ≤ 10000
- 2 ≤ k ≤ n ≤ 3·10^5，k 为偶数
- 字符串 s 仅包含 '0' 和 '1'
- 所有测试数据的 n 之和不超过 3·10^5

## 样例

### 样例 1

**输入**

```text
2
6 4
100110
6 4
111100
```

**输出**

```text
0
2
```

**说明**

对于第一组测试数据，初始计划已经是 4-均衡的：连续 4 个时段分别为 1001、0011、0110，都恰好包含两个社团活动和两个课程教学，无需任何调整。
对于第二组测试数据，一种最优方案是将第 1 个和第 2 个时段从课程教学（1）调整为社团活动（0），得到 001100，这时每连续 4 个时段都满足均衡条件，共调整 2 次。可以证明不存在只需 1 次调整的方案。

### 样例 2

**输入**

```text
1
8 4
00001111
```

**输出**

```text
4
```

**说明**

初始计划 00001111 不满足 4-均衡。一种最优方案是翻转第 2、3、6、7 个位置（将其从 0 变为 1 或从 1 变为 0），得到 00110011，这时所有连续 4 个时段均满足 4-均衡，共调整 4 次。

## 说明

题目保证对于任意满足输入条件的初始计划，总存在一种调整方案能使字符串变为 k-均衡，你只需计算最少操作次数。最优方案中每个时段至多被调整一次。
