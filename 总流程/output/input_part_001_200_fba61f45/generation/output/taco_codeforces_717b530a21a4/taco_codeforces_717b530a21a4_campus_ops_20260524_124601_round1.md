# 校园环游路线设计

> 生成任务：`campus_ops_ring_lexmin` / theme `campus_ops`

## 题目描述

学校有 N 间教室，编号 1 到 N。教室之间由走廊连接，已知这些走廊构成一个连通图，且图中恰好包含一个简单环（即恰好一个环形走廊，其余部分为树形结构）。校庆要举办“环游校园”打卡活动，需要沿着环走一圈，不重复经过任何教室（起点和终点重合）。由于存在多条可行的环游路线，校方希望获取字典序最小的教室编号序列作为官方路线。请你编写程序，对于给定的教室和走廊图，输出该字典序最小的环上教室序列。

## 输入格式

第一行包含一个整数 N (3 ≤ N ≤ 3000)，表示教室数量。
接下来 N 行，每行两个整数 u, v (1 ≤ u, v ≤ N, u ≠ v)，表示教室 u 和 v 之间有一条走廊。输入保证图是连通的，无重边，且恰好包含一个简单环。

## 输出格式

一行，若干个整数，表示字典序最小的环上教室序列。序列中的元素为教室编号，顺序为沿着环的相邻节点遍历，第一个元素与最后一个元素在图中也应是相邻的。序列中不含重复节点。

## 数据范围与限制

- 3 ≤ N ≤ 3000
- 1 ≤ u, v ≤ N, u ≠ v
- 图连通、无自环、无重边、恰有一个简单环
- 时间限制：1 秒
- 空间限制：256 MB

## 样例

### 样例 1

**输入**

```text
3
1 2
2 3
3 1
```

**输出**

```text
1 2 3
```

**说明**

整个图即为一个三元环，字典序最小的环序列为 (1,2,3)。

### 样例 2

**输入**

```text
4
1 2
2 3
3 4
4 1
```

**输出**

```text
1 2 3 4
```

**说明**

图为一个四元环。所有可能的环序列中，以1开头且方向为1→2→3→4的序列 (1,2,3,4) 字典序最小。

### 样例 3

**输入**

```text
5
1 2
2 3
3 1
3 4
4 5
```

**输出**

```text
1 2 3
```

**说明**

环仅由节点 1,2,3 构成，其字典序最小表示为 (1,2,3)。注意输出只需包含环上的节点。

## 说明

字典序比较规则：按顺序逐个元素比较，出现的第一个不同元素较小的序列为小；若所有元素均相同，则序列相等。对于本题的输入，由于环上节点互不相同，字典序最小的环序列总是唯一的（若在特殊构造下出现多个极小序列，输出任意一个即可，但此情况不可能发生）。
