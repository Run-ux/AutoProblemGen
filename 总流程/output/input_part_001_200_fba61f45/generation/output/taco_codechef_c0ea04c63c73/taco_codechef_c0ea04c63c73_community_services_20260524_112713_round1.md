# 社区服务最优排班方案

> 生成任务：`taco_counting_min_service_points` / theme `community_services`

## 题目描述

社区打算新建若干服务点。每个服务点可以发放一种“服务礼包”。第 k 类礼包精确提供 2^k - 1 人次的服务量，其中 k 是 1 到 60 的整数。

社区根据住户预约情况汇总得到一个需求码 C（一个非负整数）。为了精准匹配需求，需要安排一系列服务点，并为每个点选定一类礼包，使得所有选定礼包的服务量按位异或的结果恰好等于 C。

出于资源节约考虑，服务点的数量必须尽可能少。在最少服务点数量的前提下，统计有多少种不同的礼包选派序列（服务点的顺序重要）。

可以证明，满足最少点数要求的任意一个合法序列，都能够按照需求码 C 的二进制表示中的连续“1”区域，唯一地分解为若干个基本组分。每个组分独立地处理 C 的一个二进制位段，且不同组分之间方案数相乘即可得到总方案数。这样的分解保证了在枚举所有最优点序列时既不会重复也不会遗漏。

由于答案可能非常巨大，请输出方案数对 1,000,000,007 取模的结果。

## 输入格式

第一行包含一个整数 T，表示测试用例的数量。
接下来 T 行，每行包含一个整数 C，表示一个社区的需求码。

## 输出格式

对于每个测试用例，输出一行一个整数，表示方案数模 1,000,000,007 的结果。

## 数据范围与限制

- 1 ≤ T ≤ 100000
- 0 ≤ C ≤ 1152921504606846975（即 2^60 - 1）
- 每个服务点的服务量必须为 2^k - 1，其中 1 ≤ k ≤ 60
- 服务点数量必须是最小的可能值
- 时间限制：2 秒
- 空间限制：256 MB

## 样例

### 样例 1

**输入**

```text
1
1
```

**输出**

```text
1
```

**说明**

C=1：最少仅需 1 个服务点，礼包种类只有 k=1（服务量 1），方案唯一。

### 样例 2

**输入**

```text
1
2
```

**输出**

```text
2
```

**说明**

C=2：最少需要 2 个服务点。可行的礼包服务量组合为 (1,3) 和 (3,1)，两种序列的异或和均为 2，且无法用更少的点达成。因此方案数为 2。

## 说明

答案需要对 1,000,000,007 取模。服务点的顺序不同视为不同的方案。对于 C=0 的特殊情况，最小点数为 2，方案数为 60（对应 60 种可能的礼包种类 k，每个序列由两个相同的 2^k-1 组成）。

题目保证任意需求码 C 都存在至少一种满足条件的序列。
