# 社团赞助方案

> 生成任务：`taco_codeforces_359a62b3c24d_canonical_witness_campus_ops` / theme `campus_ops`

## 题目描述

学校有 n 个学生社团，每个社团计划举办一场活动，需要连续占用一间教室。社团 i 需要占用 t_i 分钟，并且愿意向学校缴纳赞助费 c_i 元。每个社团要么全额缴纳赞助费（成为“赞助社团”），要么不缴纳（成为“普通社团”）。不缴纳赞助费的社团，在使用教室时需要学校管理员协助开门、调试设备等，每个普通社团正好消耗管理员 1 分钟的时间。管理员只能在赞助社团活动的时段内处理普通社团的事务，且管理员同一分钟只能处理一个社团。为了确保所有普通社团都能得到服务，学校要求赞助社团的总活动时间（分钟数）不能少于普通社团的数量。

学校希望总赞助费尽可能少，同时如果存在多种费用相同的方案，希望赞助方案在字典序意义上最优：将 n 个社团按编号 1 到 n 的顺序排成一行，每个社团下方标 0（普通）或 1（赞助），得到一个 01 序列。在总费用最小的方案中，学校希望这个 01 序列的字典序最小（即尽可能让编号小的社团不赞助）。

请你找出这样的赞助方案，并输出最小总赞助费和赞助社团的编号列表。

## 输入格式

第一行一个整数 n (1 ≤ n ≤ 2000)，表示社团总数。
接下来 n 行，每行两个整数 t_i 和 c_i (0 ≤ t_i ≤ 2000, 1 ≤ c_i ≤ 10^9)，分别表示社团 i 的占用时间和赞助费。

## 输出格式

第一行输出一个整数，表示最小总赞助费。
第二行首先输出一个整数 k，表示赞助社团的数量；随后输出 k 个整数（升序排列），表示赞助社团的编号。

## 数据范围与限制

- 时间限制：2.0 秒
- 空间限制：256 MB
- 1 ≤ n ≤ 2000
- 0 ≤ t_i ≤ 2000
- 1 ≤ c_i ≤ 10^9
- 总费用可能超过 32 位整数范围，请使用 64 位整数。

## 样例

### 样例 1

**输入**

```text
4
2 5
2 5
0 5
0 5
```

**输出**

```text
10
2
2 4
```

**说明**

满足条件且总赞助费最小的方案有多个，例如赞助社团 {1,2}、{1,3}、{1,4}、{2,3}、{2,4}，总费用均为 10。对应的 01 序列分别为 1100、1010、1001、0110、0101。字典序最小的是 0101（社团 2 和 4 赞助，其余不赞助）。

### 样例 2

**输入**

```text
3
1 5
1 5
1 5
```

**输出**

```text
10
2
1 3
```

**说明**

最小总赞助费为 10。两个赞助社团即可满足条件。三种方案对应 01 序列：110（赞助 {1,2}）、101（赞助 {1,3}）、011（赞助 {2,3}）。字典序最小的是 101。

## 说明

字典序比较规则：将赞助情况表示成一个长度为 n 的 01 串，第 i 位为 1 表示社团 i 赞助，0 表示不赞助。比较时从社团 1 到 n 逐位进行，第一位不同的位置上，为 0 的序列字典序更小。
输入保证至少存在一个合法方案，且赞助社团数量至少为 1。
推荐使用 64 位整数类型（如 C++ 中的 long long）存储费用。
