# 社团教室公平度调整

> 生成任务：`campus_ops_equity_modify` / theme `campus_ops`

## 题目描述

某大学有 n 间教室，每间教室有一个容纳人数（容量）。校学生会需要从中选出 k 间教室用于社团活动日，希望所选教室的容量尽可能接近，以避免资源分配不均。定义一组教室的公平度为：这组教室中任意两间容量差的最小绝对值。
学生会关心所有可能选出 k 间教室的组合，并想知道这些组合的公平度之和。由于社团发展，他们希望这个和值达到一个特定的目标 S（模 998244353）。
为此，学校可以调整某些教室的容量，每次调整可以将一间教室的容量修改为任意 0 到 100000 之间的整数。调整不需要连续，可以一次把一个教室的容量直接改为新值。
给定初始容量和目标 S，请你计算最少需要调整多少间教室的容量，才能使得最终所有 k 元教室组合的公平度之和模 998244353 恰好等于 S。
注意公平度计算只与容量值的多重集有关，与教室顺序无关。你可以内部对容量进行排序以便计算。

## 输入格式

第一行包含三个整数 n, k, S，分别表示教室数量、需要选出的教室数量、以及目标公平度之和模 998244353 后的值。
第二行包含 n 个整数 a_1, a_2, ..., a_n，表示每间教室的初始容量。

## 输出格式

输出一个整数，表示最少需要调整的教室数量。如果无论怎么调整都无法使公平度之和模 998244353 等于 S，则输出 -1。

## 数据范围与限制

- 2 ≤ k ≤ n ≤ 1000
- 0 ≤ a_i ≤ 100000
- 0 ≤ S < 998244353
- 时间限制：2 秒
- 空间限制：256 MB

## 样例

### 样例 1

**输入**

```text
3 2 2
1 2 3
```

**输出**

```text
1
```

**说明**

初始容量 [1,2,3]，所有 2 间教室组合的公平度之和为 4（组合与公平度：{1,2}→1, {1,3}→2, {2,3}→1）。目标 S=2。可以将容量 3 调整为 1，得到 [1,1,2]，此时组合与公平度：{1,1}→0, {1,2}→1, {1,2}→1，和为 2（模 998244353 仍为 2），达成目标。只调整了 1 间教室，可以证明这是最少的。

### 样例 2

**输入**

```text
4 2 10
1 2 5 6
```

**输出**

```text
2
```

**说明**

初始容量 [1,2,5,6]，所有 2 间教室组合的公平度之和为 18。目标 S=10。可以将 5 调整为 3，6 调整为 4，得到 [1,2,3,4]，此时组合与公平度：{1,2}→1, {1,3}→2, {1,4}→3, {2,3}→1, {2,4}→2, {3,4}→1，和为 10，达成目标。至少需要调整 2 间教室，因为没有只调整 1 间就可得到和 10 的方案。

## 说明

公平度之和可能很大，需要模 998244353。调整后的容量仍须在 [0, 100000] 范围内。如果目标不可能达成，请输出 -1。
你可以将容量数组排序后计算公平度之和，因为公平度只与值有关，与原始顺序无关。
