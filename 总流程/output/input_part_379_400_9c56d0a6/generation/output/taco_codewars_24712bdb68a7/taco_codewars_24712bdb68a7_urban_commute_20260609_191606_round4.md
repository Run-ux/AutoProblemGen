# 公交班次修正

> 生成任务：`taco_codewars_24712bdb68a7_inverse_design_v2` / theme `urban_commute`

## 题目描述

小明是公交公司的调度员，发现某条线路的运行时间记录格式为数学等式，例如“12+34=46”，表示第一段耗时12分钟，第二段耗时34分钟，总耗时46分钟。等式可能包含加号(+)、减号(-)、乘号(*)，且等式两边均可能出现多个数字和运算符。然而部分记录被墨水弄脏，一些数字变得模糊不清，用问号“?”代替。根据其他班次的信息，小明推断所有这些污损数字其实都是同一个数字 d。但即便把“?”都换成 d，等式通常也不成立，这说明记录中还有一些原本清晰的数字其实是错误的。

为此，小明可以修改等式里原本清晰的数字（即那些不是“?”的数字字符）。每次修改只能选择等式中的一个已知数字字符，将其改为另一个数字字符（0-9）。注意：不能增删字符，不能修改运算符（+、-、*）、等号和紧邻数字前的前缀负号。修改后，等式的长度和运算符、等号、前缀负号的位置必须与原式完全一致。

每改动一个数字算作一次修改。小明希望修改次数越少越好。此外，修改完成后，数字 d 不能再出现在等式的任何已知数字位置上——毕竟 d 是当初被弄脏的数字，如果修改后它又出现在了清晰的位置，就自相矛盾了。所有修改后的数字必须满足常规数值约束：不能有前导零（除非该数字本身就是 0），且每个数字的绝对值不超过 1,000,000。

请你帮小明算出最少需要修改几个数字，并给出修改后的完整等式（所有“?”均已替换成 d）。如果无论如何修改都无法满足要求，则直接指出无法做到。

## 输入格式

输入包含两行。
第一行是一个字符串，表示带有“?”的等式，格式为合法的数学表达式，只包含数字0-9、问号“?”、加号“+”、减号“-”、乘号“*”和等号“=”。其中紧邻数字前的“-”视为该数字的前缀负号，不作为独立的减号运算符；数字前最多有一个前缀负号，且其后紧跟数字或“?”。表达式中可包含多个运算符（例如 a+b*c=d）。
第二行是一个整数 d（0 ≤ d ≤ 9），表示所有“?”代表的数字。

## 输出格式

如果不存在符合要求的修改方案，输出一行 -1。
否则，第一行输出一个整数 k，表示最少的修改次数；第二行输出一个字符串，表示修改完成且将所有“?”替换为 d 之后的完整等式。该等式可直接作为修改方案的证明。

## 数据范围与限制

- 等式字符串的长度不超过 30。
- 所有“?”代表同一个数字 d，0 ≤ d ≤ 9。
- 修改操作：每次只能选择一个已知数字字符（即原始表达式中不是“?”、不是运算符、不是等号、不是前缀负号的数字字符），将其改为另一个数字（0-9）。不能增删字符，不能修改运算符、等号和前缀负号的位置。修改后等式长度与字符的类别位置必须与原式一致。
- 修改后，等式中的每个数字序列不能有前导零（除非该数字本身就是 0），且每个数字的绝对值不超过 1,000,000。
- 修改后，数字 d 不得出现在等式中的任何已知数字位置上（即原表达式中原本不是“?”的位置）。
- 时间限制：2000ms，空间限制：256MB。

## 样例

### 样例 1

**输入**

```text
?+?=10
5
```

**输出**

```text
0
5+5=10
```

**说明**

将“?”全部替换为5后得到“5+5=10”，等式自然成立，且5不在已知数字{1,0}中，无需任何修改。最少修改次数为0，直接输出替换后的等式。

### 样例 2

**输入**

```text
?+?=11
5
```

**输出**

```text
1
5+5=10
```

**说明**

直接替换为5后得到“5+5=10”，等式不成立（左边等于10，右边等于11）。因为原始等式中已知数字为两个1，可以将右边十位的1修改为0，得到“10”，左边5+5=10成立，且已知数字{1,0}不含5。仅需1次修改，为最小方案。

### 样例 3

**输入**

```text
?*?=??
2
```

**输出**

```text
-1
```

**说明**

原等式只有问号，没有任何已知数字可以修改。替换为2后得到“2*2=22”，等式不成立。由于无法进行任何修改操作，不存在满足要求的解，故输出-1。

### 样例 4

**输入**

```text
-1+?=?
1
```

**输出**

```text
1
-0+1=1
```

**说明**

将“?”替换为1后得到“-1+1=1”，等式不成立（-1+1=0≠1），且数字1出现在-1中，与d=1冲突（已知数字位置不能出现d）。将-1中的数字1改为0，得到“-0+1=1”，等式成立且已知数字{0}不含1。仅需1次修改，为最小次数。注意负号保留，长度不变。

### 样例 5

**输入**

```text
?*?=1?
4
```

**输出**

```text
-1
```

**说明**

替换后得到“4*4=14”，等式不成立。原始等式中已知数字为1（在右边十位）。无论将1修改为何种数字，都无法使等式成立（左边恒为16，右边为1x，x由?固定为4），因此无解，输出-1。

## 说明

当有解时，输出的第二行字符串即为修改后的等式，它已经将所有“?”换成 d。将该字符串与原输入对比，即可知道哪些位置的数字被更改，从而还原具体的修改方案。如果无解，只输出 -1。前缀负号仅出现在数字或“?”之前，且不视为独立运算符；表达式中允许多个运算符（如 a+b*c=d）。所有修改必须保持等式长度与运算符/等号/负号的位置完全不变。
