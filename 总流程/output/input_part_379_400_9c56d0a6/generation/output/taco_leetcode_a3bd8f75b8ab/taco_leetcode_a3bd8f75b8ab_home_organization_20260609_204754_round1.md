# 储物柜整理

> 生成任务：`inverse_maxgap_minops` / theme `home_organization`

## 题目描述

小杰的家中有很多储物柜，每个柜子都有一个独一无二的编号。他有一张物品清单，记录了每个物品当前所在的柜子编号。现在他想要重新整理物品，使得所有物品按照柜子编号从小到大排序后，相邻两个物品所在柜子编号的最大差值恰好等于一个给定的目标值 target_gap。

每次操作他可以选择任意一个物品，将其移动到任意一个柜子中（编号可以是任意非负整数）。

请你帮小杰计算：最少需要进行多少次移动操作，才能达成目标。

## 输入格式

第一行包含两个整数 n 和 target_gap，分别表示物品数量和目标最大差值。
第二行包含 n 个整数，表示每个物品当前所在的柜子编号。

## 输出格式

输出一个整数，表示最少需要的操作次数。

## 数据范围与限制

- 2 ≤ n ≤ 10^5
- 0 ≤ 柜子编号 ≤ 2^31 - 1
- 0 ≤ target_gap ≤ 2^31 - 1
- 时间限制：1 秒
- 空间限制：256 MB

## 样例

### 样例 1

**输入**

```text
4 3
1 3 6 9
```

**输出**

```text
0
```

**说明**

当前柜子编号排序后为 [1, 3, 6, 9]，相邻差最大值为 3，已经等于 target_gap，无需移动任何物品。

### 样例 2

**输入**

```text
4 3
1 3 7 9
```

**输出**

```text
1
```

**说明**

将位于柜子 7 的物品移动到柜子 6，得到编号序列 [1, 3, 6, 9]，排序后相邻差最大值为 3。可以证明无法用 0 次操作达成目标，因此最少操作次数为 1。

### 样例 3

**输入**

```text
2 5
1 10
```

**输出**

```text
1
```

**说明**

可以将柜子 10 的物品移动到柜子 6，得到 [1, 6] 差值为 5；或者将柜子 1 的物品移动到柜子 5，得到 [5, 10] 差值也为 5。至少需要 1 次操作。

### 样例 4

**输入**

```text
5 0
1 2 1 3 1
```

**输出**

```text
2
```

**说明**

target_gap 为 0 意味着所有物品必须移至同一个柜子。柜子编号 1 已经出现了 3 次，只需将编号为 2 和 3 的两个物品移动到柜子 1，操作次数为 2。

## 说明

如果 target_gap 为 0，则最终所有物品必须在同一个柜子中，操作次数等于总物品数减去出现次数最多的编号的频数。对于一般情况，题目保证一定存在某种移动方案满足条件，只需输出最小操作次数，无需输出具体方案。
