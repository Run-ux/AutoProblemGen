# 最受欢迎的票号

> 生成任务：`ext_counting_trailing_nines` / theme `urban_commute`

## 题目描述

小张是某市公交系统的站务员，每天早上他都要在闸机旁发放标有编号的纸质单程票。最近公司推出“幸运票”活动：票号末尾连续的数字 9 越多，乘客就越喜欢。为了合理分配各站点的票卷，小张需要统计某一批次中“最幸运”的票有多少张。

具体来说，每个票号是一个正整数。给定两个整数 p 和 d，表示该批次票号的区间为 [p-d, p]（包含两端）。我们定义一张票的“幸运度”为其十进制表示中末尾连续 9 的个数，记作 t(x)。令该区间内所有票号幸运度的最大值为 t_max。小张的任务是统计区间内所有幸运度恰好等于 t_max 的不同票号的个数。不同票号即使幸运度相同也视为不同。

## 输入格式

一行包含两个整数 p 和 d（1 ≤ p ≤ 10^18，0 ≤ d < p），分别表示票号区间的上界以及相对于上界下界减少的数值。即考虑的票号区间为 [p-d, p]。

## 输出格式

输出一行一个整数，表示区间内幸运度等于 t_max 的不同票号的数量。

## 数据范围与限制

- 时间限制：1 秒
- 空间限制：256 MB
- 1 ≤ p ≤ 10^18
- 0 ≤ d < p

## 样例

### 样例 1

**输入**

```text
18 8
```

**输出**

```text
9
```

**说明**

区间为 [10,18]，所有票号末尾均无 9，因此最大幸运度为 0。区间内 9 个票号全部满足，故答案为 9。

### 样例 2

**输入**

```text
30000 20000
```

**输出**

```text
2
```

**说明**

区间为 [10000,30000]。幸运度最大为 4，分别是票号 19999 和 29999。只有这两张票满足条件，答案为 2。

### 样例 3

**输入**

```text
1029 102
```

**输出**

```text
1
```

**说明**

区间为 [927,1029]。幸运度最大为 3，只有票号 999 满足。答案为 1。

## 说明

答案保证在 64 位无符号整数范围内，无需对任何数取模。
