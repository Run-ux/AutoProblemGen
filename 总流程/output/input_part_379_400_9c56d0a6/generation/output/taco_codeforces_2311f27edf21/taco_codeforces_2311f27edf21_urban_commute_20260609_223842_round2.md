# 校园幸运号

> 生成任务：`inv_min_d_campus` / theme `campus_ops`

## 题目描述

校园活动中，当前已叫到的最大号码是 p。组织者希望最终显示的号码末尾至少能有 t 个连续的 9，显得格外幸运。
但由于规则限制，最终号码 x 必须是之前叫过的号（即 x 不大于 p），且只能通过“停止叫号”来提前结束，也就是决定一个减少量 d = p - x，使得最终号码 x 满足条件。为了尽量不耽误大家，你需要让这个减少量 d 尽可能小；如果有多组解，则挑选最终号码 x 最大的那一个。
你的任务是：给定 p 和 t，求出最小的 d 以及对应的最大合法最终号码 x。

## 输入格式

输入仅一行，包含两个整数 p 和 t（1≤p≤10^18，0≤t≤18），以空格分隔。

## 输出格式

输出一行两个整数，依次为最小的减少量 d 和对应的最大合法最终号码 x，以空格分隔。

## 数据范围与限制

- 1 ≤ p ≤ 10^18
- 0 ≤ t ≤ 18
- 数据保证至少存在一个合法的最终号码 x，即存在非负整数 x ≤ p 且 x 的十进制表示末尾至少有 t 个 9。
- 时间限制：1.0 秒
- 空间限制：256.0 MB

## 样例

### 样例 1

**输入**

```text
1029 3
```

**输出**

```text
30 999
```

**说明**

当前号码 1029，需要末尾至少 3 个 9。合法的号码有 999，减少量为 1029 - 999 = 30，且不存在更小的减少量，同时 999 是满足条件的最大号码。

### 样例 2

**输入**

```text
27191 2
```

**输出**

```text
92 27099
```

**说明**

当前号码 27191，要求末尾至少 2 个 9。候选号码包括 27099（减少 92）、26999（减少 192）……其中 27099 的减少量 92 最小，也是相同减少量下最大的号码（注意 27199 大于 p，不可选）。

### 样例 3

**输入**

```text
1000 0
```

**输出**

```text
0 1000
```

**说明**

t=0 表示对末尾 9 的个数没有要求。减少量 0 即可选择当前号码 1000，它也是最大的合法号码。

### 样例 4

**输入**

```text
1000 4
```

**输出**

```text
1 999
```

**说明**

p=1000，末尾需要至少 4 个 9。唯一合法的号码是 999（末尾三个 9 不够，但 999 是小于等于 1000 的最大合法号码），减少量为 1。

## 说明

d 是非负整数，x 是介于 0 到 p 之间的整数。当多个 x 都能达到相同的最小 d 时，选择 x 最大的那一个。保证输入数据至少有一组可行解。
