# 物品整理最小调整

> 生成任务：`home_org_inverse_min_shift` / theme `home_organization`

## 题目描述

小明有一个很长的柜子，柜子被划分成连续的正整数编号的格子，编号范围从 1 到 10^9。他有 N 个物品，每个物品会占据一段连续的格子。初始时，每个物品已经放置在某个区间 [S_i, E_i] 上（S_i ≤ E_i）。

小明计划整理这些物品，使得在之后的一些特定位置上检查时，看到的物品数量正好满足他的要求。具体地，小明会进行 Q 次检查，每次检查选择一个位置 p 和一个期望看到的物品数量 t，他希望在最终的物品放置方案中，恰好有 t 个物品的区间覆盖位置 p。

小明可以改变物品的放置位置：对于任意一个物品，他可以将该物品的区间修改为任意新的区间 [S', E']，满足 1 ≤ S' ≤ E' ≤ 10^9。一次修改只能改变一个物品的区间，每个物品最多只能被修改一次。小明希望知道，最少需要修改多少个物品，才能让所有 Q 次检查的要求同时得到满足。如果无法做到，请输出 -1。

## 输入格式

第一行一个整数 N，表示物品的数量。
接下来 N 行，每行两个整数 S_i, E_i，表示第 i 个物品初始占据的区间，保证 S_i ≤ E_i。
接下来一行一个整数 Q，表示检查要求的数量。
接下来 Q 行，每行两个整数 p, t，表示一次检查要求：希望在位置 p 处恰好看到 t 个物品。

## 输出格式

输出一个整数，表示最少需要修改的物品数量。如果无法满足所有检查要求，输出 -1。

## 数据范围与限制

- 1 ≤ N ≤ 100,000
- 1 ≤ Q ≤ 5,000
- 1 ≤ S_i ≤ E_i ≤ 1,000,000,000
- 1 ≤ p ≤ 1,000,000,000
- 0 ≤ t ≤ 100,000
- 时间限制: 2 秒
- 空间限制: 256 MB

## 样例

### 样例 1

**输入**

```text
3
1 2
2 3
3 4
2
2 2
3 2
```

**输出**

```text
0
```

**说明**

初始方案：物品1在[1,2]，物品2在[2,3]，物品3在[3,4]。
检查1在位置2要求看到2个物品：物品1和2覆盖位置2，恰好2个。
检查2在位置3要求看到2个物品：物品2和3覆盖位置3，恰好2个。
所有要求均已满足，不需要修改任何物品。

### 样例 2

**输入**

```text
3
1 1
2 2
3 3
1
2 2
```

**输出**

```text
1
```

**说明**

初始方案：每个物品只占据一个格子，位置2只有物品2覆盖，要求看到2个物品。
只需修改物品1，将其区间改为[2,2]，则位置2有物品1和物品2，恰好2个。修改1个物品为最优。

### 样例 3

**输入**

```text
2
1 5
3 7
1
4 2
```

**输出**

```text
0
```

**说明**

初始方案中，物品1覆盖[1,5]，物品2覆盖[3,7]。位置4同时被两个物品覆盖，满足要求。

### 样例 4

**输入**

```text
3
1 2
3 4
5 6
2
3 3
5 1
```

**输出**

```text
2
```

**说明**

初始方案：位置3只有物品2覆盖；位置5只有物品3覆盖。
要求位置3有3个物品，位置5有1个物品。
一种最优方案：保留物品2不变，修改物品1为[3,3]，修改物品3为[3,5]。
最终：位置3有物品1、2、3（3个），位置5有物品3（1个）。共修改2个物品。可以证明无法只修改1个物品达成目标。

### 样例 5

**输入**

```text
1
1 1
1
1 2
```

**输出**

```text
-1
```

**说明**

只有一个物品，它最多只能覆盖一个格子，无法在位置1看到2个物品。

## 说明

如果无法通过修改物品来满足所有检查要求，输出 -1。注意每个物品至多被修改一次，修改后的区间可以是任意合法的 [S', E']。
