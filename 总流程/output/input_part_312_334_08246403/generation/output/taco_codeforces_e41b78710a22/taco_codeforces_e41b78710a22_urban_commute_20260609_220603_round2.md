# 格子重排

> 生成任务：`inverse_tree_expectation_by_parent_swap` / theme `home_organization`

## 题目描述

小明有一个多层收纳柜，一共有 n 个收纳格，编号为 1 到 n。其中 1 号格子是整个柜子的总入口（根）。这些格子通过支架连接，形成一棵树状结构：除了根格子外，每个格子 i 都有一个唯一的父格子 p_i（1 ≤ p_i < i），表示它直接从属于哪个格子。

小明每次整理柜子时，会从根格子开始，按照一种随机顺序访问每个格子。具体来说，他站在一个格子 u 前，会先记录当前时间（起始时间为 1），然后随机打乱 u 的所有子格子的访问顺序（每种排列等概率），再依次深入每个子格子进行访问。当访问完所有子格子后，返回 u。这样，每个格子 v 都会有一个首次被访问的时间 starting_time(v)。由于访问顺序的随机性，starting_time(v) 是一个随机变量，但可以精确计算出其期望值 E[v]（可以证明 E[1] = 1，且对于非根节点，有 E[v] = E[parent(v)] + 1 + 0.5 * (S - size[v])，其中 size[v] 是以 v 为根的子树大小，S 是 parent(v) 的所有子树的 size 之和）。式子的具体推导可参见提示。

现在小明希望重新整理收纳柜，使得每个格子的期望访问时间恰好等于他预先设定好的一个目标数组 t[1..n]（显然，因为根总是第一个访问，所以必须有 t[1] = 1.0）。他每次可以选择一个非根格子 i，将其父格子改为另一个格子 j（要求 j 不是 i 的后代，以保证改完后整个结构仍然是一棵以 1 为根的树）。每次这样的操作记为一次调整。小明想让你帮忙计算，最少需要多少次操作才能让最终的柜子结构满足目标期望值（即对于每个 i，最终的 E[i] 与 t[i] 的绝对误差不超过 1e-6）。如果无论如何都无法达到目标，请输出 -1。

## 输入格式

第一行一个整数 n (1 ≤ n ≤ 100,000)。
第二行 n-1 个整数 p2, p3, ..., pn，表示初始树中每个格子的父格子。保证 1 ≤ pi < i。
第三行 n 个浮点数 t1, t2, ..., tn，表示目标期望开始时间。保证 t1 = 1.0，其余 ti 均在合理范围内。

## 输出格式

一个整数，表示最少操作次数。若无法实现目标，输出 -1。

## 数据范围与限制

- 时间限制：2 秒
- 空间限制：256 MB
- 1 ≤ n ≤ 100,000
- 输入中的浮点数保证在合理范围内，且目标数组保证 t1 = 1.0

## 样例

### 样例 1

**输入**

```text
3
1 2
1.0 2.0 3.0
```

**输出**

```text
0
```

**说明**

初始树就是链 1-2-3，其期望访问时间恰好是 [1,2,3]，与目标完全一致，无需操作。

### 样例 2

**输入**

```text
3
1 2
1.0 2.5 2.5
```

**输出**

```text
1
```

**说明**

初始树为链，期望为 [1,2,3]。可以将格子 3 的父格子改为 1，得到树 1-2 和 1-3，此时期望值为 [1,2.5,2.5]；只需要一次操作即满足目标，且没有更少的方案。

## 说明

期望值的计算公式已在上文中给出，选手需验证目标的可达性，并设计操作序列使得最终树的期望数组与目标一致。题目要求输出绝对误差不超过 1e-6 即可。
