# 格子重排

> 生成任务：`inverse_tree_expectation_by_parent_swap` / theme `home_organization`

## 题目描述

小明有一个多层收纳柜，一共有 n 个收纳格，编号为 1 到 n。其中 1 号格子是整个柜子的总入口（根）。这些格子通过支架连接，形成一棵树状结构：除了根格子外，每个格子 i 都有一个唯一的父格子 p_i（1 ≤ p_i < i），表示它直接从属于哪个格子。

小明每次整理柜子时，会从根格子开始，按照一种随机顺序访问每个格子。具体来说，他站在一个格子 u 前，会先记录当前时间（起始时间为 1），然后随机打乱 u 的所有子格子的访问顺序（每种排列等概率），再依次深入每个子格子进行访问。当访问完所有子格子后，返回 u。这样，每个格子 v 都会有一个首次被访问的时间 starting_time(v)。由于访问顺序的随机性，starting_time(v) 是一个随机变量，但可以精确计算出其期望值 E[v]。

期望值的计算基于树的结构：记 size[v] 表示以 v 为根的子树中的格子数量（包含 v 自身）。可以证明 E[1] = 1，且对于任意非根节点 v，设其父节点为 p，令 S 为 p 的所有子格子的 size 之和（即所有兄弟子树的 size 总和，包括 v 自身），则有
E[v] = E[p] + 1 + 0.5 × (S - size[v])。

现在小明希望重新整理收纳柜，使得每个格子的期望访问时间恰好等于他预先设定好的一个目标数组 t[1..n]（注意由于根总是第一个访问，所以必须有 t[1] = 1.0，并且所有 t_i 均落在合理的区间内）。他每次可以选择一个非根格子 i，将其父格子改为另一个格子 j（要求 j 不是 i 的后代，以保证改完后整个结构仍然是一棵以 1 为根的树）。每次这样的操作记为一次调整。

小明想让你帮忙计算，最少需要多少次操作才能让最终的柜子结构满足目标期望值（即对于每个 i，最终的 E[i] 与 t[i] 的绝对误差不超过 1e-6）。如果无论如何都无法达到目标，请输出 -1。

## 输入格式

第一行一个整数 n (1 ≤ n ≤ 100,000)。
第二行 n-1 个整数 p2, p3, ..., pn，表示初始树中每个格子的父格子（若 n=1 则该行省略）。保证 1 ≤ p_i < i。
第三行 n 个浮点数 t_1, t_2, ..., t_n，表示目标期望访问时间。保证 t_1 = 1.0，其余 t_i 满足 1.0 ≤ t_i ≤ n。

## 输出格式

一个整数，表示最少操作次数。若无法实现目标，输出 -1。

## 数据范围与限制

- 时间限制：2 秒
- 空间限制：256 MB
- 1 ≤ n ≤ 100,000
- 1.0 ≤ t_i ≤ n (i ≥ 2)，且 t_1 = 1.0

## 样例

### 样例 1

**输入**

```text
3
1 2
1.0 2.0 3.0
```

**输出**

```text
0
```

**说明**

初始树为链 1-2-3。其期望访问时间恰好为 [1, 2, 3]，与目标完全一致，无需操作。

### 样例 2

**输入**

```text
3
1 2
1.0 2.5 2.5
```

**输出**

```text
1
```

**说明**

初始树为链 1-2-3，期望为 [1, 2, 3]。可以将格子 3 的父格子改为 1，得到树：1 的孩子为 2 和 3。此时 size[1]=3, size[2]=1, size[3]=1。计算期望：E[1]=1；对于 2，S=1+1=2，E[2]=1+1+0.5*(2-1)=2.5；对于 3，同样 E[3]=2.5。仅需 1 次操作即满足目标，且没有更少的方案。

### 样例 3

**输入**

```text
2
1
1.0 1.0
```

**输出**

```text
-1
```

**说明**

只有两个格子，根为 1，格子 2 的父格子只能是 1。尽管允许将格子 2 的父格子改为 1（该操作合法，因为 1 不是 2 的后代），但树结构不会发生任何改变，因此期望值 E[2] 始终为 2（无法减小）。目标要求 t[2]=1.0，不可达，故输出 -1。

## 说明

上述期望公式中的 size[v] 定义为以 v 为根的子树包含的格子数量，包括 v 自身。题目保证所有合法的树的期望值均落在 [1, n] 区间内。输出时只需一个整数，表示最少操作次数或 -1。
