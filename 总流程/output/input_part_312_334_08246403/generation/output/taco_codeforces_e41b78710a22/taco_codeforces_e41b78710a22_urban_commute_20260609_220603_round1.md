# 公交期望重规划

> 生成任务：`inverse_design_commute_expectation` / theme `urban_commute`

## 题目描述

城市中有一条公交快线，共有 n 个站点，编号 1 至 n。线路以站点 1 为起点，结构为一棵树。每天清晨，一辆公交车从站点 1 出发，按照随机深度优先的顺序遍历所有站点：每当到达某个站点，它会立刻将当前时间加 1，然后随机打乱该站点所有子站点的访问顺序，并按照打乱后的顺序依次前往每个子站点。对每个站点 i，公交车到达 i 的时刻是一个随机变量，记其期望值为 E[i]。

现在，公交公司希望调整线路，使得每个站点 i 的期望到达时间恰好等于给定的目标值 t_i（允许绝对误差不超过 1e-6）。调整的方式是进行“改线”操作：一次操作可以选择某个非起点的站点 v，并将其父站点改为另一个站点 p。要求 p 不能等于 v 且 p 不能位于 v 的子树中，操作后整体仍然形成一棵以 1 为根的树。

你需要求出最少的操作次数，并输出一种具体的操作方案。如果无论如何也无法达到目标，则输出 -1。

## 输入格式

第一行一个整数 n (1 ≤ n ≤ 100000)，表示站点数量。
第二行 n-1 个整数 p2, p3, ..., pn (1 ≤ pi < n)，pi 表示初始树中站点 i 的父站点（保证构成一棵以 1 为根的树）。
第三行 n 个浮点数 t1, t2, ..., tn，表示每个站点的目标期望到达时间。

## 输出格式

若无法通过有限次操作达到目标期望，则输出一行 -1。
否则，第一行输出一个整数 k，表示最少操作次数。
接下来 k 行，每行输出两个整数 v 和 p，表示一次操作：将站点 v 的父站点改为 p。若存在多种可行方案，输出任意一种。

## 数据范围与限制

- 1 ≤ n ≤ 100000
- 时间限制：2 秒
- 空间限制：256 MB
- 输入的树保证以 1 为根，且每条边连接两个不同站点
- t_i 为实数，可能为任意值；若 t_1 != 1.0，则一定无解（因为 E[1] 恒为 1）
- 答案允许绝对误差不超过 1e-6
- 操作次数 k 必须为全局最小值，且操作序列在过程合法性条件内可以任意顺序输出

## 样例

### 样例 1

**输入**

```text
3
1 2
1.0 3.0 3.0
```

**输出**

```text
-1
```

**说明**

初始线路为链：1-2-3。根期望 E[1]=1，E[2]=2，E[3]=2.5。目标期望 [1,3,3] 无法通过任何合法操作达到。

### 样例 2

**输入**

```text
3
1 1
1.0 2.0 2.5
```

**输出**

```text
1
3 2
```

**说明**

初始线路为星型：1-2 和 1-3。当前期望 E = [1, 3, 3]。目标期望为 [1, 2, 2.5]。只需将站点 3 的父站点改为 2，线路变为链 1-2-3，期望值恰好变为目标。操作次数为 1，已是最少。

## 说明

对于期望值的计算，函数关系满足：E[1]=1，对任意非根站点 v，E[v] = E[parent(v)] + 1 + (sum_{u 与 v 同父} size(u) - size(v)) / 2，其中 size(w) 表示以 w 为根的子树中的站点总数。该关系在任意合法操作后依然保持。若 t_1 不等于 1.0，则可直接输出 -1。
